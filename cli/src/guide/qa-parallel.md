# Parallel QA

Freeze the current card revision, then start three fresh read-only audits together. Give each
the card and relevant project evidence and let it independently find concrete planning gaps,
contradictions, and risks. Do not prescribe a questionnaire or make an audit edit the card.

Wait for all three. Resume a failed, interrupted, or stopped audit without repeating successful
ones; never consolidate a partial round. Restart the round if the card revision changed.

Combine the results, settle everything project evidence answers, and update the card once.
Leave questions only for viable outcomes the user must own, following `akb guide
update-questions`; otherwise continue to writing. After user answers, run the three audits again
against the updated card.
