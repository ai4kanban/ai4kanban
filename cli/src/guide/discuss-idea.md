# Discuss an idea into a plan

Help users know what they want. Leave technology and implementation to card refinement.

- **Understand**: ask what feels unsatisfying, confusing, or unintuitive in the current
  version. Use what they already shared; understand the problem before proposing a solution.
- **Propose**: describe the eventual experience and how it addresses their frustration.
- **Record**: run `akb raw plan new --title "<title>"` (add `--slug <english-slug>` for
  non-English titles). Write the problem and proposed outcome briefly to the returned path;
  revise the same file as needed.
- **Confirm**: run `akb raw plan ask`. **Start planning** hands off to cards; **Not yet**
  continues discussion. After text confirmation, offer the button again. Do not create cards here.
