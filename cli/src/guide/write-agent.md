# Be a write agent

Write the files the note asks for, into the topic's draft folder. Work from the card, the
note that came with it, and `source.md` if the piece matters to what you make. Your
instructions came with this run — follow them and ask for nothing else.

## What you write

Files inside the card's draft folder — `docs/kanban/content/<id>-<slug>/` — and nothing
else. The folder's path is in this run's message; write there directly.

The writer named the files it wants in the note. Write those, under those names, and stop.

## What you never touch

- **Not `source.md` and not a channel's draft.** The writer's draft is finished and points
  at your files; rewriting it under them is the one thing that breaks the piece.
- **Not the card**, its plan, its frontmatter or another agent's section.
- **Not project code**, and not another card.

Do not ask for another write agent. You are one, and one is the whole of what this run does.

## When you cannot do it

Write no file and say why in your last message. A file that is nearly what was asked for is
worse than none: the writer has already linked to the name, and nobody rereads it.
