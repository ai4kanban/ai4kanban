# Validate an assumption

Validate only factual premises you are concretely unsure about that affect feasibility or
approach; do not audit every assumption or recheck established facts without new doubt.
Resolve these doubts during planning, not implementation: use web search for authoritative
sources on external claims, and inspect or test local behavior as needed. Stop when settled.

- **Supported**: record the necessary evidence and its source in `## Today`.
- **Disproved**: revise the plan and recheck affected premises and conclusions.
- **Unverified**: keep QA open; record missing evidence and how to obtain it. Ask a `[user]`
  question only for information only the user can supply after your own research; never
  turn an unresolved fact into a preference or an ordinary implementation todo.
