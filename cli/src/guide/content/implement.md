# Write the piece this card asks for

Build the approved card. It is a piece of writing rather than a change to the program, so
the deliverable is a FILE in this repository — not an answer in the conversation and not a
draft left in a scratch folder.

- **Write files, and only files**: every piece this card produces is written into the
  repository at the path the card names. A run that ends having changed nothing has not
  delivered; say what is missing and stop rather than reporting the card done.
- **No code checks**: tests, diff size and the code-review bar are the coding workflow's and
  are not applied here. Run whatever check the repository requires of the files you touched —
  a link check, a spell check, a build of the site the piece is published from — and nothing
  else.
- **User-action blockers**: follow `akb guide update-questions` and append a `[user]`
  question describing the obstacle and action needed. Stop only dependent work; resume it
  after the user resolves the question. Settle routine wording choices yourself.
- Do not replace or contradict what the card says.
- **Follow-ups**: follow `akb guide follow-up` for additional work.

## What "done" is

- **The card's todos are ticked** and every file the card asks for is on disk.
- **Nothing written is not delivered.** A stage that ends with the working tree exactly as it
  started is unfinished, whatever was decided in the session. Publishing the piece anywhere
  outside this repository is not this card's work.
