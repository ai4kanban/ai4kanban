# Motion recipes

Choose by the techniques the shot needs. Reorder, repeat and interleave actions and camera
moves as scripted; sequence variations do not need separate recipes. Write uncovered
techniques directly with the details needed for the shot. Verification clips are examples,
not defaults.

For composition and animation, follow `references/composition/index.md` to the matching
category and read the entry it lists. Check the entry's linked source before adapting it.

Paths are relative to this agent's folder — the same paths your own files are listed under.
