Set up ai4kanban for this project.

Setup is one command plus the steps only an agent in this repo can do. The command copies
the skill in and scaffolds the board; the skill's own setup guide walks you through the
rest. Your settings live with the board at `docs/kanban/config.md`, never inside the skill
folder, so the skill can be replaced wholesale on every update.

1. Read this repository first, before running anything — enough to pick the tracks the
   work naturally splits into: the buckets a task can live in. The default is
   `feature bug research`; pick something that fits this project better if it does. A solo
   product being launched fits the indie-hacker preset (the skill's
   `references/presets/indie-hacker.md`) better than the default tracks.

2. Run the one setup command from the project root, passing those tracks:

       npx --yes ai4kanban@latest install --tracks <track1>,<track2>,...

   That copies the skill into `.claude/skills/kanban/` (Claude Code) and
   `.agents/skills/kanban/` (Codex), scaffolds the board under `docs/kanban/`, and writes
   `docs/kanban/setup-checklist.md` — setup's remaining steps, one box each. It's safe to
   run twice and it never edits a board that's already there.

   Already added the skill as a plugin (`/plugin marketplace add ai4kanban/ai4kanban` then
   `/plugin install kanban@kanban`)? The plugin makes the skill available but does not
   configure a board, so still run the command — it scaffolds the board either way.

3. Read the skill's `SKILL.md`, at `.claude/skills/kanban/SKILL.md` — note how its "The
   script" section says to run the script. Then follow the skill's `references/setup.md`:
   it is the guide for every box left on the checklist, from filling the config to
   creating the first tasks. Start at the first unticked box.

To pull a newer version later, run `npx --yes ai4kanban@latest update` — same shape, one
command. The skill's `references/update.md` covers what it does and what it leaves to you.
