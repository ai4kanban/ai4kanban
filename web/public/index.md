## Review the key parts. Let agents do the rest.

WildCrane helps you clarify your idea. Each workflow brings you drafts of the parts that need your input. Review and refine them, then let agents complete the work. Tasks that don’t depend on each other move forward at the same time.

## Focus on what matters. Leave the rest to agents.

Complex work moves forward in the background. Your agents notify you when there’s progress.

## The right workflow for the work

Start with six built-in workflows for coding and content. Each makes clear what you review before agents take over. You can also create your own agents and workflows.

- **Coding**: Review the UI and copy that need your input. Agents implement the approved plan.
- **Video clone (code-generated videos)**: Review the reference breakdown and recreation storyboard. Agents recreate the video and make a reusable template.
- **Product video**: Review the script and storyboard. Agents produce the video and cover.
- **Slide deck**: Review the slide content and layout. Agents produce a PowerPoint deck with each slide as an image.
- **Social post**: Review the copy. Agents write the platform captions, plus the page images for a carousel.
- **Blog post**: Review the outline, copy and images. Agents prepare the complete article.
