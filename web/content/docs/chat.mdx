When you want to think out loud — what's worth doing next, what a card actually means, whether
two cards are the same card — open a conversation instead of starting a run.

```bash
akb chat "what should I build next, and why?"
akb chat 241 "what is still unclear about this card?"
akb chat 241 "put it in v0.8 and drop the last todo"
akb chat "start a build on 241"
```

You explain nothing: a chat already knows your project, your open cards and, when you name one,
that card in full. In the app a card's chat is the rail on the right of its page (**Discuss** in
the header), and questions about the whole board go to **New idea**, on every page. A card's
chat is one conversation either way, so you can start it in a terminal and carry it on in the app.

A discussion that **Plan tasks** turns into cards carries on in them: each card's chat shows the
discussion folded above it, and its page links the plan under **Source**.

| You want | What happens |
| --- | --- |
| to decide what to build, or why | it answers — a question, not a job |
| to understand a card before you approve it | it answers |
| to compare two cards, or spot a duplicate | it answers |
| a change you have already settled — reword it, put it in v1, archive it | it makes the change |
| a preference or a correction that outlasts this card | the [memory review](/docs/agents#let-the-memory-review-remember-for-you) writes it down once the card is archived |
| the card worked out, or the code written | it does the work here unless you ask for a background run |

On a card, a change goes into the card, and an answer settles one of its open questions. Say to
hold off and it leaves the card alone. A card a run is already working on is off limits.
`--clear` starts a conversation fresh.

## A model per conversation

Each conversation picks its own agent and model, starting from the board's. Changing one moves
nothing else, so a cheap model can take the quick questions while an expensive one takes the
thinking. Changing the model keeps the conversation; changing the agent starts a new one.

In the app both sit beside **Send**; in a terminal they are `--model` and `--agent`.
