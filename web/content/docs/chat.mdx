Use **New idea** for a board-wide discussion or **Discuss** on a card for its conversation. Chat
has project and open-card context; naming a card includes its full text.

```bash
akb chat "what should I build next, and why?"
akb chat 241 "what is still unclear about this card?"
akb chat 241 "make the empty state friendlier"
```

A card's conversation continues across the terminal and app. When **Plan tasks** creates cards
from a discussion, each card carries the discussion above its chat and links the plan under
**Source**.

## Turn discussion into changes

Most of the time, chat is where you [revise a draft](/docs/drafts#request-changes): say what to
change, and the card is updated. You can also ask questions, answer open questions or start the
build. Say to hold off if you only want to discuss.

A card a run is working on can't be changed in chat. `--clear` starts a fresh conversation.

## A model per conversation

Choose a runtime — a coding agent and its model — beside **Send**, or with `--runtime <id>` in
the terminal; `akb agent` lists the ids and `--runtime ""` goes back to the board's. Each
conversation keeps its own. Switching to a runtime on the same coding agent keeps the
conversation; one on another coding agent starts a new one. See
[Runs](/docs/runs#which-runtime-each-agent-runs-on) for board runtime settings.
