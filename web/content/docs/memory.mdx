## Three kinds of memory

| Memory | What it holds | Who reads it |
| --- | --- | --- |
| **Project memory** | What the project is, who it is for and what has shipped | Planning and Triage |
| **Agent memory** | One agent's own notes, such as layout preferences or wording choices | That agent |
| **Global memory** | Notes several agents share, such as competitor information | Every agent connected to it |

<MemoryAnimation />

Every built-in workflow already defines what its agents remember. When you [add an agent of your own](/docs/agents#add-one-of-your-own), describe in its instructions what it should remember and where.

## Project memory

**Describe the project** keeps it current: after a card is finished, it reads the project and rewrites the description. Find it in **Configuration → Board**; edits by hand do not last.

## Agent memory

Corrections and rejected drafts become notes the agent follows on later tasks. Open an agent's page under **Configuration → Workflows** or **Configuration → Board** to see its memory files, also in `docs/kanban/memory/agents/<agent>/`. Edit outdated preferences or remove notes that no longer apply. For instructions read on every run, [give the agent a rule](/docs/agents#give-an-agent-a-rule).

## Global memory

- **Create**: press **+** in **Configuration → Global memory** and enter its name, description and rules: what belongs there and when to check it again. Notes live in `docs/kanban/memory/<name>/`.
- **Connect**: add `memory: [<name>]` under `akb:` in the agent's `AGENT.md`.
- **Built-in memory**: **Competitors** is kept by `competitor-research`. Its rules update with releases and cannot be edited.
- **Delete**: **Delete** on its page removes the folder and its contents.

## Memory keeps itself current

Two board agents run on a schedule, so you never have to:

- **Review chats**: every day, reads the chats of archived cards and saves their lasting decisions. Chats save nothing as you talk; say “don't record this” to opt out.
- **Tidy memory**: every 7 days, trims memory back to what helps planning.

To run one sooner, open it in **Configuration → Board** and press **Review now** or **Run now**. Change their schedules there too.
