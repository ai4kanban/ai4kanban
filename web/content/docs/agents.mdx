Open **Configuration → Workflows** for a workflow's agents and **Configuration → Board** for
board-wide agents. Each agent has a page for its instructions and runtime; scheduled agents also
have schedule controls.

## Roles

Built-in roles handle planning, execution and board maintenance. Configure their rules and
runtimes on their pages; add custom helpers or scheduled agents below.

- **Planning helper**: discusses ideas and cards with you.
- **Workflow planners**: plan each workflow's cards; see [Workflows](/docs/workflows) for each
  workflow's planning helpers.
- **Builder**: builds a card and lands it.
- **Suggest follow-up work**: proposes work after delivery; see [Follow-ups](/docs/follow-ups).
- **Review chats** and **Tidy memory**: retain useful decisions and compress notes; see
  [Memory](/docs/memory).
- **Describe the project**: keeps `memory/project.md` current for planning.

## Specialists

A specialist writes its own section of a card while the card is planned. The workflow's planner
brings in the ones a card needs and leaves you a question when a decision is yours.

## Give an agent a rule

Write instructions in the rule box on its page. The agent reads them on every run. Rules are
stored in `docs/kanban/rules/<agent>.md` and shared through git on Local boards. Keep them short.

See [Memory](/docs/memory) to edit preferences and decisions, share notes between agents, and
review finished card chats.

## Run an agent on a schedule

Find board-wide scheduled agents under **Configuration → Board**, or a workflow's under
**Scheduled** in **Configuration → Workflows**. Coding includes
[QA manager](/docs/daily-loop#test-cases).

On the agent's page, choose **Auto** to run when it has new input, a preset or a custom schedule.
**Disable** turns scheduling off; **Run now** starts a run even when disabled. Changes are
committed when **Automatic Git commits** is on. Failed runs can retry later or be resumed from
**Runs**.

From a terminal:

```bash
akb workflow schedule <id> --on <agent> --cadence 1d
akb workflow schedule <id> --off <agent>
akb workflow schedule <id> --run <agent>
```

## Add one of your own

Ask your coding agent with the AI4Kanban skill:

> Read akb guide write-agent, then create an agent that [describe its job].

Or press **+** beside **Helpers** or under **Scheduled** in **Configuration → Workflows**, name
the agent and write its instructions. Helpers join planning; scheduled agents run without a card.
**Delete** removes a custom agent, its rule and memory.

## Choose what an agent runs on

Choose its runtime on the agent's page. See
[Runs](/docs/runs#which-runtime-each-agent-runs-on) for coding tools and models.
