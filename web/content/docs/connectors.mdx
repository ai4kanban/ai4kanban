A **runtime** names one of these and says how to reach it. Add one with `akb agent runtime add`
and set it up in **Configuration → Runtimes**; point an agent at one on its own page, or with
`akb agent bind <agent> <runtime>`.

A new board picks the first agent already on your machine that answers, so there is nothing to
fill in when you already run one. An agent that is installed but signed out reads **Logged out**,
with the command that signs it back in.

## Support

All eight do the work. What differs is what they report back. `akb agent list` shows the same
table.

| | Claude Code | Codex | Cursor | OpenCode | Kimi Code | DeepSeek Harness | ZCode | Grok Build |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| Chat and resume | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Early-crash resume | ✓ | — | — | ✓ | — | ✓ | — | ✓ |
| Run cost | ✓ | ✓ | — | ✓ | — | ✓ | — | ✓ |
| Token counts | ✓ | ✓ | — | ✓ | ✓ | ✓ | ✓ | ✓ |
| Model name | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Rate-limit exit | ✓ | — | — | — | — | — | — | — |
| Provider retry | ✓ | ✓ | — | — | — | — | — | — |
| Direct skill call | ✓ | ✓ | — | — | — | — | — | — |

- **Chat and resume**: talk to the board or a card, and pick up a failed run where it stopped.
- **Early-crash resume**: a run that failed in its first seconds resumes; the others offer
  **Retry**.
- **Run cost, token counts, model name**: what **Runs** shows for a finished run. A cost is an
  estimate, not a bill.
- **Rate-limit exit**: a rate-limited run ends and frees the card; the others wait the limit
  out.
- **Provider retry**: a run that hits a passing provider failure picks itself back up.
- **Direct skill call**: the agent loads the board skill by name; the others are asked to in
  the prompt.

A run that stops producing output ends by itself; set how long in **End a silent run after**
under **Configuration → General**.

**Background tasks** — while Claude Code waits on work it started in the background, it
is not silent: it waits up to 2 hours, then ends with the reason. A run carries on when
the work finishes. In a chat you can keep talking meanwhile; the line above the message
box counts the tasks and stops them, and their results arrive as a new message.

## What a run may touch

Codex, OpenCode, DeepSeek Harness and Grok Build write only inside the project. Claude Code,
Cursor, Kimi Code and ZCode run their tools without asking and are not held to the project
folder. All eight reach the network. Pick a fenced agent if that matters to you, or run the
board in a container.

## Settings

Each agent's fields sit under the grid. Every run takes them, and every conversation starts on
them; a single [chat](/docs/chat) can pick another agent or model.

| Agent | Fields |
|---|---|
| Claude Code | Provider (subscription, Anthropic API, or a compatible gateway), model, reasoning effort |
| Codex | Provider (ChatGPT subscription, OpenAI API, or a Responses-API gateway), model, reasoning effort |
| Cursor | Model, Cursor key (optional). Reasoning goes inside the model id: `claude-opus-4-8[effort=high]` |
| OpenCode | Model as `provider/model`, reasoning effort. Keys come from `opencode auth login` |
| Kimi Code | Provider (Kimi sign-in, or a custom model endpoint in the Kimi, Anthropic or OpenAI format), model |
| DeepSeek Harness | Model, DeepSeek key (optional — otherwise the one `dsh` saved) |
| ZCode | Model, Z.AI Coding Plan key (a `zcode login` won't run the board) |
| Grok Build | Model, xAI key (optional — otherwise the one `grok login` saved) |

For a gateway such as OpenRouter or LiteLLM, use Claude Code (Anthropic format), Codex (OpenAI
Responses API) or Kimi Code (any of the three).

Press **Test** (or run `akb agent test`) to send one small message through the setup, so a bad
login turns up here rather than on your next card.

### Kimi Code

- **Install**: `curl -LsSf https://code.kimi.com/install.sh | bash` — Kimi **Code**, not the
  older `kimi-cli`.
- **Sign in**: `kimi login`.
- **Your own endpoint**: pick **Custom model endpoint** and fill in the model id, base URL and
  key; **Endpoint format** picks Kimi's, Anthropic's or OpenAI's API.
- **Model**: on the sign-in provider, an alias from your own `config.toml`. Empty runs Kimi's
  default.
- **Limitation**: not yet tested on a real card run.

### ZCode

ZCode is Z.ai's coding agent for its GLM models, and the way to run this board on a GLM Coding
Plan.

- **Install**: `npm install -g zcode-app-cli` — a community package that lifts the agent out of
  ZCode Desktop.
- **Sign in**: paste a Coding Plan key from [Z.ai](https://z.ai/subscribe) or
  [BigModel](https://bigmodel.cn/glm-coding) into **Z.AI Coding Plan key**. A `zcode login`
  does not work.
- **Model**: `glm-5.3`, `glm-5-turbo` or another your plan reaches. Empty runs ZCode's default.
- **Limitation**: a stopped run can't be resumed; start it again.

### Grok Build

- **Install**: `curl -fsSL https://x.ai/cli/install.sh | bash`.
- **Sign in**: `grok login`, or an xAI key in **xAI API key** on a machine with no browser.
- **Model**: `grok-4.6`, or another your key reaches. Empty runs Grok's default.
