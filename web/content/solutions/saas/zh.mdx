## 产品开发与营销在同一个看板上推进

一个功能、一个落地页、一支发布视频。内置专业 agent 和工作流，让互不依赖的任务并行推进。agent 结合项目背景开展工作，你不必在不同对话里反复介绍同一个产品。

你把关重点。agent 为需要你决定的部分准备草稿，再在约定范围内完成后续工作。

<Board alt="产品与营销任务在同一个看板上并行推进" />

## 开发之前先审关键草稿

界面、文案、邮件或 agent 指令，凡是你在意的关键点，都可以在实现前先看草稿。内置专业 agent 按任务分工，你不用自己设计团队分工或反复调提示词。

不确定一个功能值不值得做，就先看草稿。趁完整功能还没实现，改掉问题，或放弃这个想法。

### 影响产品的问题提前问清

agent 结合项目补齐计划，把关键问题、选项和推荐答案放到卡片上。你不必从头写完整需求，只需作出产品决定。

<Screens src="coding-questions-poster-v1" alt="卡片上的问题、选项和推荐答案" />

### 小修复简单做

小任务可以直接实现。大改动按需要规划和准备关键草稿，审过确认后再交给 agent 开发。

## 为产品准备合适的配图

配图 agent 结合项目背景和你的视觉偏好，为文档、落地页、SEO 博客和产品内引导准备图表与插图。

先确认每张图要传达什么，再完成制作。已经定下的视觉风格，也能延续到下一项任务。

## 产品要做好，也要讲清楚

开发只是 SaaS 工作的一部分。官网、发布文案和用户文档，也需要讲清产品帮助谁、为什么值得使用。

文案 agent 结合项目背景和写作偏好，起草产品及营销文案。页面制作前先确认信息与措辞，减少反复解释产品、纠正表达的时间。

## 规划功能时先看看竞品怎么做

由你指定需要关注的竞品。规划功能时，研究 agent 自动调查这些产品如何支持该功能，把相关结果放到任务卡片上。

对比不同做法，再决定自己的方案。结论与功能计划放在一起，供后续实现参考。

## 让客户了解产品的新进展

邮件 agent 帮你准备产品通讯邮件，包括标题、正文，以及电脑和手机预览。发出之前，先确认信息是否清楚、读者下一步该做什么。

草稿确认后，再通过你的邮件服务发送。

## 把产品进展做成营销素材

用现有内容工作流介绍新版本、讲解新功能，或展示产品的使用方式。

- **轮播帖**：先确认文案，再获得每一页的图片及配文，用于多页社交帖子。
- **产品视频**：制作前先确认脚本和分镜，把故事讲什么、怎么讲定下来。

关键内容先定好，再由 agent 制作素材，其他互不依赖的工作可以同时继续。

## 这次说清楚，下次少重复

每个 agent 记住与自身工作相关的偏好和决策。文案 agent 学习你如何介绍产品，配图 agent 记住你选定的视觉风格。

agent 之间也能共享项目知识。下一项任务从已有共识继续，减少重复纠正。

[了解专业 agent](/docs/agents)

## 主线做完，再把遗漏补上

一项主线工作完成后，agent 自主提出跟进建议，帮你查缺补漏。后台 agent 回顾进展，QA 从用户角度测试近期产品改动。

建议进入待筛选列表，由你决定哪些值得建成任务。

<Screens src="coding-follow-ups-v1" alt="待筛选列表里的跟进建议" />

## 继续使用你已有的工具和订阅

在桌面应用中打开项目，连接 Claude Code、Codex 等[受支持的工具](/docs/connectors)。工具在你的电脑上运行，使用你自己的订阅；AI4Kanban 不额外收取 token 费用。

每个 agent 可以分别选择工具和模型。你也可以通过 Skill 和 CLI，在编码 agent 会话中操作同一个看板。
