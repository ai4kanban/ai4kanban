## 产品开发与营销在同一个看板上推进

一个待交付的功能、一篇待写的文章、一支待制作的发布视频。内置专业 agent 和工作流，让互不依赖的任务并行推进，不必为每项工作设计团队分工、反复调提示词。

agent 使用项目背景开展工作。需要你拍板的部分先看草稿，确认后按草稿完成；遇到新的关键决定，再请你把关。

## 把产品进展做成营销素材

介绍新版本、讲解功能用法，或准备产品介绍。按需要的素材选择工作流：

- **博客文章**：先审大纲，再获得带配图和链接的完整文章。
- **产品视频**：先审脚本，再获得成片和封面。涉及产品演示时，会先在真实应用中排练，再交给你确认脚本。
- **幻灯片**：先确认内容和逐页预览，再获得每页为一张图片的 PPT；不能单独编辑其中的文字和形状。
- **轮播帖**：先确认文案和逐页大纲，再获得每页图片及所选平台的配文。

素材制作期间，互不依赖的任务可以继续。依赖功能最终表现的内容，等功能交付后再完成。

## 把产品讲清楚，让客户看到新进展

结合相同的项目背景，准备落地页、发布文案、配图和客户通讯邮件。页面制作或邮件发出之前，先审文案、配图草稿和邮件预览。

最终获得约定的文案和图片，以及通讯邮件的标题、正文和电脑、手机预览。邮件确认后，通过你的邮件服务发送。

## 按确认的草稿，把功能做出来

界面、文案、邮件或 agent 指令，需要你判断的部分都可以在开发前先审。任务卡片直接预览电脑和手机双端原型，不必启动项目。小修复可以直接实现。

## 项目背景和相关偏好，延续到下一项任务

每项任务使用项目背景，以及与自身工作相关的偏好和决策。文案 agent 记住你如何介绍产品，配图 agent 记住你选定的视觉风格；agent 之间也能共享项目知识。

下一项任务少一些重复解释，需要你拍板的草稿和新决定，仍由你把关。

[了解专业 agent](/docs/agents)

## 主线做完，再把遗漏补上

一项主线工作完成后，agent 自主提出跟进建议，帮你查缺补漏。后台 agent 回顾进展，QA 从用户角度测试近期产品改动。

建议进入待筛选列表，由你决定哪些值得建成任务。

<Screens src="coding-follow-ups-v1" alt="待筛选列表里的跟进建议" />

## 继续使用你已有的工具和订阅

在桌面应用中打开项目，连接 Claude Code、Codex 等[受支持的工具](/docs/connectors)。工具在你的电脑上运行，使用你自己的订阅；AI4Kanban 不额外收取 token 费用。

每个 agent 可以分别选择工具和模型。你也可以通过 Skill 和 CLI，在编码 agent 会话中操作同一个看板。
