description: A new or changed skill, agent prompt, or other instructions an AI model follows.
---

- **The exact text**: a new prompt in full in a fenced block; a changed one as a unified diff
  in a `diff` block against the current file, with enough context to locate every change.
- **Sample outputs**: two or three, each produced by following the prompt yourself on a
  realistic, distinct input shown above it.
- **Writing**: plain natural-language instructions in English, one short generic sentence per
  rule; never code that builds or picks the prompt.
