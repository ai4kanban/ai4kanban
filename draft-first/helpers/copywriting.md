---
description: User-facing text the task writes or changes outside the product's screens — website pages, the README, release notes, store listings, user documentation — when its wording still needs the user's decision.
---

- **Only what changes**: each changed passage, labelled with its file and section; a new page
  in full, with where it goes in the navigation.
- **As readers see it**: plain text without markup; a rewrite gives only the new text,
  scattered edits read ~~old~~ → new, and metadata reads `Field: new value`.
- **Languages**: group them, never interleave line by line.
- **Standard**: claim only what ships; name screens, buttons and commands exactly as the
  product shows them; take tone and terms from what the project already publishes.
