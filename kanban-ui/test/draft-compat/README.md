# Render compatibility

A draft folder moves onto a card as is, so draft-first and the board must draw it the same
way. Each case in `cases.json` names an asset, what it draws as, and text the result must
contain.

The same folder is `test/compat/` in
[ai4kanban/draft-first](https://github.com/ai4kanban/draft-first). Change both together.
