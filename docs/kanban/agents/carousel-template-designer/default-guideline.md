# Default carousel template guideline

Defaults for a template designed with no reference; the card and the reference win.

- **Page set**: two openings (one with a visual slot, one with text only), three middles (a header with a visual slot, text only, and a full-page visual slot with no header) and one closing.
- **Visual slot**: every visual slot accepts an image, a video or a component and is labelled "图片 / 组件 / 视频" ("IMAGE / COMPONENT / VIDEO"); what fills it is decided when the content is designed, never by the template.
- **Text only**: the text in a layout of its own, such as centered; never a component standing in for the visual.
