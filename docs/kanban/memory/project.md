# Project

What the project is today, from its users' side. Rewritten whole by `akb describe-project`;
edits here do not last.

## What it is

AI4Kanban 是面向独立开发者的 agent 工作台，把开发和营销工作流放进同一块看板。agent 先把需要你判断的部分（UI、文案、视频脚本等）做成草稿给你审，你认可后再交给 agent 实现和处理细节；互不依赖的任务并行推进，项目上下文和你的偏好带进下一个任务。提供 macOS / Windows / Linux 桌面应用（内含 `akb` 命令行和 agent skill），看板默认是仓库里 `docs/kanban/` 下的 Markdown 文件。

## Who it is for

- **独立开发者和小团队**：既要做产品又要做营销，想交付更多功能、发布更多内容的人。
- **已在用 coding agent 的开发者**：Claude Code、Codex、Cursor 等用户，使用自己的订阅或 API key，无额外 token 费用。

## Problems it solves

- **营销和开发一样耗精力**：开发和营销在同一块看板上由专项 agent 分工推进。
- **做对需求仍不够好**：功能达标但 UI 别扭、视频照做但脚本生硬；草稿先审让你在关键处定标准。
- **agent 需要人盯**：看板拆分任务、并行推进，只在需要决策时通知你。
- **反复交代偏好**：决策、否决和各专项 agent 学到的偏好记入项目记忆，后续沿用。
- **遗漏后续工作**：完工后 agent 建议后续工作，QA agent 从用户角度检查近期改动，统一进 Triage 由你取舍。

## Features

- **看板与卡片**：一个想法一张卡，按优先级、ROI 和依赖排序；"下一步做什么"直接给出推荐；长期不动的卡归入"搁置"列。
- **6 种工作流**：全部免费，自建工作流也免费；Coding、产品视频、幻灯片（导出每页一张图的 PPTX）、社交帖子（按平台出文案、配图和说明，可套用模板库的轮播模板出页图）、博客文章、视频克隆（先审拆解和分镜、可与原片对照，再出与原片并排对比的复刻版，附可换上你自己内容、可增删和调整节拍的模板）；没有 Pro 或积分时，托管配音、配乐和生图改用不花积分的做法；按需求自动匹配工作流，已有卡片也可改换；可自建工作流和 agent 并加自己的规则。
- **Refine / Resolve**：自动规划卡片，太大就拆成子任务，只把真正需要你判断的问题留给你。
- **草稿先审**：文案、UI 设计稿、配图、竞品调研、技术选型、提示词等 10+ 专项 agent 各写卡片的一节；设计稿可交互、可缩放，文案按页面和语言并列阅读；版本、图片、视频可并排对比并下载；整页设计可从模板库挑预览；在卡片对话里提意见，草稿就地修改；大改动分阶段出稿，卡片显示当前阶段，逐段批准后才继续。
- **一键构建（Build）**：在独立会话和 Git worktree 里并行构建，冲突自动处理，落成一次提交并自动归档；Diff 标签显示改动。
- **QA 手册**：QA agent 每次构建后测试受影响的用例并附截图或日志，用例下的反馈可送进 Triage。
- **Chat**：就整个看板或某张卡对话，结论可直接改卡或拆成新卡。
- **Runs**：后台运行 agent，可看日志、停止、续跑，显示成本、token 和模型。
- **8 种 coding 工具**：Claude Code、Codex、Cursor、OpenCode、Kimi Code、DeepSeek Harness、ZCode、Grok Build，每个 agent 可单独选工具和模型。
- **项目记忆**：决策、否决按模块记录并定期精简；归档卡片的对话回收进记忆；全局记忆可供多个 agent 共用。
- **内置与定时 agent**：完工后建议后续工作，前置变化时自动修订计划，自动更新项目描述；可按频率或有新输入时自动运行。
- **Triage**：建议、后续工作和 `akb triage add` 送来的外部反馈进入待分拣队列，逐条建卡、立即开始、讨论或忽略。
- **归档**：移除的卡连同理由留存，30 天后自动清理。
- **Local 与 Cloud 看板**：本地看板随 git 走；Cloud 看板（邀请制预览）跨机器同步，可在浏览器和手机上读。
- **通知与 Insights**：应用内通知栏列出需要决策和已落地的卡（无需登录 Cloud），也可发桌面或 Slack 通知；每日完成、新建、否决的统计。
- **Pro 订阅**：在桌面应用或网页的 Billing 面板先开通 7 天免费试用（附一笔试用积分），试用结束后购买和管理；托管配音、配乐和生图消耗每月 AI credits，用量和价格在 Pricing、Billing 与设置 → Cloud 里可查。
- **在线 demo**：在 `ai4kanban.dev/demo` 免安装点一遍完整流程。
- **模板库**：在 `ai4kanban.dev/templates` 按界面、视频、道具、动效、轮播分类浏览，原作与复刻对照（轮播模板可逐页翻看），复制提示词即可在 AI4Kanban 里套用；模板默认需 Pro。
- **CLI 与 skill**：所有按钮都有对应的 `akb` 命令；一个仓库可放多块看板。
