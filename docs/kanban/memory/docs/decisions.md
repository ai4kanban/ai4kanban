# Decisions

Settled answers to cards' open questions, grouped by topic. Keep only **user-facing**
calls that guide future planning — what a user can see, do, or would care about.
Internal detail stays on the card.

## Connectors

- **The GLM / Z.ai route is ZCode, not Claude Code pointed at Z.ai**, and the base-URL way in
  is not mentioned at all — not even as an unsupported alternative. A second way into GLM
  splits the one answer we support. The compatible-endpoint provider stays for gateways.
- **A connector nobody has run a card on says so**, until a real card has passed on it, rather
  than reading like a tested connector's.
