# Decisions

Settled user-facing answers for telemetry. Read before proposing.

## The service

- **A fix to the daily summaries ships the day it is built**, by hand, not with the next release.

## Reading the numbers

- **内部运营数字放进本地 telemetry 数据页**：如 AI 调用成本，和其他指标同一页显示，不另做命令行报表。
- **The public install count is the real one**, however far below downloads it sits.
