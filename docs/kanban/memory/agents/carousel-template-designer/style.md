# 图文模板设计偏好

## General

- **中英文都要**：初稿和渲染范例各出中英文一版，长度上限按中英文分别写。
- **复刻前多看参考**：看同一账号的多篇帖子再定风格，不只看卡片给的一篇；参考里没有的元素（如翻页箭头）不加。
- **署名用品牌 logo**：署账号品牌，不署人名；原样用项目自己的 logo，不改色、不重画，中间页可以只放 logo；文字左对齐时 logo 放右下角。
- **纸纹等材质用文生图**：做成真实纸张扫描图铺底，不用代码噪点；浅色底的亮度对齐参考，不偏黄。
- **中英文排版分开定**：中文行距更宽、标题下留白更大；英文字号更小、行距紧凑、标题下留白收紧。
- **精致在细节，动画讲数据**：细线、半透明叠层、刻度和极小标签；成百细小元素按数据编排，同一组元素跨页延续、每页推进一步，聚焦时其余淡出；不用一条粗线加几个浮动标签充数。
- **配方要引导出人手的感觉**：手绘线、正在工作的光标这类母题写清像什么、不像什么、怎么画，并配参考图；只列名词，换个 agent 照做会画成均匀的死线。
- **复刻先量排版**：字号档位、字面宽窄与字重、下划线、行距和对齐都对着参考量出来照做；参考全帖一个字号就不拆档，居中的元素按页面中线居中。
