# Style

- **不套网站风格**：不沿用网站的暖白底、墨色粗描边与实心投影，换风格增加多样性；配色仍与网站主题协调，不能只剩黑白；可以更精致，但保持干净优雅。
- **杂志式编辑排版**：纯色底，不用渐变；大号衬线标题是画面主体，文字要大；元素尽量少，不放眉题、编号、标语、署名、占位条和多余的界面控件，示意界面只留核心数字或图形。
- **对比要两边都画**：讲 A 优于 B 时同时画出两侧并标 ✗/✓；冗长的一侧只留两三行真实文字后淡出，不靠堆字表现冗长。
- **SVG 封面**：封面整张用 SVG 画时可接成网站的 TSX 封面（`web/components/blog/covers/`），可加克制的动画。
- **配图讲别的论点**：同篇的绘制配图与封面同一风格，但不重复封面已讲的内容，每张讲文章另一个论点并放进对应一节。
- **截图必须真实且对题**：只用真实产品界面，且与所在段落的例子对应；拍不到对题的真实界面就不放。
- **截图语言**：英文博客的产品截图用英文界面和英文卡片内容，在看板副本里拍，不改用户的真实看板和设置。
