# Style

## Look

- **不套网站风格**：不沿用网站的暖白底、墨色粗描边与实心投影；配色仍与网站主题协调，不能只剩黑白；精致但干净优雅。
- **色板与字体**：1600×1000 画布；底 `#faf7f2`、墨 `#382f42`；紫 `#e5daf2`/`#66507f` 表示「你定的、对的一侧」，橙 `#f5cfbb`/`#b95536` 表示「缺口、错的或 Agent 的一侧」；Georgia 标题、Helvetica 标签、Menlo 代码。
- **杂志式编辑排版**：纯色底不用渐变；大号衬线标题是主体；元素尽量少，不放眉题、编号、标语、署名、占位条和多余界面控件；图上标题写不贴切（如「one post, all three at work」）就不放。

## Drawn figures

- **对比要两边都画**：讲 A 优于 B 时两侧都画并标 ✗/✓；冗长的一侧只留两三行真实文字后淡出。
- **配图讲别的论点**：不重复封面已讲的内容，每张讲文章另一个论点并放进对应一节。
- **线条干净统一**：回环、箭头等同类元素用一条干净的线、同一画法。
- **SVG 封面可带克制的动画**。
- **示意图标在图注里**：虚构示例在图注开头写 `Illustrative:`，不在图上加标签。

## Screenshots

- **真实且对题**：只用与所在段落例子对应的真实界面，拍不到就不放；英文博客用英文界面和英文卡片内容，在看板副本里拍，不动用户的真实看板。
- **截图装框**：放在同色板底上、浅边框圆角；外部网页只留被引用段落，原话用橙色高亮、不改字；产品界面要点用右侧紫色竖线标注，折叠部分用橙色。
