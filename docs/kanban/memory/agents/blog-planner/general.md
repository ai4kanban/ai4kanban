# General

- **博客位置**：网站博客在项目内 `web/content/blogs/`，文章为 `.mdx`，线上地址 `https://ai4kanban.dev/blog/<slug>`。
- **只写有依据的说法**：不承诺未经测量的效果，不把我们自己的经验说成读者的情况或普遍规律；有原稿时只用原稿的真实观点和例子，不编造场景、数据或细节，篇幅不比原稿更臃肿。
- **按读者的问题分节**：章节围绕读者会问的问题和想了解的子话题组织，原稿决定要讲什么，结构为读者需求服务。
- **说清具体结果**：大纲和正文的每句写明对谁、做什么、有什么后果，不用 “walls of text stop working” 这类说不清“对什么失效”的表达。
