# What the user taught `email-planner` about writing

- **开头给出下一步**：第一句就说清读者唯一要做的事。
- **产品介绍**：最多一句，放在后面；直说它做什么、带来什么好处，不用比喻。
- **不邀请回信**：不写"有问题直接回复这封邮件"之类的话。
- **链接**：按钮链到 https 网页，不用 `ai4kanban://`；应用内路径用文字写出。
- **标题直白**：说清是什么、对读者有什么价值，不抽象、不文艺；标题不用 QA 这类内部术语，主标题要短。
- **讲大目标，不讲子功能**：相关改动归到它们共同服务的目标下；琐碎改动（如每次运行花费）不进邮件。
- **数字说清口径**：比的是什么、涵盖哪些工作，写进同一句；不另起免责说明。
- **配图**：艺术感背景上叠高清真实界面（可用 tsx 忠实复刻），不沿用往期插画；不加追踪。
