# Feedback

## General

- **不拿 AI4Kanban 自身做演示**：被演示的开发放在与本仓库隔离的演示项目里；排练用真实工作时改动须可恢复。
- **配角内容可预置**：观众不关注的铺垫（如分组卡里其余子任务）可手工模拟；主线操作仍须真实。
- **外部素材先预置**：品牌标志等 Agent 拿不到的文件先放进演示项目，否则会引出与主线无关的问题。
- **演示数据像真产品**：用具体的 Agent、连接器和模型名，不用「Voice agent」这类泛称；参照产品现有界面时带齐那个界面的字段。
- **前后对比同一形态**：修改只做样式打磨、并排展示首版与定稿，形态大变会让观众怀疑不是同一功能；想要的首版形态写进需求句。
- **先看默认折叠状态**：卡片上的 Agent 分区（含预览）默认收起；说「直接可见」前先在未点击的页面核对，需要点开就写进演示步骤。
