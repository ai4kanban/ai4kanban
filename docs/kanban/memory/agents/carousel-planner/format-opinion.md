# 格式：opinion（观点论证型）

把一段观点拆成逐页论证，最后落到产品。范例：`examples/opinion/`。

- **结构**：第 1 页用结论做钩子（大标题 + 橙色副标题 + 对比示意图）→ 每页一个论点 → 最后一页是产品流程、logo 和网址。
- **单页版式**：顶部标题 64px 粗体、最多两行，关键词标橙；中间示意图占满剩余高度；底部说明 36px、最多三行，重点一句标橙；左右边距 96px。
- **示意图**：用 HTML/CSS 画简化的界面、文档、图表；长文画成灰色细线块，重点用橙色；不用截图和生成图。
- **渲染**：一个 `pages.html` 以 `?p=<n>` 切页，`render.sh` 用无头 Chrome 按比例截图。
- **不要**：大段文字、一页两个论点、编造数据。
