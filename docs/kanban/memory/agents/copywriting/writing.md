# Writing

- **中文用正式、易懂的书面语**：不用口语化或生造的说法（如「带你的人」），栏目名用常见的正式叫法（如「导师介绍」）。
- **定位说「可靠又快」**：AI4Kanban 是多工作流看板（编码、博客、视频等）；可靠来自规划时先预览关键结果，快来自并行执行和交付后的自动跟进。宣传语要落到具体价值。
- **不说「全交给智能体」**：规划离不开用户，「你只做决定，其余交给智能体」不能用；「不用盯着智能体」只限执行阶段。
- **下载导语**：「Download AI4Kanban. Plan with precision, ship at speed.」，中文「下载 AI4Kanban，精准规划，快速交付。」
