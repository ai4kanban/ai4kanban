# 插图风格

## Site figures

- **官网插图**: 沿用 `web/components/blog/figures/kit.tsx` 的语言：水彩底 `Mat` 上放白色卡片、软阴影；橙色只标用户审的部分，其余用无字灰条。
- **文字用 HTML**: 需随语言换行的标签写成 HTML，不放进按比例缩放的 SVG；窄屏用容器查询改为上下排列。
- **落地页配图照真实界面画**: 固定尺寸的图框用 React 按产品真实样式画（真实截图裁不进去），示例素材用已上线的真实内容（如博客封面），不用色块占位；首屏可用录屏，页面不引用 GIF，录屏进入视野才播放。
- **记忆不配截图**: 记忆在界面上不外露，只用文字讲。
- **界面图保持原样**: 不给按钮或字段加白缝、橙色描边这类标注框，会破坏原界面设计。
- **博客封面**: 沿用 `ShowTheUiFirst` 的画布与配色：左侧 200px Georgia 三行标题（每行约 10 个字符以内，否则撞右栏），右侧 ✗ 橙粉栏 / ✓ 淡紫栏，上下或左右排列。
- **文章页配图**: 可用代码画的手绘线稿 SVG：简洁的动漫小人配圆头机器人（代表 Agent），纯白底，站点橙色点缀。

## Hero

- **首屏主视觉**: 代码画的像素风 SVG 动画，沿用 `web/public/agent-art/` 的 Agent 形象、硬阴影和 `steps()` 动作；减弱动态时停在最后一帧。
- **首屏不放背景**: 像素泳道、漂浮 3D 卡片等动态背景都被嫌乱；首屏留纯白，功夫花在插图的画框上。

## Agent art

- **角色精灵**: 新角色不靠出图模型，用脚本在 `kanban-ui/public/agent-art/base.png` 上按 2px 网格画道具，机身逐像素一致；道具只用 `agent-art.md` 的五色，48px 下靠轮廓可认，不与已有道具撞。
- **道具要演出动作**: 道具不只抱在胸前，按职责摆出使用姿势（如望远镜举到脸前观察，可挡住面罩）。

## Card previews

- **预览的限制**: TSX 预览只渲染静态 HTML，无 React hooks，客户端逻辑写成 ref 回调、动效另附录屏；只放行 `data:` 图片，像素图内联成同目录 `.ts`（站点仍用 `/agent-art/`）；只能引用本卡素材目录，借别的卡的界面稿要复制成 `illus-*` 再加道具。

## OG image and logos

- **OG 图**: 沿用站点 `/og-image/` 的深色底，左侧 logo、标题与安装命令（描边框，不用半透明灰底）；右侧要有层次（叠放卡片、批注气泡、确认动作），整体在 630 高度内垂直居中、与左侧文字对齐，不只贴一张截图。
- **子产品 logo**: draft-first 定为举剪贴板的动漫风圆头机器人，剪贴板上只画两条墨色直线（一长一短），不画草书、虚线框；字标小写 `draft-first`，连字符与字母同色、不着橙色；抽象几何、文件加笑脸、取景框、对勾都被否；轮廓上不能有刺出的东西；靠轮廓在 16px 可认，加白色描边让同一版在深色底也能用。
