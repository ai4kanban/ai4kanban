# 插图风格

- **官网插图**: 沿用 `web/components/blog/figures/kit.tsx` 的语言：水彩底 `Mat` 上放白色卡片、软阴影；橙色只标用户审的部分，其余用无字灰条。
- **文字用 HTML**: 需随语言换行的标签写成 HTML，不放进按比例缩放的 SVG；窄屏用容器查询改为上下排列。
- **落地页配图用真实录屏**: 产品能力配图在演示项目（如“邀请成员”）的桌面应用里拍截图，展示过程的用 GIF，中英各一套；不用代码画示意插图。
- **首屏主视觉**: 用代码画的像素风 SVG 动画，沿用 `web/public/agent-art/` 的 Agent 形象、硬阴影和 `steps()` 动作；减弱动态时停在最后一帧。
- **卡片预览里的图片**: TSX 预览只放行 `data:` 图片，像素图要内联成同目录的 `.ts`，站点仍用 `/agent-art/` 路径。
- **首屏背景**: 不用生成的场景画；用代码绘制的像素风动态背景（原生 WebGL，低分辨率 + 抖动），暖白底上浅橙、浅紫缓慢漂移，标题区留空；加载后动态导入，静态底色兜底，视野外暂停。
- **卡片预览不跑脚本**: TSX 预览只渲染静态 HTML，React hooks 不可用；客户端逻辑写成 ref 回调，效果另附浏览器截图。
