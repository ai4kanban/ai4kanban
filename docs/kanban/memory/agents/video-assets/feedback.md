# Feedback

## General

- **运行画面要连续可信**：办公室镜头拍到 Agent 进场、到工位并开始工作；静止、空白或像故障的画面不入片。
- **处理过程要看得见**：有后台处理的点击，先展示运行日志和处理中状态再给结果；可压缩等待，不可瞬间跳到结果。
- **输入要看清**：逐字输入或回到完整请求并停留到可读；不滚到与脚本无关的区域。
- **动画做出分层运动**：不以两张静帧淡入淡出代替；逐帧检查过渡中的重叠，不只看末帧。
- **先试录再采集**：核验尺寸、DPR 和真实帧率；不合格时保留证据，不用静帧拼接或低帧率冒充。
- **录屏规格写全**：成片尺寸与比例、视口、DPR、缩放和设备布局；画面等比铺满、避开字幕，先全景后推近，不补宽边。
- **每镜动作写满**：起始画面、取景、推近目标、逐步动作与输入、停顿和结束状态，每步留够看懂的时间；用户没说出口的预期写成假设交审。
- **静帧即成片画面**：按成片的推近、裁切和位置画出观众实际看到的那一帧。
- **重拍前留恢复清单**：清空旧媒体前在素材目录外保存；旧检查和预览不能证明新一轮可用。
