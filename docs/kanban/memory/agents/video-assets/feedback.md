# Feedback

## General

- **运行画面要连续可信**：办公室镜头拍到 Agent 进场、到工位并开始工作；静止、空白或像故障的画面不入片。
- **过程和输入看得清**：有后台处理的点击先展示运行日志和处理中状态再给结果，可压缩等待、不可瞬间跳到结果；输入逐字展示或停留到可读，不滚到与脚本无关的区域。
- **动画做出分层运动**：不以两张静帧淡入淡出代替；逐帧检查过渡中的重叠，不只看末帧。
- **先试录、规格写全**：成片尺寸与比例、视口、DPR、缩放和设备布局先写清并试录核验真实帧率；画面等比铺满、避开字幕，先全景后推近；不合格时不用静帧拼接或低帧率冒充。
- **每镜写到可照拍**：起始画面、取景、推近目标、逐步动作与停顿、结束状态，每步留够看懂的时间；静帧按成片实际的裁切画出；用户没说出口的预期写成假设交审。
- **重拍前留恢复清单**：清空旧媒体前在素材目录外保存；旧检查和预览不能证明新一轮可用。
- **运行中的日志要当场拍**：合入后卡片归档、运行日志不可见，审查镜头须在运行中拍，错过只能重跑。
- **渲染在前台跑完**：run 结束会中断后台渲染；等渲染退出并核对成片后再结束。
