# Reusable video assets

Paths are under `.akb/boards/docs/kanban/assets/`. Screen clips are 1920×1080, 30 fps, silent H.264, English UI, demo board copy, pointer and click ring drawn in.

- `850/01-open-board.mp4`: board with development #2 and video #13 in one frame, pointer drifts to #2; suits openings and "one board" shots; board layout only; recapture when the board page layout or card design changes.
- `850/02-open-task.mp4` … `850/07-review-plan.mp4`: open a card, answer a question, type in card chat, the agent writes the request back, review Scope/Todo; suits planning and chat demos; tied to demo card #2 text; recapture when the card page, question block or chat panel changes.
- `850/08-start-delivery.mp4`: Implement → confirm → Runs office with Builder running; suits delivery shots; shows the RUN LOG strip; recapture when the Implement dialog or Runs view changes.
- `850/10-open-video-task.mp4`, `850/11-video-workflow.mp4`, `850/12-type-video-brief.mp4`: board → video card, Configuration → Workflows → Demo video roles, typed video brief; recapture when Configuration or the Demo video workflow's agents change.
- `850/13-media-preview.mp4` + `850/13-media-audio.wav`: in-card video plays about 3.9 s and pauses; recapture when the media player changes.
- `850/14-board.png`: board still; same limits as 01.
- `850/00-music.mp3`, `00-click.mp3`, `00-select.mp3`, `00-confirm.mp3`: CC0 copies from `assets/video/README.md`; no typing sound exists there.

- `850/00-logo-mark.svg`: unchanged `web/public/logo-mark.svg`; logo beside typeset product name; replace when brand mark changes.
- `850/10-scriptwriter.png`, `10-video-assets.png`, `10-video-editor.png`: unchanged repository agent-art sprites, 96×96 transparent; collaborative credits, animate in composition and add role props; replace when the character family changes.
