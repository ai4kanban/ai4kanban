# 0.9.0

What each close of this release left behind: a changelog an agent wrote from the cards, and
the cards themselves. A change that never went through the board is in neither — only a
person can add that.

## Closed 2026-09-06

### What changed

- Keep your board in Cloud and open it in a browser — from a second machine, a borrowed laptop or a phone, where the screens now lay out for the small width — and invite teammates into the workspace.
- Set a new board up by talking to it: pick the agent, then answer a conversation that reads the repo and works the rest out, instead of filling in three screens of form.
- The chat rail is a full conversation — keep typing while a reply is still coming, copy, resend or reword a message, open the agent's steps and what the reply cost, and pick the model for one conversation.
- Create task opens as a full-screen chat: discuss a vague idea until it is a plan you can read in one screen, write it up as a task, or build it straight from the box with no card.
- Every flow the board runs is now a named agent you train — one Agents pane, a rule of your own on each, and memory that survives the run.
- AI review runs once per delivery, re-checks only what a rebase changed, and can be switched off for a board or for a single build.

What it was for — 1. low hanging fruit for ui/ux improvemnets 2. web version so mobile users can access the board.
