# 读官网首页

## Setup

- **站点**：官网（`web/`）的静态构建用 `wrangler pages dev` 跑在本机（地址给 `SITE`），无头 Chrome 开远程调试（`CDP_PORT`），窗口 1440×900，手机 390×844；脚本是 [home.mjs](home.mjs)（用 [cdp.mjs](cdp.mjs) 驱动浏览器）。录屏和插图来自线上 `cdn.ai4kanban.dev/home/`。
- **读者**：第一次听说 AI4Kanban、点进 `ai4kanban.dev` 想弄清它做什么的人，用 Mac 打开。

## Steps

1. 打开 `/zh`。
   标题「先看草稿，再往下做」（不带句号），导语「为看板上的任务准备关键草稿。你把关重点，agent 完成细节，一个人也能推进更多事。」，两个按钮：「下载 — macOS」直接给 v0.10.1 的 `.dmg`，「查看 GitHub ↗」。下面是 `/demo` 的录屏：静音、循环、无控件，自己播放（3 秒后从 3.5 秒走到 6.5 秒）。
   ![中文首屏](01-zh-hero.png) · [home.log](home.log)

2. 往下滚到「01 关键部分先看草稿，方向不对现在就改。」，继续滚。
   标题、导语、左边四种草稿（UI 原型、文案稿、分镜、配图）和右边的配图一起固定在页头下方（标题始终在距顶 112px 处）；滚动时高亮框依次滑过四种类型，右侧配图同步换成对应的草稿；列表下方是收尾句「你不用把每个细节都规定好……」。
   ![高亮在 UI 原型](02-zh-drafts-ui.png) · ![高亮在分镜](03-zh-drafts-script.png) · [home.log](home.log)

3. 继续滚过「02」和「03」。
   02「这次提过的意见，下次不用再说。」配一张简笔画（一个人提意见，机器人照做几份草稿），下方小字「产品视频、幻灯片、轮播帖和博客文章需要 Pro。」；03「让 agent 替你查缺补漏」配机器人拿放大镜找出遗漏、递给人一条跟进的简笔画。两张图都直接画在白底上，没有截图框。
   ![02](04-zh-agents.png) · ![03](05-zh-followups.png) · [home.log](home.log)

4. 滚到「04 多项工作一起推进，关键决定交给你。」，点后面露出一截的那张图。
   两张叠放的截图来自 `/demo`：前面是看板，后面是 #38 卡片页；点后面那张，它翻到前面（按钮标签从「切换到 Card 视图」变成「Card 视图（当前）」）。截图是英文界面。
   ![看板在前](06-zh-deck-board.png) · ![卡片页翻到前面](07-zh-deck-card.png) · [home.log](home.log)

5. 滚到页尾的「06」。
   「写下一个想法，先看看草稿。」，一个「下载 — macOS」按钮，下面说明构建未签名、首次打开会被拦，最后一行「偏好命令行？在项目里运行 npx ai4kanban@latest install。」
   ![页尾](08-zh-start.png) · [home.log](home.log)

6. 打开英文首页 `/`。
   标题分两行「See the draft. / Let agents do the rest.」，页面标题「See the draft before agents get to work | AI4Kanban」；四种草稿叫 UI mockup、Copy draft、Storyboard、Figures。
   [home.log](home.log)

7. 用 390px 宽的手机打开 `/zh`，滚到 01。
   不再固定：四种类型上下排列，每种的说明下直接跟它的配图；页面不横向滚动。
   ![手机上的草稿板块](09-phone-drafts.png) · [home.log](home.log)

8. 打开系统的「减少动态效果」后打开 `/zh`。
   首屏录屏不播放，停在首帧（`hero-demo-poster-v1.jpg`）。
   [home.log](home.log)

## Feedback

- **一句话讲清楚**：「先看草稿，再往下做」加一段真实的 `/demo` 录屏，几秒钟就明白产品是干什么的，比旧版「AI 项目经理」具体得多。
- **草稿板块好看但费滚动**：固定区要滚 1.5 屏才走完四种类型，滚轮快的人会觉得页面「卡住了」；不支持滚动驱动动画的浏览器（如 Firefox）看到的是手机式排列，这次没在 Firefox 里实测。
- **02、03 的简笔画**：亲切、一眼看懂，和上下的真实界面截图风格反差明显。
- **中文页里是英文界面**：录屏、草稿板块的 UI 原型、04 的两张截图都是英文的 notely 演示项目，中文读者需要自己脑补。
- **翻转卡组不好发现**：后面那张只露出 40px 一条边，不提示可以点。
