# 把官网切换成中文

## Setup

- 浏览器语言设为简体中文（`Accept-Language: zh-CN`），打开 `https://wildcrane.ai/`。

## Steps

1. 打开首页。
   预期：英文页面顶部出现一条横幅「此页面有中文版。切换到中文」，右侧有关闭按钮。
   证据：[01-banner.png](01-banner.png)
2. 点「切换到中文」。
   预期：进入 `/zh`，导航变成「文档 / 定价 / 资源 / 下载」，标题「不用每个细节都亲自盯」。
   证据：[02-zh-home.png](02-zh-home.png)
3. 再打开 `https://wildcrane.ai/`。
   预期：仍是英文首页，横幅不再出现。
   证据：[03-revisit.png](03-revisit.png)

## Feedback

横幅只用一行告诉用户有中文版，一点就到，中文文案自然、不像机翻。摩擦点：首页里的产品截图
仍是英文界面；切过一次后回到根地址不会自动跳中文，横幅也不再提醒，想再切换只能去找页脚的语言菜单。
