# 评论写到一半刷新页面

## Setup

- 本地云端栈（见 README「如何运行取证」），以发起人 alice 登录，打开任务「给登录页加上「记住我」」
  的审核链接，还没有评论。

## Steps

1. 点右上「评论」，在评论框写「「记住我」勾选后能不能在设置里随时取消？」，先不发送。
   预期：右侧评论栏打开，文字在评论框里。
   证据：[01-typed.png](01-typed.png)
2. 刷新页面，再打开「评论」。
   预期：评论框里仍是刚才的文字，评论数为 0。
   证据：[02-reloaded.png](02-reloaded.png)
3. 点发送。
   预期：评论出现在栏里，署名和时间齐全，评论框清空，计数变为 1。
   证据：[03-sent.png](03-sent.png)
4. 再刷新页面并打开「评论」。
   预期：评论框是空的，已发的内容不会被填回来。
   证据：[04-after-send.png](04-after-send.png)

## Feedback

刷新不丢草稿，发出去就清空，行为符合直觉，完全不用操心。摩擦点：草稿只存在这台浏览器，换设备
就没了；页面上也没有任何「草稿已保存」的提示，用户要刷新一次才知道它还在。
