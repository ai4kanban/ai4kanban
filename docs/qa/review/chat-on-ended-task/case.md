# 在已结束任务页和 AI 讨论

## Setup

- 本地云端栈（见 README「如何运行取证」），以发起人 alice 登录。一台假 Runner 已连接。
- 任务「重新设计结账页」已完成（`status='done'`），之前在任务页和 AI 聊过一轮。
- 任务「订单页加导出按钮」在等审核，打开它的任务页；取证时对话框开着，用 SQL 把它置为 `done`
  （SQL 不发实时事件，页面不会自己刷新）。

## Steps

1. 打开「重新设计结账页」的任务页，点右下「和 AI 讨论」。
   预期：之前的问答照常显示，回复下有复制按钮；输入框灰色禁用，占位文字「任务已结束」，发送按钮
   禁用；没有「试试问」建议，没有「清空对话」，也没有任何报错。
   证据：[01-ended-chat.png](01-ended-chat.png)
2. 点输入框，输入「那支付步骤呢？」并按回车。
   预期：输入框不接收文字，什么也没发出。
   证据：[02-cannot-type.png](02-cannot-type.png)
3. 打开「订单页加导出按钮」的任务页，点「和 AI 讨论」。
   预期：输入框可用，上方是写方案时的回复，顶部右侧有「清空对话」；有历史就不显示「试试问」建议。
   证据：[03-open-task.png](03-open-task.png)
4. 任务在此期间结束；在输入框写「导出能带上退款记录吗？」。
   预期：页面没变化，输入框仍可用，发送按钮亮起。
   证据：[04-typed.png](04-typed.png)
5. 点发送。
   预期：刚写的消息不出现在对话里，输入框变成禁用的「任务已结束」，「清空对话」消失；没有「AI 没能回复」之类的报错。
   证据：[04-sent-after-end.png](04-sent-after-end.png)
6. 页面语言选 English，重开第 1 步的链接和对话框。
   预期：占位文字为「Task ended」。
   证据：[05-english.png](05-english.png)
7. 手机宽度（390px）重开第 1 步的链接和对话框。
   预期：对话占满屏幕，历史可读，底部是禁用的「任务已结束」输入框。
   证据：[06-phone.png](06-phone.png)

## Feedback

结束的任务不再假装能聊：一打开就是灰掉的「任务已结束」，历史还在、能复制，也没有「清空对话」，记录不会被误删。页面开着时
任务结束，发送后安静地切到禁用态，不吓人。摩擦点：第 5 步写好的问题直接被清掉，没有一句话说它没发出去，也没留给我复制；
「任务已结束」只说了不能聊，没说想继续追问该去哪里（新发起一个想法）。
