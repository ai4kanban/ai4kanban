# 分享审核链接并管理谁能打开

## Setup

- 本地云端栈（见 README「如何运行取证」），以任务发起人 alice 登录；任务「给登录页加上「记住我」」
  在等审核，已有一条「仅受邀的人」的审核链接，carol@example.com 已受邀。

## Steps

1. 打开审核链接，点右上角「分享」。
   预期：弹出面板，顶部是链接和「复制链接」，「谁能打开」为「仅受邀的人」，列出已受邀的
   carol，底部写到期日和「撤销链接」。
   证据：[01-share-panel.png](01-share-panel.png)
2. 在「受邀的人」里输入 `erin@example.com` 回车。
   预期：erin 加进列表。邮件发不出去时提示改为手动把链接发给她（本地栈没有邮件服务，
   所以这里一定出现）。
   证据：[02-invite.png](02-invite.png)
3. 把「谁能打开」改成「任何拿到链接的人」。
   预期：即时保存，下方出现「无需登录，只能查看正文和预览。链接外传，内容即公开。」
   证据：[03-anyone.png](03-anyone.png)
4. 退出登录后再打开同一链接。
   预期：不用登录直接看到卡片正文，右上只有语言切换，没有评论、执行等操作。
   证据：[04-visitor.png](04-visitor.png)
5. 以 alice 回到页面，点「分享」→「撤销链接」。
   预期：面板底部改为「撤销后，链接立即失效。」与「取消」「撤销链接」二次确认。
   证据：[05-revoke-ask.png](05-revoke-ask.png)
6. 确认撤销。
   预期：面板显示「链接已撤销」与「生成新链接」。
   证据：[06-revoked.png](06-revoked.png)
7. 未登录再打开这条链接。
   预期：「链接已失效」页。
   证据：[07-dead-link.png](07-dead-link.png)

## Feedback

一个面板管完链接、权限、受邀人和撤销，改动即时生效，撤销有二次确认，整体顺手。摩擦点：
「生成新链接」之外没有续期，到期只能换链接再发一遍；访客模式只剩正文，连「这是谁发来的、
怎么参与」的提示都没有，第一次收到链接的人可能不知道自己只能看。
