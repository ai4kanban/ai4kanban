# 分享审核链接并管理谁能打开

## Setup

- 本地云端栈（见 README「如何运行取证」），以任务发起人 alice 登录；任务「给登录页加上「记住我」」
  在等审核，carol@example.com 已受邀，这个浏览器还没存过链接。另有一条 alice 在别的浏览器生成的链接。

## Steps

1. 打开任务页，点右上「分享」。
   预期：弹出面板，顶部是 `/s/<链接码>` 的地址和「复制链接」，「谁能打开」为「仅受邀的人」，列出 carol，
   底部写到期日和「撤销链接」。
   证据：[01-share-panel.png](01-share-panel.png)
2. 在「受邀的人」里输入 `erin@example.com` 回车。
   预期：erin 加进列表。邮件发不出去时提示改为手动发链接（本地栈没有邮件服务，所以这里一定出现）。
   证据：[02-invite.png](02-invite.png)
3. 把「谁能打开」改成「任何拿到链接的人」。
   预期：即时保存，下方出现「无需登录，只能查看正文和预览。链接外传，内容即公开。」
   证据：[03-anyone.png](03-anyone.png)
4. 退出登录后打开这条链接。
   预期：不用登录直接看到卡片正文，右上是语言切换和「登录」；没有评论、分享、移除、执行和「和 AI 讨论」。
   证据：[04-visitor.png](04-visitor.png)
5. 把语言切到 English。
   预期：页面换成英文，仍是只读。
   证据：[05-visitor-english.png](05-visitor-english.png)
6. 以 alice 回到任务页；这个浏览器存的还是旧地址 `https://review.wildcrane.ai/<链接码>`，点「分享」。
   预期：面板显示 `/s/<链接码>`，不显示旧域名。
   证据：[06-old-address.png](06-old-address.png)
7. 点「撤销链接」。
   预期：面板底部改为「撤销后，链接立即失效。」与「取消」「撤销链接」二次确认。
   证据：[07-revoke-ask.png](07-revoke-ask.png)
8. 确认撤销。
   预期：面板显示「链接已撤销」与「生成新链接」。
   证据：[08-revoked.png](08-revoked.png)
9. 未登录再打开这条链接。
   预期：「链接已失效」页。
   证据：[09-dead-link.png](09-dead-link.png)
10. 换一个没存过链接的浏览器，以 alice 打开别处生成的那条链接，点「分享」。
    预期：被带到任务页，面板管的就是刚打开的这条链接，撤销后它失效。
    证据：[10-other-browser.png](10-other-browser.png)（产品没通过：面板新建了另一条链接，撤销的也是新的，打开的那条
    仍然有效，已报待筛选）

## Feedback

一个面板管完链接、权限、受邀人和撤销，改动即时生效。摩擦点：面板只认这个浏览器存的那条链接，换台电脑就管不到
已发出去的链接，这是最要紧的问题；「生成新链接」之外没有续期；工作区成员在任务页看不到「分享」，只有所有者能分享；
访客页没有「这是谁发来的、怎么参与」的提示。
