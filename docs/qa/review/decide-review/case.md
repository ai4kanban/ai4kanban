# 确认或移除等审核的任务

## Setup

- 本地云端栈（见 README「如何运行取证」），以发起人 alice 登录。两个 Coding 任务在等第一次
  审核，各有一条审核链接。本地没有 Runner，任务进入待审核是直接改库造的。

## Steps

1. 打开第一个任务的审核链接。
   预期：标题下是「待审核」，右侧有移除图标和「执行」，右下有「和 AI 讨论」。
   证据：[01-owner-open.png](01-owner-open.png)
2. 点「执行」。
   预期：状态变为「已确认」，「执行」消失；任务回到排队等构建。
   证据：[02-approved.png](02-approved.png)
3. 打开第二个任务的审核链接。
   预期：同样是「待审核」，有移除和「执行」。
   证据：[03-second-task.png](03-second-task.png)
4. 点移除图标。
   预期：弹出「移除这个任务？」，说明不能恢复、会腾出套餐名额，可选填原因，「不移除」「移除」。
   证据：[04-remove-ask.png](04-remove-ask.png)
5. 填原因后点「移除」。
   预期：状态变为「已移除」，移除和「执行」都消失；任务取消并记下原因。
   证据：[05-removed.png](05-removed.png)

## Feedback

确认只要一下，移除有二次确认并能留原因，状态标签即时更新。摩擦点：「执行」不说明点下去
会发生什么（构建会开始、会占用 Runner），也没有撤回；移除只是一个无文字的图标，紧挨主按钮，
不易发现；想打回修改时，没有待决问题的卡片上找不到入口，只能去「和 AI 讨论」或评论里说。
