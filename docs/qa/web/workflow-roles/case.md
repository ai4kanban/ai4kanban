# 查看工作流里有哪些角色

## Setup

- 本地云端栈（见 README「如何运行取证」），alice 已登录，项目 `demo-app`。

## Steps

1. 打开项目设置，选「工作流」。
   预期：中间是当前工作流（「博客文章」）的各道批准，每道里的角色只有头像和名字，没有被截断的
   描述，每行约 26px；最后是「通过后归档卡片」。
   证据：[01-roles.png](01-roles.png)
2. 点一个角色（「简报与大纲」）。
   预期：右侧显示它的名字和完整说明「写博客文章的简报和大纲，正文按它来写。」，以及「你的要求」。
   证据：[02-role-open.png](02-role-open.png)

## Feedback

列表去掉半句描述后干净多了，一屏就能看清整条流程。代价是只看名字猜不出角色做什么，要逐个点开；
「第 1 道批准」这种叫法也不说明谁来批准。页面首次打开要十几秒才出内容（本地开发服务器）。
