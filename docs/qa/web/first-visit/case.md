# 第一次打开 WildCrane Web

## Setup

- 本地云端栈（见 README「如何运行取证」），alice 已有一台连上的电脑（假 Runner，Claude Code
  已登录）。浏览器是干净的，没有任何本地记录。

## Steps

1. 打开 Web 首页。
   预期：「登录 WildCrane」，可「用 GitHub 登录」或发送邮箱验证码。
   证据：[01-sign-in.png](01-sign-in.png)
2. 以 alice 登录（取证时直接写入登录态）。
   预期：先出现「帮助改进 WildCrane」，「共享匿名使用情况」默认开启，按钮「继续」。
   证据：[02-usage-notice.png](02-usage-notice.png)
3. 点「继续」。
   预期：弹出「功能导览」第 1 页「执行之前，先看预览」，底部有「跳过」、5 个页点和「下一步」。
   证据：[03-tour.png](03-tour.png)
4. 点「下一步」。
   预期：第 2 页「专注主线，支线交给 Agent」，多出「上一步」。
   证据：[04-tour-next.png](04-tour-next.png)
5. 点「跳过」。
   预期：导览关闭，首页是「接下来该做什么？」和输入框；电脑已就绪，所以不出现准备 AI 工具的
   引导。刷新后导览不再出现。
   证据：[05-home.png](05-home.png)

## Feedback

三屏依次出现，每屏一件事，很快就到首页。导览的插图和文案有说服力，但叠着几张卡片的样式让
人以为还有别的弹窗。首页一句「接下来该做什么？」加一个输入框，起步门槛很低；不过顶栏写着
「选择项目」，看不出不选项目时任务会进到哪里。
