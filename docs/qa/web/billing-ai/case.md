# 在设置里查看账单和 AI 能力

## Setup

- 本地云端栈（见 README「如何运行取证」），alice 已登录。本地 Worker 给了占位的 Creem 设置，
  账单才能读出来；第 2 步前用 `POST /v1/billing/trial` 让 alice 开始 Pro 试用。

## Steps

1. 点右上角齿轮打开「设置」，选「账单」。
   预期：免费版一行带「升级到 Pro」；下面是「同时运行的任务」「存储」；再往下是「AI 能力」分组，
   每项右侧写积分单价：图像生成「经济 230 · 标准 320 · 高质 769 积分 / 张」、语音合成「标准 160 ·
   高质 270 积分 / 分钟」、音乐生成「160 积分 / 首」，末尾一句「Agent 在任务中按需使用，消耗 Pro 套餐
   的 AI 积分。」。
   证据：[01-free.png](01-free.png)
2. 开始试用后再看「账单」。
   预期：顶部是「Pro 试用中」和剩余天数，多出「AI 积分 1,000 / 1,000」一行；「AI 能力」分组不变。
   证据：[02-pro.png](02-pro.png)
3. 在手机宽度（390px）从底部「更多」→「设置」→「账单」进入。
   预期：同样的内容排成单列，说明文字自动换行，页面不横向滚动。
   证据：[03-phone.png](03-phone.png)
4. 把界面切成 English 再看。
   预期：分组标题「AI CAPABILITIES」，单价写成「Economy 230 · Standard 320 · Premium 769」「credits per image」，
   语音「credits per minute」，音乐「credits per track」。
   证据：[04-english.png](04-english.png)

## Feedback

终于能在一个地方看到积分能买到什么、各花多少，三项能力一行一个单价，扫一眼就懂，也能换算让 Agent 配一分钟音
要多少积分。摩擦点：单价只有积分，不知道折合多少钱，也看不出 1,000 积分够配几分钟（约 3–6 分钟）；免费版
也列出这几项，却只在末尾小字说要 Pro 积分，容易误以为免费就能用；分组是纯展示，看起来像能点开的设置项。
