# 跳过方案直接构建一个想法

## Setup

- 本地云端栈（见 README「如何运行取证」），alice 已登录，电脑「QA Mac」（假 Runner）在线。
  Agent 的回复和构建结果由假 Runner 写入。
- 第 5 步起在项目 `demo-app` 里：那里已有一个直接构建、并在任务页聊过的任务
  「任务列表支持按优先级排序」，它在左栏「任务」下。

## Steps

1. 在首页写「任务列表加一个导出 CSV 的按钮」并发送，等 Agent 回复。
   预期：右侧出现想法卡「任务列表导出 CSV」，带「直接构建」和「创建任务」；左栏「对话」下有这条。
   证据：[01-idea.png](01-idea.png)
2. 点「直接构建」。
   预期：进入任务页「#1 任务列表导出 CSV」，「排队中」，有「来自对话」链接；左栏不出现这个任务，
   原来的对话也从左栏移走。
   证据：[02-built.png](02-built.png)
3. 点「看板」。
   预期：`#1` 在「排队中」一列。
   证据：[03-board.png](03-board.png)
4. 构建完成后，在任务页打开对话，发「导出时把日期列也带上」。
   预期：说明任务已结束、不能再对它发消息（Cloud 的回答是「This task has finished.」），或者干脆
   不给输入框。
   实际：输入框照常可用，发出后只提示「AI 没能回复，请重试。」，重试也一样。
   证据：[04-done.png](04-done.png)、[05-sent.png](05-sent.png)
5. 在 `demo-app` 的收件箱里，鼠标移到「看板卡片显示负责人头像」上。
   预期：行尾出现「转成任务」「直接构建」「忽略」三个图标，悬停「直接构建」有提示。
   证据：[06-inbox.png](06-inbox.png)
6. 点「直接构建」。
   预期：进入任务页「#2 看板卡片显示负责人头像」；左栏「任务」下仍只有之前那一条，没有 `#2`。
   证据：[07-inbox-built.png](07-inbox-built.png)
7. 构建停下来问「没有负责人的卡片显示什么？」，打开 `#2`。
   预期：对话框自动弹出，带这个问题和两个选项；左栏仍没有 `#2`。
   证据：[08-asked.png](08-asked.png)
8. 在对话里发「头像能不能也显示在任务页标题旁？」。
   预期：`#2` 立刻出现在左栏「任务」最上面，带转圈；对话显示「正在回复…」。
   证据：[09-back-on-rail.png](09-back-on-rail.png)

## Feedback

左栏终于只放还要聊的东西：直接构建的任务不来占位，一旦我在任务页开口，它又自己回来，规则不用
学就懂；想法对话和收件箱两处的「直接构建」表现一致。摩擦点：第 4 步——任务结束后输入框还在，
发了却只说「AI 没能回复」，像是出了故障，用户会一直重试；收件箱的三个操作只在悬停时出现，而且
是无文字图标；直接构建的任务正文把 `## Done when` 原样显示成文字，没有排版。
