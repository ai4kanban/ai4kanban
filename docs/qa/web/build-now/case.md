# 跳过方案直接构建一个想法

## Setup

- 本地云端栈（见 README「如何运行取证」），alice 已登录，电脑「QA Mac」（假 Runner）在线。
  Agent 的回复和构建结果由假 Runner 写入。
- 前 5 步在项目 `shop-app`，已有 `#1`–`#3`。
- 第 6 步起在项目 `demo-app`：那里已有一个直接构建、并在任务页聊过的任务
  `#9`「任务列表支持按优先级排序」，它在左栏「任务」下。

## Steps

1. 在首页写「任务列表加一个导出 CSV 的按钮」并发送，等 Agent 回复。
   预期：右侧出现想法卡「任务列表导出 CSV」，带「直接构建」和「细化想法」；左栏「对话」下有这条。
   证据：[01-idea.png](01-idea.png)
2. 点「直接构建」。
   预期：不经过创建中，直接进入任务页「#4 任务列表导出 CSV」，「排队中」，有「创建者 Alice」和「来自对话」链接；
   左栏不出现这个任务，原来的对话也从左栏移走。
   证据：[02-built.png](02-built.png)
3. 点「看板」。
   预期：`#4` 在「排队中」一列，是普通卡片，不是灰底的「创建中」。
   证据：[03-board.png](03-board.png)
4. Runner 领走构建。
   预期：`#4` 移到「进行中」，标「执行中」——跳过了细化，一开始就是执行。
   证据：[04-building.png](04-building.png)
5. 构建完成后，在任务页打开对话，试着输入。
   预期：对话顶部是收起的「来自对话 · 2 条」，下面是构建回复，不重复卡片正文；输入框置灰，占位文字
   「任务已结束」，打不进字，发送按钮不可点。
   证据：[05-done.png](05-done.png)
6. 在 `demo-app` 的待筛选里，鼠标移到「看板卡片显示负责人头像」上，再移到中间的图标上。
   预期：行尾出现「细化想法」「直接构建」「忽略」三个图标，悬停的那个提示「直接构建」。
   证据：[06-inbox.png](06-inbox.png)
7. 点「直接构建」。
   预期：进入任务页「#10 看板卡片显示负责人头像」；左栏「任务」下仍只有 `#9`。
   证据：[07-inbox-built.png](07-inbox-built.png)
8. 构建停下来问「没有负责人的卡片显示什么？」，打开 `#10`。
   预期：对话框自动弹出，带这个问题和两个选项；左栏仍没有 `#10`。
   证据：[08-asked.png](08-asked.png)
9. 对话读完后发「头像能不能也显示在任务页标题旁？」。
   预期：`#10` 立刻出现在左栏「任务」最上面；对话显示「正在回复…」。
   证据：[09-back-on-rail.png](09-back-on-rail.png)（气泡里这句重复两遍是取证造成的：上次没发出去的草稿留在框里，脚本又输入了一次）

## Feedback

左栏只放还要聊的东西：直接构建的任务不来占位，一旦我在任务页开口，它又自己回来。任务结束后输入框
直接写「任务已结束」，一眼就懂；折叠条把想法讨论收起来，不再把卡片正文重复一遍。摩擦点：待筛选的三个操作
只在悬停时出现，而且是无文字图标；直接构建排队时运行日志上没有「丢弃这次执行」，要撤只能移除整个任务；
任务正文把 `## Done when` 原样显示成文字，没有排版；刚打开已结束的任务时运行日志一闪「还没有输出」；
第 8 步打开页面的头几秒发送不可点，输入的话停在框里，容易以为发出去了；已结束的任务想追问，只能自己去
发起新想法，页面没有给入口。
