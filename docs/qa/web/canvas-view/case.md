# 在任务页用画布并排看预览

## Setup

- 本地云端栈（见 README「如何运行取证」），项目 `demo-app` 里 `#7`「结账页改版」待审核，卡片有「竞品调研」
  「界面设计」「接口文档」三个 agent 分段，共三张预览图。`#5`「购物车支持批量删除」没有 agent 分段。
- 窗口 1440×900；第 8 步 390px 手机；第 10、11 步 1024×768 平板，触摸由 CDP 模拟。

## Steps

1. 打开 `#7`。
   预期：标题行有「文档 / 画布」切换，默认「文档」，产出竖排。
   证据：[01-document.png](01-document.png)
2. 点「画布」。
   预期：正文留在上方，下面每个 agent 一组、从左到右排开，组名带条数，按 100% 显示；不再显示
   「Agent 的分析」折叠栏。
   证据：[02-canvas.png](02-canvas.png)
3. 把页面滚到画布。
   预期：画布贴到顶栏下方，高度等于一整屏；左下角是缩放条。
   证据：[03-canvas-full-screen.png](03-canvas-full-screen.png)
4. 在画布上滚动滚轮，再用鼠标拖动，再按住 Ctrl 滚动。
   预期：画布没贴顶时滚轮滚页面，贴顶后才平移画布；向上时画布先回到顶，再滚页面。拖动平移；
   Ctrl+滚轮缩放。
   证据：[04-wheel.log](04-wheel.log)、[04-panned.png](04-panned.png)
5. 点缩放条的「适应全部」。
   预期：三组全部进入视野，缩放约 66%。
   证据：[05-fit-all.png](05-fit-all.png)
6. 打开「和 AI 讨论」，拖动画布，再单击画布空白处。
   预期：拖动时对话留在原处；单击后对话收起，和文档视图一样。
   证据：[06-chat-stays.png](06-chat-stays.png)、[04-wheel.log](04-wheel.log)
7. 点「文档」，再打开 `#5`。
   预期：回到竖排，折叠栏回来；`#5` 没有分段，标题行不出现切换。
   证据：[07-back-to-document.png](07-back-to-document.png)、[08-no-sections.png](08-no-sections.png)
8. 在手机宽度打开 `#7`。
   预期：没有切换，只有文档视图。
   证据：[09-phone.png](09-phone.png)
9. 卡片多一张资源里有、正文没引用的预览，再看画布。
   预期：最右多一组「其他产出」。
   证据：[10-other-previews.png](10-other-previews.png)
10. 在平板宽度打开 `#7` 的画布。
    预期：画布照常显示，100%。
    证据：[11-tablet.png](11-tablet.png)
11. 从文字块上两指张开，抬起一指接着移动，再单指拖动，最后两指捏拢。
    预期：缩放随两指距离变化（到 200%），以两指中点为锚点，整页不缩放；抬起一指后剩下的手指接着
    平移；捏拢最低到 40%。
    证据：[12-pinch.log](12-pinch.log)、[12-pinched.png](12-pinched.png)、[13-panned.png](13-panned.png)
12. 把界面切成 English。
    预期：切换写「Document / Canvas」，agent 组名也译成英文。
    证据：[14-english.png](14-english.png)

未取证：真实 iPad Safari 的整页缩放（只有 Chrome 触摸模拟，`visualViewport.scale` 全程为 1）。

## Feedback

要并排比较时画布很顺手，三组产出一屏看完，再也不用一路往下滚。切换也不打断审核：评论、执行、AI 对话都
原样在。摩擦点：打开时贴在正文下方，要先滚一段才能用；滚轮时而滚页面、时而平移，初次用会愣一下；组与组
高度差很大时，下半屏全是空的点阵；组里的预览还带自己的缩放条，和左下角的总缩放并存，容易点错；平板截图
里第一张预览有一段时间是灰块，加载慢时看不出在读。
