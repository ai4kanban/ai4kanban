# 在待筛选看一条建议的详情

## Setup

- 本地云端栈（见 README「如何运行取证」），项目 `demo-app` 的待筛选有三条：质检员提的「结账页记住最近用过的
  优惠码」、竞品调研提的「订单列表支持按金额筛选」、接口直接添加的「手工记下的旧想法：发票抬头模板」。
- 窗口 1440×860，从没调过宽度。

## Steps

1. 点第一条。
   预期：详情栏约占窗口 40%（576px），标题下一行「提出者 · 质检员」带图标。
   证据：[01-qa-agent.png](01-qa-agent.png)、[06-width.log](06-width.log)
2. 点第二条。
   预期：「提出者」换成它自己的 agent。
   证据：[02-other-agent.png](02-other-agent.png)
3. 点第三条。
   预期：没有「提出者」这一行，也不写「未知」。
   证据：[03-no-agent.png](03-no-agent.png)
4. 把详情栏左边界拖到最左，再拖到最右。
   预期：最宽 720px，列表不被挤没；最窄 360px。
   证据：[04-widest.png](04-widest.png)、[05-narrowest.png](05-narrowest.png)
5. 拖到 640px，刷新后再打开一条。
   预期：仍是 640px。
   证据：[06-after-reload.png](06-after-reload.png)
6. 双击边界。
   预期：回到默认 576px。
   证据：[06-width.log](06-width.log)
7. 手机宽度打开一条。
   预期：详情占满屏，没有拖动边界，「提出者」同样显示。
   证据：[07-phone.png](07-phone.png)

## Feedback

默认宽度一下让长说明好读了，多数内容不用滚；「提出者」让我一眼分清这是质检发现还是竞品建议，决定时更有
底。摩擦点：边界平时看不出来，只有鼠标碰上去才有提示，不知道能拖；同一来源下多条建议，只有点开才看得出
谁提的，列表里分不开；只有一个来源时列表行的来源列空着，看着像漏了内容。
