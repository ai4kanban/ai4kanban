# 在任务页查看卡片里的预览

## Setup

- 本地云端栈（见 README「如何运行取证」），项目 `demo-app` 里有待审核的任务 `#1`「结账页支持优惠码」。
- 卡片「界面」一节有两个预览：「结账页」是已上传的截图；「优惠码无效」在卡片里写了，但从没上传。
- 取证时用 CDP 拦截读取预览的请求：第 1 步把每个请求拖慢 6 秒，第 3 步让它们以断网失败。

## Steps

1. 打开 `#1`，网络很慢。
   预期：「结账页」先显示灰底占位块，直到截图到达；全程不出现「预览缺失」或「文件不存在」。
   「优惠码无效」直接显示「预览缺失」。
   证据：[01-loading.png](01-loading.png)、[01-loading.log](01-loading.log)
2. 等加载完成。
   预期：「结账页」显示截图，带展开和更多操作按钮。
   证据：[02-loaded.png](02-loaded.png)
3. 断网后重新打开 `#1`。
   预期：「结账页」显示「预览加载失败，请刷新后重试。」，而不是「预览缺失」；「优惠码无效」仍是
   「预览缺失」。
   证据：[03-failed.png](03-failed.png)

## Feedback

三种情况终于分得清：慢就是占位，断网说加载失败，只有真没上传才说缺失，不会再让人以为文件丢了。
摩擦点：占位块是静止的灰底加图标，慢网下 20 秒都没动静，看不出还在加载；「预览缺失：…未随这次审核
提交」对不懂审核流程的人很难懂；卡片有待答问题时，每次打开对话框都会自动弹出盖住半边预览，得先手动关掉。
