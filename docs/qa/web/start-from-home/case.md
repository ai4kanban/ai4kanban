# 从首页一句话开始一个任务

## Setup

- 接 [第一次打开](../first-visit/case.md) 的状态：alice 已登录，电脑「QA Mac」在线，项目
  `demo-app` 已放到这台电脑上。Agent 的回复由假 Runner 写入（真实环境由 Claude Code 生成）。

## Steps

1. 在首页输入框写「给设置页加一个深色模式开关」。
   预期：输入框下方是「自动选择」工作流和「全局默认」运行环境。
   证据：[01-typed.png](01-typed.png)
2. 点发送。
   预期：进入新对话，左栏「对话」下出现这条，带转圈；正文显示「正在回复…」。
   证据：[02-sent.png](02-sent.png)
3. 等 Agent 回复。
   预期：回复显示在对话里并标出用时；右侧出现想法卡「设置页加深色模式开关」，带结果说明、
   工作流「软件开发」、「直接构建」和「细化想法」；左栏这条换成想法标题并亮起红点。
   证据：[03-reply.png](03-reply.png)
4. 鼠标移到想法卡右上角的垃圾桶上。
   预期：按钮下方出现完整的提示「丢弃」，不被面板裁掉。
   证据：[04-discard-tip.png](04-discard-tip.png)
5. 点「细化想法」。
   预期：回到项目「通用」的看板，`#1` 在「排队中」一列，是灰底的「创建中」卡片，点不开；左栏既没有「任务」
   分组，也没有这条对话，要等 [卡片写好](../card-being-created/case.md)。
   证据：[05-task-created.png](05-task-created.png)

## Feedback

从一句话到一个任务只要发送和一次点击，Agent 先把想法写成带验收的卡片再动手，很踏实。「直接构建 /
细化想法」这对名字说清了区别——先不先出方案，不用再猜。摩擦点：点完被送回看板，刚才的对话从左栏消失，
第一次用会慌，要在看板上认出那张灰卡片才知道事情在进行；对话框的占位文字还写着「说『做吧』创建任务」，
和按钮的新叫法对不上；没选项目时任务落进「通用」，事先没有任何提示。
