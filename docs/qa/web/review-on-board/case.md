# 在看板上找到待审核的任务并开始执行

## Setup

- 接 [从首页开始一个任务](../start-from-home/case.md)：任务 `#1` 的第一步已由假 Runner 完成，
  写好卡片（目标、方案、验收），任务等待审核。

## Steps

1. 在左栏点「看板」。
   预期：看板分「等你处理」「进行中」「排队中」「搁置」几列；`#1` 在「等你处理」，标「待审核」。
   证据：[01-board.png](01-board.png)
2. 点这张卡。
   预期：进入任务页，标「待审核」；运行日志显示「已完成 · 30 秒 · 约 $0.42」；下面是卡片正文；
   右上有「评论」「分享」、移除图标和「执行」。
   证据：[02-task-page.png](02-task-page.png)
3. 点「执行」。
   预期：状态变为「排队中」，「执行」消失，左栏红点熄灭；构建交给这台电脑。
   证据：[03-run.png](03-run.png)
4. 在手机宽度（390px）打开任务页，点底部「看板」。
   预期：看板一屏一列，先显示「等你处理 0 个」，右上 4 个页点；底部是「看板」「对话」「更多」。
   证据：[04-phone-board.png](04-phone-board.png)
5. 点第 3 个页点（转到「排队中」）。
   预期：滑到「排队中 1 个」，`#1` 在这一列。
   证据：[05-phone-column.png](05-phone-column.png)

## Feedback

看板的「等你处理」把要我动手的事放在最前，一眼就知道该看哪张。任务页信息完整，费用和用时都在
运行日志一行里。摩擦点：「执行」不说明它就是批准方案、会开始构建，也没有撤回；审核提出的问题
「批准这份方案？」在页面上看不到。手机上一屏一列很清楚，只是页点很小，不看标题难知道其余列是什么。
取证时用无头 Chrome 直接打开任务链接，正文骨架屏常要十几秒才换成正文（刷新只需约 2 秒），
本地开发服务器较慢，未能确认线上是否同样如此。
