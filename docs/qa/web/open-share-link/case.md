# 工作区成员打开分享链接，直接到任务页

## Setup

- 本地云端栈（见 README「如何运行取证」），`web/` 用 `vite build` 加 `vite preview`。工作区 Acme 里 alice 是
  所有者、bob 是成员；任务 `#1` 在等审核，有一条「仅受邀的人」的链接，carol@example.com 是受邀客人，不是成员。
- alice 已有连上的电脑；第 3 步时 bob 还没有，第 4 步起有。

## Steps

1. alice 已登录，从首页打开链接。
   预期：地址换成 `/tasks/DA-1`，页面是任务页，有「评论」「分享」、移除和「执行」。
   证据：[01-owner.png](01-owner.png)
2. 按返回键。
   预期：回到首页，不回到链接。
   证据：[02-back.png](02-back.png)
3. bob 已登录，还没连电脑，打开链接。
   预期：地址换成任务页，看到任务。
   证据：[03-member-no-computer.png](03-member-no-computer.png)（未通过：地址换了，页面却是「连接你的电脑」，
   没有跳过入口，已提交待筛选）
4. bob 连上电脑后再打开链接。
   预期：到任务页，工作区自动切到 Acme；有「评论」和「执行」，没有所有者才有的「分享」。
   证据：[04-member.png](04-member.png)
5. 未登录打开链接。
   预期：「你收到一个审核邀请」，可用 GitHub 或邮箱验证码登录。
   证据：[05-sign-in.png](05-sign-in.png)
6. 填 bob 的邮箱，点「发送验证码」。
   预期：「输入验证码」，写明发到了 bob@example.com。
   证据：[06-code.png](06-code.png)
7. 输入验证码。
   预期：不用再操作，直接到任务页。GitHub 登录未取证：替身没有这条回调。
   证据：[07-after-sign-in.png](07-after-sign-in.png)
8. 在任务页退出登录，再打开链接。
   预期：又回到登录邀请，两边是同一个登录态。
   证据：[08-signed-out.png](08-signed-out.png)
9. carol 登录后打开链接。
   预期：留在 `/s/<链接码>` 的审核页，有「评论」，没有「执行」「分享」和移除。
   证据：[09-guest.png](09-guest.png)

## Feedback

已连电脑的成员很顺：一跳就到，返回键也干净，少登录一次。最大的问题在没连电脑的成员：只想看一眼的同事被要求先装
桌面端，而审核页上已没有成员入口，这个人看不到任务。登录邀请写的是「审核邀请」，成员登录后却到了任务页，文案和
去向对不上。链接页登录后没有过渡提示，页面直接换掉。
