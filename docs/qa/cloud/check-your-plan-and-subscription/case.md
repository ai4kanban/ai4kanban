# 在 Cloud 看板网站查看套餐并购买 Pro

## Setup

- **账号**：已在 Cloud 看板网站登录（见 [登录](../sign-in-to-the-hosted-board/case.md)），免费版。
- **本次证据的来源**：同登录用例，网站（`cloud-ui`）在本地实跑；[stand-in.mjs](../sign-in-to-the-hosted-board/stand-in.mjs) 也顶替 Creem 的结账页和客户门户，不发生任何真实付款。定价页的「购买 Pro」只是指向网站的 `/billing/checkout?period=…`，第 6 步直接打开这个地址，没有构建官网。

## Steps

1. 点头像 → 「设置」。
   设置页显示账号、「套餐：免费版」、按月 $15 / 按年 $120（省 33%，默认选中按年）和「购买 Pro」，下面是「功能导览」的「重新查看」。
   ![](01-free-plan.png)

2. 用 Tab 键走到周期选项，按左方向键。
   选中改为「按月」，这一档的边框变成墨色细框（未聚焦时是橙红边），没有橙红外框。
   ![](02-keyboard-focus.png)

3. 选「按月」，按「购买 Pro」。
   浏览器被送到 Creem 的结账页，带着所选的周期。
   [03-get-pro.log](03-get-pro.log)

4. 在结账页付款。
   回到设置页，网站先向 Cloud 确认订阅，再去掉地址里的参数；套餐显示「Pro · 按月」「2027年10月4日自动续费」和「管理账单」。
   [04-paid.log](04-paid.log)
   ![](04-pro-plan.png)

5. 按「管理账单」。
   浏览器被送到 Creem 的客户门户。
   [05-manage.log](05-manage.log)

6. 已是 Pro，再在定价页按「购买 Pro」。
   浏览器回到设置页，套餐卡片顶部是绿色提示「你已是 Pro，无需再次购买。」，套餐和续费日期不变，不会再走一次结账。
   [06-already-pro.log](06-already-pro.log)
   ![](06-already-pro.png)

## Feedback

- **价格和周期一眼可见**：两档并排、年付标出省多少，按钮只有一个。
- **键盘也能选周期**：Tab 进来、方向键切换，聚焦的一档换成墨色框；但它和「已选中」的底色叠在一起，第一次用的人未必分得清哪个是聚焦、哪个是选中。
- **付完款马上看到 Pro**：回到设置页就是新套餐和续费日期，不需要刷新或等待。
- **重复购买有了交代**：以前已是 Pro 再点「购买 Pro」会被静默带回设置页，像按钮坏了；现在一句「无需再次购买」说清楚了。只是地址里留着 `?checkout=subscribed`，提示要离开这个地址才会消失。
- **从定价页选的周期被忽略**：已订阅的人在定价页选了「按年」，回来看到的仍是「按月」，提示里也没说想换周期该去「管理账单」。
- **「管理账单」去的是另一个网站**：没有任何提示就离开了 AI4Kanban，第一次点的人可能不确定那是不是官方页面。
- **未在真实 Cloud 上验证**：结账页、门户和 Cloud 的确认都是替身，真实的 Creem 页面、价格和付款失败没有走过。
