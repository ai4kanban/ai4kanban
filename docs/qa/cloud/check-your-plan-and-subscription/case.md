# 在 Cloud 看板网站查看套餐并购买 Pro

## Setup

- **账号**：已在 Cloud 看板网站登录（见 [登录](../sign-in-to-the-hosted-board/case.md)），免费版。
- **本次证据的来源**：同登录用例，网站在本地实跑；[stand-in.mjs](../sign-in-to-the-hosted-board/stand-in.mjs) 也顶替 Creem 的结账页和客户门户（一个只有「Pay」链接的页面），不发生任何真实付款。

## Steps

1. 点头像 → 「设置」。
   设置页显示账号、「套餐：免费版」、按月 $15 / 按年 $120（省 33%，默认选中按年）和「购买 Pro」，下面是「功能导览」的「重新查看」。
   ![](01-free-plan.png)

2. 选「按月」，按「购买 Pro」。
   浏览器被送到 Creem 的结账页，带着所选的周期。
   [02-get-pro.log](02-get-pro.log)

3. 在结账页付款。
   回到设置页，网站先向 Cloud 确认订阅，再去掉地址里的参数；套餐显示「Pro · 按月」「2027年10月4日自动续费」和「管理账单」。
   [03-paid.log](03-paid.log)
   ![](03-pro-plan.png)

4. 按「管理账单」。
   浏览器被送到 Creem 的客户门户。
   [04-manage.log](04-manage.log)

## Feedback

- **价格和周期一眼可见**：两档并排、年付标出省多少，按钮只有一个。
- **付完款马上看到 Pro**：回到设置页就是新套餐和续费日期，不需要刷新或等待。
- **「管理账单」去的是另一个网站**：没有任何提示就离开了 AI4Kanban，第一次点的人可能不确定那是不是官方页面。
- **未在真实 Cloud 上验证**：结账页、门户和 Cloud 的确认都是替身，真实的 Creem 页面、价格和失败情形（付款失败、取消订阅）没有走过。
