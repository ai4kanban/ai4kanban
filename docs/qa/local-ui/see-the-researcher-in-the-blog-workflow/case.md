# 在「博客文章」工作流里找到博客研究员，停用再启用它

## Setup

- **看板**：任意已装好的看板；本次用的是 [switch-a-card-to-another-workflow/seed.sh](../switch-a-card-to-another-workflow/seed.sh) 建的一次性项目。
- **账号**：本机已登录 Cloud，是 Pro（博客文章是 Pro 工作流）。Cloud 由 [stand-in.mjs](../give-a-copied-video-clone-workflow-a-build-agent/stand-in.mjs) 顶替。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截「配置」窗口。

## Steps

1. 点右上角的「配置」，再点左栏「工作流」，在中间一栏顶上的下拉里选「博客文章」。
   「规划」框里是领头的「博客策划」，「规划助手」下面依次是「博客研究员」和「博客配图」；「执行」框只有「+ 设置 Agent」。
   ![博客文章工作流](01-blog-flow.png)
   [各个框的文字](01-blog-flow.log)

2. 点「博客研究员」。
   右侧标题「博客研究员」，说明「在大纲前调研博客文章角度所依赖的公开事实、现实方案、限制和反例，写作中按需补查。」，右上「停用」；下面是「运行时」和「额外要求」（范围「博客文章 · 规划」）。研究员在列表和右侧头部都是专属角色：胸前一个放在灰色底座上的天蓝地球仪，不再是首字母卡片。
   ![博客研究员](02-researcher.png)
   [右侧文字与角色图](02-researcher.log)

3. 点「停用」，再点「启用」。
   停用后研究员移到规划框底部的「已停用（1）」下，按钮变成「启用」；再点「启用」，它回到「博客策划」和「博客配图」之间。
   ![停用之后](03-disabled.png)
   [规划框前后](03-disabled.log)

## Feedback

- **新角色好找**：研究员就排在博客配图前面，说明一句话讲清它在大纲前做什么。
- **形象补齐了**：研究员有了地球仪，和策划、配图站在一列里不再像没做完；但 26px 下地球仪只是一小团蓝，要点开才认得出。
- **停用的后果不知道**：停用后策划会不会照常写、文章会不会少了依据，界面上没有任何说明。
- **没有跑到的**：真实的研究运行与它写出的 `research.md`、策划读取研究、已有看板升级后自动加入研究员、英文界面。
