# 在工作流里让一个 Agent 定期运行

## Setup

- **看板**：一个刚用 `akb install` 建好的看板（项目是 git 仓库），删掉 `docs/kanban/setup-checklist.md`，界面语言为中文；工作流是内置的「软件开发」，还没有自建 Agent；看板的界面已经开过一分钟以上（定时器走过一轮）。
- **Agent**：用 [`skill/run-a-workflow-agent-on-a-schedule/stand-in.mjs`](../../skill/run-a-workflow-agent-on-a-schedule/stand-in.mjs) 顶替真实的 Agent（不需要账号），写法见那个用例的 Setup；被定期运行启动时它往 `CHANGELOG.md` 加一行。
- **界面**：这次构建的 `kanban-ui`（`AI4KANBAN_CLI` 指向这次构建出的 `cli/dist/kanban.mjs`），在浏览器里打开看板，窗口 1280×1000。截图只截「配置」或「运行历史」窗口。
- **英文界面（第 15、16 步）**：把界面语言换成 English 后重开同一个看板。

## Steps

1. 点右上角的「配置」，再点左栏的「工作流」。
   「规划」「执行」两个分组框下面是「定期运行」框，没有箭头和上面相连；框里一行小字「到点自己运行，不随卡片」，右端一个「+」，下面已经有一个 Agent：「QA 管理员」。上面「执行后」那一组是空的。
   ![定期运行框里自带 QA 管理员](01-scheduled-box.png)

2. 点「QA 管理员」。
   右侧名称行有两个控件：周期小控件「每天」和「立即运行」，没有「删除」；描述「维护项目的 QA 手册：跟进每张完成的卡片，并为已有功能补写场景。」下面一行「尚未运行 · 首次运行 <明天此刻> 之后」。再往下是「运行时」和一个「额外要求」框，框右上角标着范围「软件开发 · 定期运行」，占位符「例如：沿用产品现有术语。」；没有 `AGENT.md`。
   ![QA 管理员的页面](02-qa-manager.png)

3. 点进「额外要求」框，输入「场景一律用中文写。」，再点框外。
   文字留在框里；`akb workflow schedule coding --json` 里 `qa-manager` 的 `extra` 就是这句话。没有「已保存」之类的提示。
   ![写了额外要求](03-extra-requirements.png)

4. 点「定期运行」框里的「+」。
   「QA 管理员」下面出现新建行：虚线空头像位、已聚焦的名称输入、变淡的「创建」，行下小字「小写字母，用短横线连接」；「+」变成「×」。
   ![定期运行的新建行](04-new-agent-row.png)

5. 输入 `changelog-keeper`，按回车。
   框里多出「Changelog keeper」并被选中，排在「QA 管理员」后面。右侧名称行有三个控件：周期小控件「每天」、「立即运行」、「删除」；描述下面一行「尚未运行 · 首次运行 <明天此刻> 之后」；再往下是它的 `AGENT.md`，里面写着 `hook: schedule`，没有「额外要求」框。
   ![新建的周期 Agent](05-created.png)

6. 点周期小控件「每天」。
   弹出一个窄菜单：「每 6 小时」「每天」（打勾）「每 7 天」「自定义」，分隔线下面最后一项是棕红色的「停用」。
   ![周期菜单](06-cadence-menu.png)

7. 选「每 6 小时」。
   菜单收起，小控件变成「每 6 小时」，下面那行变成「尚未运行 · 首次运行 <六小时后> 之后」。
   ![改成每 6 小时](07-every-6-hours.png)

8. 点「立即运行」。
   按钮变成不可点的「运行中…」；几秒后变回「立即运行」，下面那行变成「上次运行 <刚才> · 下次运行 <六小时后> 之后」。项目里多出一个提交 `changelog-keeper: scheduled run (Coding)`。
   ![运行之后](08-ran.png)

9. 关掉「配置」，点右上角的「运行历史」，再点场景里标着「Changelog keeper / 定期运行」的小人。
   展开的面板标题是「软件开发 · Changelog keeper」，右边写着「定期运行」、开始时间和对勾；正文是这次运行说的话。
   ![运行历史里的这一遍](09-runs.png)

10. 回到「配置 → 工作流」，选中「Changelog keeper」，点周期小控件，选「停用」。
    小控件变成「已停用」，「立即运行」仍是可点的样子；下面那行只剩「上次运行 <时刻>」。左边它移到「QA 管理员」下面的「已停用 (1)」小标题下，头像变灰。
    ![停用之后](10-disabled.png)

11. 点「立即运行」。
    窗口里什么都没变：按钮没有变成「运行中…」，上次运行时间不动，也没有任何提示；没有启动运行，项目里没有新提交。
    ![停用时点立即运行之后的窗口](11-run-now-while-disabled.png)

12. 关掉「配置」。
    看板顶上有一条浅红色的提示「changelog-keeper 已停用，选一个运行周期即可启用。」——它在上一步就出现了，被「配置」窗口挡着。
    ![窗口后面的提示](12-refusal-behind-the-window.png)

13. 回到「配置 → 工作流」，选中「Changelog keeper」，再点小控件。
    菜单里只有四个周期选项，没有一项打勾，也没有「停用」。
    ![停用时的菜单](13-menu-while-disabled.png)

14. 选「每天」。
    Agent 重新启用：小控件是「每天」，下面那行是「上次运行 <时刻> · 下次运行 <明天此刻> 之后」；左边回到「QA 管理员」后面，「已停用」小标题消失。
    ![重新启用](14-enabled-again.png)

15. 用英文界面打开同一页，点「QA manager」。
    框叫「Scheduled」，小字「Runs on its own, not per card」；控件是「Every day」「Run now」，那一行是「Never run · First run after …」，下面的框叫「EXTRA REQUIREMENTS」，范围「Coding · Scheduled」，里面还是第 3 步写的那句话。
    ![英文界面](15-english.png)

16. 点「Every day」。
    菜单是「Every 6 hours」「Every day」（打勾）「Every 7 days」「Custom」，最后一项「Disable」。
    ![英文的周期菜单](16-english-menu.png)

## Feedback

- **不用学新东西**：「+」、新建行、选中后的详情页都和上面两个框一样；周期和停用收在一个小控件里，名称行很干净。
- **停用后的「立即运行」是个哑按钮**：它现在看起来可点，点了却不运行——看板拒绝了，拒绝的那句话还显示在「配置」窗口后面，不关窗口根本看不到（第 11、12 步）。文档写的是「Run now … works while the agent is disabled」，实际不是；以前按钮变淡至少是诚实的。
- **提示里是文件夹名**：那句话叫它「changelog-keeper」，页面上它叫「Changelog keeper」；提示也不会自己消失，关了窗口才第一次看到时已经不知道是哪一步弄出来的。
- **QA 管理员悄悄换了位置**：升级后它从「执行后」消失、出现在最底下的「定期运行」里，界面上没有一句话说明；「执行后」一组现在是空的，只剩一个小标题和「+」，看不出这里原来有过东西。
- **每天一遍的代价界面上不说**：QA 管理员默认开着、每天跑，页面上只有「首次运行 … 之后」；它每遍会真的启动 agent 花钱、没有新完成的卡片也照跑，这些只在文档里写了。
- **刚装好的看板头一分钟没有首次运行时间**：定时器还没走过一轮时，那一行只写「尚未运行」，要等一分钟再开页面才出现「首次运行 … 之后」。
- **「额外要求」存没存看不出来**：失去焦点就保存，但没有任何反馈；框的范围「软件开发 · 定期运行」字很小，和上面两个阶段的同名框只差这几个字。
- **内置和自建的页面不一样**：QA 管理员有「额外要求」、没有 `AGENT.md` 和「删除」，也没有上面内置 Agent 那个「查看规则」；想知道它每遍到底做什么只能去看文档。自建的正好反过来。
- **「定期运行」框在屏幕底下**：1280×1000 的窗口里框里有两个 Agent 时下边框就贴着窗口底，停用后的那一行只露出半截（见第 10 步的截图）；这一列没有任何「下面还有」的提示。
- **「停用」藏得深**：要先想到「停用是一种周期」才会去点周期小控件；上面两个框里的 Agent 是名称行上一个直接的「停用」按钮，同一页两种做法。
- **「之后」读起来别扭**：「首次运行 2026-10-03 21:39 之后」像是话没说完；知道是「不早于这个时刻」的人才读得顺。
- **新建完是个半成品却能马上跑**：`AGENT.md` 还是「Unwritten — …」的英文占位，「立即运行」已经可点；新建后它默认每天运行，明天此刻就会带着占位规则自己跑一遍。
- **运行中看不出进度**：按下后只有「运行中…」，没有去「运行历史」的入口；运行结束后那一行只更新时间，不提这一遍有没有改动、提交是哪个。
- **没有跑到的**：QA 管理员的「立即运行」（会真的启动 agent，这里只有替身，替身不做它的事）；「自定义」周期的编辑区；运行失败后的界面；手机宽度；看板级周期 Agent（「配置 → 看板」）那个同款菜单。
