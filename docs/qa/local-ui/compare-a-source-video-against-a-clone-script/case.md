# 视频复刻还没出片时，逐镜对照原片和复刻脚本

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「复刻发布会片头：逐镜对照原片和脚本」（需要 ffmpeg；脚本打印卡号，本次与另一个场景共用项目，这张是 #3）。脚本生成一段 8 秒的原片和色相偏移的成片、四镜的原片拆解 `breakdown.json`（S1–S4，各 2 秒），和一份删掉了 S3 的三镜复刻脚本 `clone.json`。正文依次是：`<Compare a="source.mp4" b="clone.json" shots="breakdown.json">`「原片与复刻脚本」（`a-label` 原片拆解、`b-label` 复刻脚本），和两段视频的 `<Compare shots="breakdown.json">`「成片对原片」。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截对比块。

## Steps

1. 打开 `/3`，滚到「原片与复刻脚本」。
   上面只有一段原片（标签「原片拆解」，没有喇叭），下面的播放条按拆解切成四段，再下面是「S1 / 4」（只有镜头号）和「0:00 / 0:08」。播放条下分两栏：左「原片拆解」写「黑底上标志从中心淡入」「“ACME”」，右「复刻脚本」写「看板标志从中心淡入」「“AI4Kanban”」；底下一个收起的「制作说明」。
   ![原片和两栏脚本](01-script-compare.png)
   [布局与文字](01-script-layout.log)

2. 点播放条第二段。
   原片跳到 2 秒，变成「S2 / 4」；两栏都换成 S2，各多一行「旁白 …」。
   ![第二镜](02-shot-2.png)
   [两栏文字](02-click-s2.log)

3. 点播放，过 4 秒后暂停。
   两栏跟着原片走：到 4 秒变成「S3 / 4」，左栏是「三张功能卡依次弹出」，右栏是灰底提示「新版没有这一镜」。
   ![新版删掉的一镜](03-missing-shot.png)
   [每 0.5 秒的采样](03-play-into-s3.log)

4. 回到第二段，点「制作说明」。
   两栏同时展开各自的说明：左「标题 64px 粗体；0.4 秒滑入」，右「卡片移动 0.5 秒」。
   ![展开制作说明](04-details-open.png)
   [展开后的文字](04-details.log)

5. 点标题行的「更多」（⋯）。
   两项「下载「原片拆解」」「下载「复刻脚本」」，分别下到 `source.mp4` 和 `clone.json`。
   ![下载菜单](05-download-menu.png)
   [菜单和文件](05-download.log)

6. 滚到「成片对原片」，点播放条第四段。
   两段视频上下排，各带喇叭；播放条按拆解切成四段（各 179 宽），下方没有脚本栏。点第四段两边都跳到 6 秒，显示「S4 / 4」，气泡「S4 · 0:06」。
   ![成片对原片](06-finished-compare.png)
   [分段与跳转](06-finished-compare.log)

## Feedback

- **草稿阶段终于能对着原片审脚本**：原片一播，两栏跟着换镜，不用在两份分镜之间上下滚动找同一镜；删掉的镜头直接写「新版没有这一镜」，一眼就知道。
- **说明默认收起很克制**：两栏只留动作、字幕、旁白，展开一次两边都出来，对照细节也方便。
- **镜头只有编号**：拆解当 `shots` 时进度条下只写「S2 / 4」，不像纯列表那样带镜头名；要靠下面两栏才知道这一镜讲什么。
- **复刻脚本没有自己的时间**：脚本里 S2 写的是 2–4.5 秒，界面完全按原片的 2–4 秒切换，加长的半秒看不出来。
- **左栏标签和视频标签重名**：视频左上角和左栏标题都是「原片拆解」，其实视频是原片、左栏才是拆解；`a-label` 一个名字管了两处。
- **没有跑到的**：复刻脚本里有拆解没有的镜头时的报错、拆解文件写坏时的提示、全屏、窄屏两栏上下排、英文界面。
