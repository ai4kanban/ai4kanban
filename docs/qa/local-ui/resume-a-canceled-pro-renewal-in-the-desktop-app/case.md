# 在桌面应用的账单面板里恢复已取消的 Pro 续费

## Setup

- **账号**：本机已登录 Cloud，Pro · 按月，已取消续费但仍在有效期内。
- **本次证据的来源**：本分支的看板界面（`kanban-ui`）对着复制出来的临时看板实跑，[stand-in.mjs](stand-in.mjs) 顶替 Cloud：它答一份已取消、可恢复的订阅，用 `--fail-resume` 启动时第一次恢复续费会失败，每次恢复都等两秒才答。登录是手写的 `session.json`，没有走真实登录和 Creem。

## Steps

1. 打开「配置 → 账单」。
   套餐显示「Pro 已取消」「2026年11月14日到期，不再续费。」，右侧是强调色「恢复续费」和「管理账单」。
   [01-open-billing.log](01-open-billing.log)
   ![](01-canceled.png)

2. 按「恢复续费」。
   按钮变淡、不可再按，文字换成「正在恢复…」。
   ![](02-resuming.png)

3. 等 Cloud 答出错。
   按钮复原，套餐卡片内右下显示「无法恢复续费，请重试。」，套餐仍是「到期，不再续费」。
   [03-resume-failed.log](03-resume-failed.log)
   ![](03-resume-failed.png)

4. 再按「恢复续费」。
   错误提示随即消失；恢复成功后面板重新读取，套餐显示「Pro 有效」「2026年11月14日自动续费」，「恢复续费」消失，只剩「管理账单」，没有额外提示。
   [04-resumed.log](04-resumed.log)
   ![](04-resumed.png)

## Feedback

- **和网页一致，一键就好**：不用再经「管理账单」进 Creem 门户，按钮文案、位置和网页设置页对得上。
- **进行中看得见**：按下后按钮变淡并写「正在恢复…」，不会误按两次。
- **失败能重试，但不说原因**：错误就在按钮下方，再按即重试；Cloud 给的原因（这里是 Creem 没回应）不显示，连续失败时用户无从判断。
- **成功是静默的**：面板直接变成「有效 · 自动续费」，干净；但状态标签从「已取消」变「有效」只是颜色和两个字，不留意可能没察觉已经恢复。
- **未在真实 Cloud 上验证**：Cloud、Creem 和登录都是替身，真实的状态流转和出错情形没有走过；已安装 CLI 过旧时的失败也没有单独跑。
