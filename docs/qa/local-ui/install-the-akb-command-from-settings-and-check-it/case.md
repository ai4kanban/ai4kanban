# 在桌面应用的配置里装上 akb 命令，照提示确认版本

## Setup

- **看板**：任意一个看板。
- **界面**：看板 UI（`kanban-ui`）在浏览器里打开，窗口 1440×900，界面语言中文。桌面应用由本目录的 `bridge-fake.js`（页面加载前注入的 `window.ai4kanban`）顶替：它报告这台 Mac 上还没有 `akb`，按「安装」时调用本目录的 `install-server.mjs`，像应用一样在 `~/.local/bin/akb` 写一个指向 `akb` 启动脚本的链接。
- **终端**：`HOME` 是空的临时目录，`PATH` 只有 `~/.local/bin` 和系统目录。

## Steps

1. 打开右上角「配置」→「通用」。
   最上面是「安装」区：「akb 命令 · 未就绪」和橙色「安装」按钮，下面一句「终端中还没有 akb。安装后，编码 Agent 才能直接操作这个看板。」
   ![akb 命令未就绪](01-install-row.png)

2. 点「安装」。
   状态变成绿色「就绪 · 随应用更新」，按钮消失，下面换成一句带勾的「已完成。请在终端中运行 `akb --version`；单独输入 `akb` 会为当前项目打开这个应用。」
   ![安装完成的提示](02-done-note.png)

3. 打开新终端，照提示运行 `akb --version`。
   `~/.local/bin/akb` 是指向启动脚本的链接；命令打印版本号 `0.11.2`，正常退出。
   [终端输出](03-terminal.log)

## Feedback

- **提示终于能照做**：照着完成提示敲的第一条命令直接打印版本号，不再先撞上一条「`akb version` 已改为 `akb --version`」的报错。
- **一步到位**：一个按钮、一句结果，状态当场变绿，不用重启应用或刷新。
- **提示里的第二半句有点意外**：「单独输入 `akb` 会打开这个应用」对只想在终端用命令的人是新信息，放在完成提示里容易被略过。
- **没有跑到的**：真实桌面应用（这里的应用桥是替身，链接也是替身写的）；首次启动时的安装窗口（`readyLink`、`readyWindows`）；Windows 上加入 PATH 后的提示（「请打开新的终端」）；需要管理员密码写 `/usr/local/bin/akb` 的情况；英文界面。
