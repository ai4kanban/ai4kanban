# 只在用键盘移动时看到聚焦框

## Setup

- **看板**：任意临时看板（`akb install` 新建即可），已跳过欢迎导览。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文；点顶栏齿轮打开「配置」，停在「通用」。

## Steps

1. 用鼠标点左侧的「通用」。
   只有选中的浅橙底色，按钮四周没有任何聚焦框或阴影。
   ![鼠标点击后](01-mouse-click.png)
   [按钮的样式](01-mouse-click.log)

2. 用鼠标点「界面语言」的下拉按钮「中文」。
   菜单在下方展开；按钮仍是原来的浅灰底，没有橙红描边，只是右侧箭头翻转朝上。
   ![下拉展开](02-dropdown-open.png)
   [展开前后的样式和菜单项](02-dropdown-open.log)

3. 按 Esc 收起菜单，再用鼠标点「静默多久后结束运行」的输入框。
   输入框四周出现一圈细墨色实线框，没有橙红描边或橙色内阴影。
   ![输入框聚焦](03-input-focused.png)
   [输入框的样式](03-input-focused.log)

4. 按 Tab。
   焦点移到下一行「使用情况上报」的开关：开关套上墨色细框，右下方叠出浅橙、墨色两层偏移阴影，像被抬起来。
   ![键盘聚焦](04-tab.png)
   [开关的样式](04-tab.log)

## Feedback

- **安静多了**：鼠标点哪儿都不再冒橙红框，界面不再像在报错；键盘走到哪里，抬起的阴影一眼就能看见。
- **下拉展开几乎看不出**：语言下拉平时就是浅灰底，展开时唯一的变化是箭头翻转，主要靠弹出的菜单才知道它开着。
- **输入框的提示偏弱**：聚焦只是一圈 1.5px 墨色线，在浅灰底上不算醒目，正在输入时才注意得到。
- **「分钟」被挤成两行**：输入框右侧的单位竖着排成「分 / 钟」，和这次改动无关，但每次聚焦都看得到。
- **没有跑到的**：英文界面、深色模式、Cloud 看板、看板页与卡片页上的 Tab 顺序、触屏。
