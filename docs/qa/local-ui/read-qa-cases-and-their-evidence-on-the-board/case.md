# 在看板上读 QA 场景和它的截图

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：新装看板，`docs/qa/checkout/` 下两个场景，各有一张截图和一份日志的链接。
- **本机证据**：「用保存的银行卡付款」的截图和日志放在项目的 `.akb/qa/checkout/pay-with-a-saved-card/`（不进 git）；「在结算时使用优惠券」在这台电脑上没有任何证据，就像在别的电脑上跑过、只拉下了 `case.md`。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 点左栏底部的「测试用例」。
   页面标题「测试用例」，下面「1 个模块 · 2 个用例」；一块 `checkout` 卡片，右上「2 个用例」，「最近更新」里列着两个场景的标题和日期。
   ![测试用例首页](01-case-list.png)

2. 点 `checkout` 这块卡片。
   进到 `checkout` 模块页，两张场景卡片，每张写着「2 步 · 1 张截图 · 1 份日志」、标题和「1 条感受」。
   ![模块页](02-module-page.png)

3. 点「用保存的银行卡付款」。
   场景页：路径 `docs/qa/checkout/pay-with-a-saved-card/case.md`、日期、「1 条感受」；「前置条件」「步骤」照 `case.md` 排好，第 1 步下面直接显示截图（图下写「结算页」），第 2 步下面是 `02-pay.log` 的内容；最下面是「使用感受」。页面上没有任何缺文件的提示。
   ![证据显示在步骤里](03-evidence-shown.png)
   截图和日志只在 `.akb/qa/` 下，git 里只有 `case.md`，页面上的图片能正常取到：
   [证据在本机、不在 git 里](04-evidence-is-local.log)

4. 回到 `checkout`，点「在结算时使用优惠券」。
   标题下面日期旁边多一个浅橙色标记「这台电脑上没有截图和日志」，整页只出现这一次；两个步骤下面什么都不显示，没有逐条的「找不到文件」。
   ![本机没有证据](05-no-evidence-here.png)
   [标记只出现一次](06-marked-once.log)

5. 删掉「用保存的银行卡付款」在 `.akb/qa/` 下的 `02-pay.log`，只留截图，再打开这个场景。
   顶部没有「这台电脑上没有截图和日志」；第 1 步的截图照常显示，第 2 步下面一条浅橙色的「找不到文件 02-pay.log」。
   ![只缺一份文件](07-one-file-missing.png)

## Feedback

- **证据离开 git 也看得到**：截图和日志只在 `.akb/qa/` 下，场景页照样把它们放进对应的步骤里，读起来和以前没有区别。
- **整份缺失只提示一次**：换台电脑打开，顶部一个标记就说清了「这里没有证据」，不会每个步骤各弹一条红字，页面干净。
- **列表上的数字不分本机有没有**：模块页里「在结算时使用优惠券」也写着「1 张截图 · 1 份日志」，进去才发现一张都没有；在列表里就标出来会省一次点击。
- **标记说了缺，没说怎么补**：「这台电脑上没有截图和日志」之后没有下一步，不知道该去哪台电脑找，或者重跑一次场景就会生成。
- **「最近更新」的行不是链接**：首页 `checkout` 卡片里列出了场景标题，点它却是进模块页，不是直接打开那个场景。
- **没有跑到的**：英文界面；手机宽度；`.akb/qa/` 和 `docs/qa/` 里都有同名文件时以哪份为准；只有日志、没有截图的场景。
