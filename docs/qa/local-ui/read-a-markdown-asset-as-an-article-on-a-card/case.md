# 在卡片页把 Markdown 原稿当文章读，切换版本

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2「发布周报自动化的博客」带两份原稿——`post.zh.md`（用 `variants` 声明了中文、English、日本語三个版本；头部有 `title`、`dek`、`seo_title`；正文很长，引用同一文件夹里的图片 `hours-saved.png`）和一份短的 `launch.mdx`（含 `import` / `export` 行、一个单独成块的组件和一个行内组件）。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，看「博客原稿」。
   原稿按文章排版：大标题「每周报告，五分钟写完」，下面是导语；`seo_title` 等其余头部字段不显示；正文里的图片从卡片资源文件夹读出并显示。文章折在 440px 高，底部淡出，下方是「展开全文」；标题行左侧是「博客原稿」和版本切换「中文 3 ⌄」——没有边框和图标，数字和箭头是灰色，和右侧的「原文」、复制、查看原尺寸、下载图标一样轻。
   ![折叠的文章](01-folded.png)
   [标题、折叠高度、图片和版本切换的样式](01-folded.log)

2. 鼠标移到「中文 3」上，再点它。
   悬停时它才出现一层浅灰底，菜单开着时这层底一直在；下拉菜单按书写顺序列出中文、English、日本語，中文后面打勾；悬停数字提示「共 3 个版本」。
   ![悬停时的浅底](01-hover.png)
   ![版本菜单](02-language-menu.png)
   [菜单项](02-language-menu.log)

3. 选 English。
   标题、导语和正文换成英文版，版本切换显示「English 3」，仍是折叠状态；下载的文件名随之变成 `post.en.md`。
   ![英文版](03-english.png)
   [切换后的状态](03-english.log)

4. 点「展开全文」。
   文章展开到文末，最后一段「This is the last paragraph…」可见，按钮变成「收起」。
   ![展开到文末](04-expanded.png)
   [展开后的高度](04-expanded.log)

5. 在文末点「收起」。
   文章折回 440px，页面跳回到这篇文章的位置，不会停在文章之后的空白处。
   ![收起后的位置](05-collapsed.png)
   [收起后的位置](05-collapsed.log)

6. 点「原文」。
   显示原文件的全部文字（含 `seo_title` 等头部字段），等宽字体、同样折叠；按钮变成「文章」，点它切回文章。
   ![原文视图](06-source.png)
   [原文开头](06-source.log)

7. 点下载图标。
   下载当前语言的原文件 `post.en.md`，内容就是原稿。
   [下载的文件](07-download.log)

8. 往下看「发布说明」（`launch.mdx`）。
   只排版 Markdown：`import` / `export` 行和单独成块的组件都不显示，行内组件只去掉标签、文字「新功能」照常显示；没有声明版本，所以没有版本按钮；内容短，没有「展开全文」。
   ![MDX 原稿](08-mdx.png)
   [显示的文字](08-mdx.log)

9. 刷新卡片页，点「博客原稿」的查看原尺寸图标。
   刷新后版本回到 `src` 指定的中文；打开单独预览页 `/assets/2/post.zh.md`：顶部是「返回 #2」、文件路径和原文、复制、下载按钮，文章不折叠，直接显示全文。

10. 点复制图标。
   剪贴板里是 `post.zh.md` 在本机的绝对路径，图标短暂变成对勾，提示「已复制」。
   ![单独预览页](09-own-page.png)
   [预览页状态](09-own-page.log)

## Feedback

- **版本切换不再抢眼**：去掉边框和图层图标后，标题行的视线先落在「博客原稿」和文章标题上；「中文 3 ⌄」仍一眼看得出能点，悬停的浅底和右侧图标按钮一致。
- **代价是不像按钮**：没悬停时它就是一行文字加箭头，第一次来的人可能不知道数字「3」是版本数，要悬停才看到「共 3 个版本」。
- **终于不用下载才能读**：博客原稿直接按文章读，标题、导语、图片、代码块都对。
- **折叠高度被大图吃掉**：440px 里标题、导语占去一半，开篇就是图片时，折叠状态几乎只看到图，读不到第一段正文。
- **收起后标题行仍被顶栏挡住**：从文末「收起」，页面跳回文章，但带版本切换和「原文」的标题行落在顶栏下面（截图 05），要再往上滚一点。
- **「原文」也折叠**：查正文的 Markdown 还得再点「展开全文」。
- **没有跑到的**：桌面应用（Electron）、深色模式、手机宽度的看板；原稿文件缺失时的提示；外链图片。
