# 在卡片页把 Markdown 原稿当文章读，切换版本

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2「发布周报自动化的博客」带两份原稿——`post.zh.md`（用 `variants` 声明了中文、English、日本語三个版本；头部有 `title`、`dek`、`seo_title`；正文很长，引用同一文件夹里的图片 `hours-saved.png`）和一份短的 `launch.mdx`（含 `import` / `export` 行、一个单独成块的组件和一个行内组件）。
- **浏览器**：无头 Chrome，下载用 `Browser.setDownloadBehavior` 存到一个空的临时目录；用 `Browser.grantPermissions` 给页面剪贴板读写权限。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，看「博客原稿」。
   原稿按文章排版：大标题「每周报告，五分钟写完」，下面是导语；`seo_title` 等其余头部字段不显示；正文里的图片从卡片资源文件夹读出并显示。文章折在 440px 高，底部淡出，下方是「展开全文」。标题行左边是折叠箭头、「博客原稿」和浅灰底的版本「中文 ⌄」（不带版本数）；右边是「查看原文」`<>`、「查看原尺寸」↗ 和 ⋯ 三个图标。
   ![折叠的文章](01-folded.png)

2. 点「中文」。
   下拉菜单按书写顺序列出中文、English、日本語，中文后面打勾。
   ![版本菜单](02-language-menu.png)

3. 选 English，再点 ⋯。
   标题、导语和正文换成英文版，版本显示「English」，仍是折叠状态；⋯ 里是「下载」和「复制绝对路径」，「下载」的文件名随之变成 `post.en.md`。
   [切换后的状态和 ⋯ 菜单](03-english.log)

4. 点「展开全文」。
   文章展开到文末，最后一段「This is the last paragraph…」可见，按钮变成「收起」。
   ![展开到文末](04-expanded.png)

5. 在文末点「收起」。
   文章折回 440px，页面跳回到这篇文章的位置，不会停在文章之后的空白处。
   ![收起后的位置](05-collapsed.png)

6. 点标题行的「查看原文」`<>`。
   显示原文件的全部文字（含 `seo_title` 等头部字段），等宽字体、同样折叠；图标变成按下状态、提示变成「查看文章」，再点切回文章。
   ![原文视图](06-source.png)

7. 点 ⋯ →「下载」，再点 ⋯ →「复制绝对路径」。
   下载当前语言的原文件 `post.en.md`，与原稿逐字节相同；复制后菜单不关，这一项变成「已复制」，剪贴板里是 `post.en.md` 在本机的绝对路径。
   [下载的文件和剪贴板](07-download.log)

8. 往下看「发布说明」（`launch.mdx`）。
   只排版 Markdown：`import` / `export` 行和单独成块的组件都不显示，行内组件只去掉标签、文字「新功能」照常显示；没有声明版本，所以没有版本按钮；内容短，没有「展开全文」。
   ![MDX 原稿](08-mdx.png)

9. 刷新卡片页，点「博客原稿」的「查看原尺寸」↗。
   刷新后版本回到 `src` 指定的中文；打开单独预览页 `/assets/2/post.zh.md`：顶部是「返回 #2 发布周报自动化的博客」、文件路径和文字按钮「原文」、复制、下载图标，文章不折叠，直接显示全文。
   [预览页状态](09-own-page.log)

10. 点复制图标。
    剪贴板里是 `post.zh.md` 在本机的绝对路径，图标变成对勾，提示「已复制」。
    ![单独预览页](10-own-page-copied.png)

## Feedback

- **标题行轻了**：下载和复制路径收进 ⋯，右边只剩三个图标，视线先落在「博客原稿」和文章标题上；版本切换有浅灰底，一眼看得出能点。
- **不知道一共几个版本**：版本数去掉了，要点开菜单才知道有三种语言。
- **「原文」变成了 `<>` 图标**：卡片上要悬停才知道是「查看原文」；单独预览页上却还是文字按钮「原文」，两处不一致。
- **终于不用下载才能读**：博客原稿直接按文章读，标题、导语、图片、代码块都对。
- **折叠高度被大图吃掉**：440px 里标题、导语占去一半，开篇就是图片时，折叠状态几乎只看到图，读不到第一段正文。
- **收起后标题行仍被顶栏挡住**：从文末「收起」，页面跳回文章，但带版本切换和 ⋯ 的标题行落在顶栏下面（截图 05），要再往上滚一点。
- **「原文」也折叠**：查正文的 Markdown 还得再点「展开全文」。
- **没有跑到的**：桌面应用（Electron）、深色模式、手机宽度的看板；原稿文件缺失时的提示；外链图片。
