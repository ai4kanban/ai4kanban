# 在卡片页把 Markdown 原稿当文章读，切换语言

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2「发布周报自动化的博客」带两份原稿——`post.zh.md`（另有同名的 `post.en.md`、`post.ja.md`；头部有 `title`、`dek`、`seo_title`；正文很长，引用同一文件夹里的图片 `hours-saved.png`）和一份短的 `launch.mdx`（含 `import` / `export` 行、一个单独成块的组件和一个行内组件）。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，看「博客原稿」。
   原稿按文章排版：大标题「每周报告，五分钟写完」，下面是导语；`seo_title` 等其余头部字段不显示；正文里的图片从卡片资源文件夹读出并显示。文章折在 440px 高，底部淡出，下方是「展开全文」；标题行右侧是「🌐 中文 ⌄」「原文」和下载图标。
   ![折叠的文章](01-folded.png)
   [标题、折叠高度和图片](01-folded.log)

2. 点「🌐 中文」。
   下拉菜单列出 English、日本語、中文三项，中文后面打勾。
   ![语言菜单](02-language-menu.png)
   [菜单项](02-language-menu.log)

3. 选 English。
   标题、导语和正文换成英文版，按钮显示「English」，仍是折叠状态；下载的文件名随之变成 `post.en.md`。
   ![英文版](03-english.png)
   [切换后的状态](03-english.log)

4. 点「展开全文」。
   文章展开到文末，最后一段「This is the last paragraph…」可见，按钮变成「收起」。
   ![展开到文末](04-expanded.png)
   [展开后的高度](04-expanded.log)

5. 在文末点「收起」。
   文章折回 440px，页面跳回到这篇文章的位置，不会停在文章之后的空白处。
   ![收起后的位置](05-collapsed.png)
   [收起后的位置](05-collapsed.log)

6. 点「原文」。
   显示原文件的全部文字（含 `seo_title` 等头部字段），等宽字体、同样折叠；按钮变成「文章」，点它切回文章。
   ![原文视图](06-source.png)
   [原文开头](06-source.log)

7. 点下载图标。
   下载当前语言的原文件 `post.en.md`，内容就是原稿。
   [下载的文件](07-download.log)

8. 往下看「发布说明」（`launch.mdx`）。
   只排版 Markdown：`import` / `export` 行和单独成块的组件都不显示，行内组件只去掉标签、文字「新功能」照常显示；只有一种语言，所以没有语言菜单；内容短，没有「展开全文」。
   ![MDX 原稿](08-mdx.png)
   [显示的文字](08-mdx.log)

9. 刷新卡片页，点「博客原稿」的文件名。
   刷新后语言回到卡片引用的中文，文件名链接指向它；打开单独预览页 `/assets/2/post.zh.md`：顶部是「返回 #2」和同样的语言、原文、下载按钮，文章不折叠，直接显示全文。
   ![单独预览页](09-own-page.png)
   [预览页状态](09-own-page.log)

## Feedback

- **终于不用下载才能读**：博客原稿直接按文章读，标题、导语、图片、代码块都对，读起来像成品而不是源文件。
- **语言菜单清楚**：地球图标加当前语言名，一眼知道能切；菜单按文件名排序（English、日本語、中文），不是按引用的那份置顶，语言多时要找一下。
- **折叠高度被大图吃掉**：440px 里标题、导语占去一半，开篇就是图片时，折叠状态几乎只看到图，读不到第一段正文。
- **语言不记住**：选了 English 再点文件名，预览页打开的是 `post.en.md`；但刷新卡片页就回到卡片引用的那份。
- **收起后标题行被顶栏挡住**：从文末「收起」，页面确实跳回文章，但文章顶端停在视口最上沿，带语言菜单和「原文」的标题行落在顶栏下面，要再往上滚一点才看得到。
- **「原文」也折叠**：想核对头部字段时一般够用，但查正文的 Markdown 还得再点「展开全文」。
- **没有跑到的**：桌面应用（Electron）、深色模式、手机宽度的看板；原稿文件缺失时的提示；外链图片。
