# 放大卡片里的样稿和图片，看清小字

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2「订单页改版」依次带一份桌面样稿 `orders.tsx`（表格，标题下和右下角各有一行 10–11px 的小字）、一份手机样稿 `orders-phone.html`、一张 2400×1350 的图片 `sales-chart.png`。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，看「订单页（桌面）」，再把鼠标移到画面上。
   标题行只有「订单页（桌面）」和右侧「查看代码」`<>`、「查看原尺寸」↗、⋯ 三个图标；样稿贴满白框，按正文宽度缩小，小字几乎看不清。不指着画面时看不到缩放按钮；指针移上去，画面右下角浮出「− 59% + ⇤⇥」，「适应宽度」是灰的。
   ![指着画面时浮出缩放条](01-desktop-fit.png)
   [比例和按钮状态](01-desktop-fit.log)

2. 点三次「放大」，鼠标停在按钮上。
   比例 59% → 115%，按钮下方出现提示「放大」；画面区域高度不变（752×470），内容变成 1469×918，在区域里可横向、纵向滚动；小字已经清楚。
   ![放大到 115%](02-desktop-zoomed.png)

3. 在画面区域里滚到右下角。
   区域横向滚了 717px、纵向 448px，右下角的「第 1 / 9 页 · 每页 14 条」读得清；缩放条一直浮在右下角。
   ![区域内滚到右下角](03-desktop-scrolled.png)

4. 点「适应宽度」。
   回到 59%，滚动消失，「适应宽度」又变灰。
   [比例和区域尺寸](02-04-desktop-zoom.log)

5. 连续点「缩小」，直到点不动。
   点四次到 25%，「缩小」变灰；缩小的画面在原来那块区域里居中，区域高度不变。
   ![缩到 25%](05-desktop-min.png)

6. 往下看「订单页（手机）」，点两次「放大」，在区域里往下滚。
   打开时是 75%；放大后是 117%，区域高度不变（705），手机框在区域里上下滚动，滚到底看到手机下边框。
   ![手机样稿放大到 117%](06-phone-zoomed.png)

7. 再往下看「销售趋势图」，点三次「放大」。
   标题行只有「查看原尺寸」和 ⋯，没有「查看代码」；打开时 31%（按正文宽度完整显示），放大到 61% 后在区域里双向滚动；图片仍是指向单独预览页 `/assets/2/sales-chart.png` 的链接。
   ![图片放大到 61%](07-image-zoomed.png)

8. 回到桌面样稿，点「查看代码」，再点它切回画面。
   代码视图下 `<>` 呈按下状态、提示变成「查看画面」，画面上不再浮出缩放条。切回画面后缩放条回来，比例停在切走前的 25%。
   ![代码视图里没有缩放](08-code-view.png)

9. 点桌面样稿标题行的「查看原尺寸」↗，打开单独预览页。
   顶部信息行是「返回 #2 订单页改版」和文件路径，右侧有缩放按钮、「代码」和复制图标，打开时是 100%（原尺寸），画面超出栏宽可滚动。
   ![单独预览页默认 100%](09-preview-100.png)

10. 连续点「放大」，直到点不动。
    点七次到 400%，「放大」变灰。
    ![放大到 400%](10-preview-max.png)

11. 点「适应宽度」。
    比例变成 91%，整张画面刚好铺满栏宽。
    ![预览页适应宽度](11-preview-fit.png)

12. 分别从卡片上打开手机样稿和图片的「查看原尺寸」，各点一次「适应宽度」。
    两页打开时都是 100%；适应宽度后，手机画面放大到 280%（宽窗口里手机框撑满整栏），图片缩到 49%。
    [比例和按钮状态](12-preview-phone-and-image.log)

## Feedback

- **就地看清小字**：桌面样稿按 59% 缩进正文栏，点两三下就能读 10px 的字；区域高度不跳，页面也不会被撑长。
- **画面更大更干净**：样稿和图片贴满白框，标题行只剩三个图标，看稿时注意力都在画面上。
- **缩放藏起来了**：不指着画面时看不到任何缩放入口，第一次要碰巧把鼠标移上去才发现；放大后它才一直显示。
- **切回画面不复位**：从代码切回画面停在原来的比例（这里是 25%），想看全貌还得再点「适应宽度」。
- **步长偏小**：一档只放大 1.25 倍，从 25% 回到 100% 要点好几下，比例数字不能点也不能输入。
- **不能用快捷键和捏合**：触控板捏合、`⌘+`/`⌘-` 都不管用，习惯了看图软件的人会先试这两样。
- **预览页的手机适应宽度太猛**：宽窗口里一按就到 280%，手机框比屏幕还高，基本没法当「看全貌」用。
- **放大的手机样稿多是空白**：内容短时放大后往下滚全是空的手机屏，区域高度固定让人多滚几下才知道到底了。
- **没有跑到的**：桌面应用（Electron）里的同一张卡；触屏设备上缩放条常显；⋯ 里的复制绝对路径（见 `read-a-markdown-asset-as-an-article-on-a-card`）；窗口宽度变化时「适应宽度」是否跟着变；深色模式；手机宽度的看板。
