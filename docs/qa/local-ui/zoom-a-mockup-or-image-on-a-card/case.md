# 放大卡片里的样稿和图片，看清小字

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2「订单页改版」依次带一份桌面样稿 `orders.tsx`（表格，标题下和右下角各有一行 10–11px 的小字）、一份手机样稿 `orders-phone.html`、一张 2400×1350 的图片 `sales-chart.png`。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。
- **手势**：触控板捏合用 CDP 的 `Input.synthesizePinchGesture` 产生（Chromium 收到的是按住 Ctrl 的滚轮），双指滑动用不带修饰键的滚轮事件。

## Steps

1. 打开 `/2`，看「订单页（桌面）」，再把鼠标移到画面上。
   标题行只有「订单页（桌面）」和右侧「查看代码」`<>`、「查看原尺寸」↗、⋯ 三个图标；样稿贴满白框，按正文宽度缩小，小字几乎看不清。不指着画面时看不到缩放按钮；指针移上去，画面右下角浮出「− 59% + ⇤⇥」，「适应宽度」是灰的。
   ![指着画面时浮出缩放条](01-desktop-fit.png)
   [比例和按钮状态](01-desktop-fit.log)

2. 点三次「放大」，鼠标停在按钮上。
   比例 59% → 115%，按钮下方出现提示「放大」；画面区域高度不变（752×470），内容变成 1469×918；小字已经清楚。
   ![放大到 115%](02-desktop-zoomed.png)

3. 指着画面，在触控板上双指往右下滑。
   画面在区域里平移到右下角（横 717px、纵 448px），右下角的「第 1 / 9 页 · 每页 14 条」读得清；卡片页本身不动，缩放条一直浮在右下角。
   ![双指平移到右下角](03-desktop-scrolled.png)

4. 点「适应宽度」。
   回到 59%，滚动消失，「适应宽度」又变灰。
   [比例、区域尺寸和卡片页位置](02-04-desktop-zoom.log)

5. 连续点「缩小」，直到点不动。
   点四次到 25%，「缩小」变灰；缩小的画面在原来那块区域里居中，区域高度不变。
   ![缩到 25%](05-desktop-min.png)

6. 往下看「订单页（手机）」，点两次「放大」，指着它双指往下滑。
   打开时是 75%；放大后是 117%，区域高度不变（705），手机框在区域里往下移，滑到底看到手机下边框。
   ![手机样稿放大到 117%](06-phone-zoomed.png)

7. 再往下看「销售趋势图」，点三次「放大」，双指滑动。
   标题行只有「查看原尺寸」和 ⋯，没有「查看代码」；打开时 31%（按正文宽度完整显示），放大到 61% 后在区域里双向平移；图片仍是指向单独预览页 `/assets/2/sales-chart.png` 的链接。
   ![图片放大到 61%](07-image-zoomed.png)

8. 回到桌面样稿，点「查看代码」，再点它切回画面。
   代码视图下 `<>` 呈按下状态、提示变成「查看画面」，画面上不再浮出缩放条。切回画面后缩放条回来，比例停在切走前的 25%。
   ![代码视图里没有缩放](08-code-view.png)

9. 点「适应宽度」，指着桌面样稿双指往下滑。
   样稿在 59% 不动，滑动交给卡片页：页面往下滚了 300px，没有卡在样稿上。
   [样稿和卡片页的滚动位置](09-swipe-at-fit.log)

10. 指着表格中间一行，触控板捏合放大。
    样稿以光标为中心放大到 129%，光标下仍是同一处内容（横 26.6%→26.7%、纵 46.8%→46.7%）；另两张保持 117%、61%，窗口本身不缩放，卡片页不动。
    ![捏合放大](10-pinch-out.gif)
    [比例和光标下的位置](10-pinch-out.log)

11. 放大后双指往下滑。
    只有样稿在区域里平移（纵向到 564px），卡片页不动。
    ![放大后平移样稿](11-pan-zoomed.png)
    [样稿和卡片页的滚动位置](11-pan-zoomed.log)

12. 继续往里捏合，捏到缩不动为止。
    停在 25%，「缩小」变灰；另两张不变。
    [比例和按钮状态](12-pinch-in.log)

13. 点「适应宽度」，在样稿上点一下，再双指往下滑；然后把指针移出样稿，再移回来双指往下滑。
    点过之后滑动交给样稿自己，卡片页不动；指针离开再回来，滑动又滚卡片页（300px）。
    [点击前后的滚动结果](13-click-then-swipe.log)

14. 点桌面样稿标题行的「查看原尺寸」↗，打开单独预览页。
    顶部信息行是「返回 #2 订单页改版」和文件路径，右侧有缩放按钮、「代码」和复制图标，打开时是 100%（原尺寸），画面超出栏宽可滚动。
    ![单独预览页默认 100%](14-preview-100.png)

15. 连续点「放大」，直到点不动。
    点七次到 400%，「放大」变灰。
    ![放大到 400%](15-preview-max.png)

16. 点「适应宽度」。
    比例变成 91%，整张画面刚好铺满栏宽。
    ![预览页适应宽度](16-preview-fit.png)

17. 在预览页的画面上捏合放大。
    放大到 164%，横向上光标下的位置不变（32.2%），纵向往上偏了一点（34.2%→32.4%）；窗口不缩放。
    ![预览页捏合放大](17-preview-pinched.png)
    [比例和光标下的位置](14-17-preview-page.log)

18. 分别从卡片上打开手机样稿和图片的「查看原尺寸」，各点一次「适应宽度」。
    两页打开时都是 100%；适应宽度后，手机画面放大到 280%（宽窗口里手机框撑满整栏），图片缩到 49%。
    ![手机预览适应宽度](18-preview-phone-fit.png)
    [比例](18-preview-phone-and-image.log)

## Feedback

- **捏合就是想要的样子**：指着哪儿就从哪儿放大，光标下的内容不跑，其他样稿和窗口都不跟着动；看小字终于不用连点按钮。
- **双指滑动分得清**：放大时滑动只平移样稿，适应宽度时滑动照常滚卡片页，读长卡片不会被样稿「吃掉」滚动。
- **点过一下滑动就不灵了**：在样稿上随手点一下，之后双指滑动既不滚卡片页、样稿也没内容可滚，看起来像卡住；要把指针移出去再回来才恢复，界面上没有任何提示。
- **预览页捏合有点漂**：画面没铺满高度时，纵向锚点会往上偏一点，放大一次偏二十来像素，不影响使用但能察觉。
- **缩放条仍藏着**：不指着画面时看不到缩放入口；`⌘+`/`⌘-` 仍不管用，比例数字不能输入。
- **切回画面不复位**：从代码切回画面停在原来的比例（这里是 25%），想看全貌还得再点「适应宽度」。
- **预览页的手机适应宽度太猛**：宽窗口里一按就到 280%，手机框比屏幕还高，基本没法当「看全貌」用。
- **没有跑到的**：真实触控板（手势由 CDP 合成，未在 macOS 实机上捏合）；桌面应用（Electron）里整窗是否真的不跟着缩放；带交互的样稿点一下后在内部点击和滚动；触屏设备；深色模式；手机宽度的看板。
