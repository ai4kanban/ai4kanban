# 在浏览器标签栏上认出看板的飞鹤图标

## Setup

- **看板**：任意已建好的看板。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页。
- **取证**：headless Chrome 不画标签栏，所以读出看板页声明的标签页图标，在浅色和深色配色（CDP 模拟 `prefers-color-scheme`）下各画一份：一个仿标签页（16px）加一个放大的（64px）。

## Steps

1. 打开看板，看它给标签页的图标。
   页面只声明一个内联 SVG 图标，不额外请求文件；画的是飞鹤，深色配色下鹤身改成白色，丹顶是橙红圆点。
   [标签页图标](01-tab-icon.log)

2. 在浅色配色下看标签页。
   标签上是一只黑色飞鹤和「AI4Kanban」；16px 下仍能看出展翅的鹤和红点丹顶。
   ![浅色标签栏](02-light.png)

3. 在深色配色下看标签页。
   鹤变成白色，丹顶仍是橙红，在深色标签栏上看得清。
   ![深色标签栏](03-dark.png)

## Feedback

- **小尺寸也认得出**：剪影简单，16px 下仍是一只鹤，丹顶那一点颜色让它在一排标签里跳出来。
- **和页面里的标志不一致**：标签页已是飞鹤，看板左上角仍是橙色三竖条方块，标签页标题也还是「AI4Kanban」，同一个窗口里两套形象。
- **深浅跟系统走**：浏览器主题和系统配色不一致时，鹤的颜色可能和标签栏不搭（卡片已接受这一点）。
- **没有跑到的**：真实浏览器标签栏（headed Chrome、Safari、Firefox）；Cloud 看板的标签页图标（归 cloud 模块）。
