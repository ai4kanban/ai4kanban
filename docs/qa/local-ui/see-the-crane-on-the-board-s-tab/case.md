# 在浏览器标签栏和看板左上角认出 WildCrane 的飞鹤

## Setup

- **看板**：任意已建好的看板。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900。
- **取证**：headless Chrome 不画标签栏，所以读出看板页声明的标题和标签页图标，在浅色和深色配色（CDP 模拟 `prefers-color-scheme`）下各画一份：一个仿标签页（16px）加一个放大的（64px）。

## Steps

1. 打开看板，看它给标签页的标题和图标。
   标题是「WildCrane」；页面只声明一个内联 SVG 图标，不额外请求文件；画的是飞鹤，深色配色下鹤身改成白色，丹顶是橙红圆点。
   [标签页标题和图标](01-tab-icon.log)

2. 在浅色配色下看标签页。
   标签上是一只黑色飞鹤和「WildCrane」；16px 下仍能看出展翅的鹤和红点丹顶。
   ![浅色标签栏](02-light.png)

3. 在深色配色下看标签页。
   鹤变成白色，丹顶仍是橙红，在深色标签栏上看得清。
   ![深色标签栏](03-dark.png)

4. 看看板左上角的标志。
   也是同一只墨色飞鹤（23×22）配橙红丹顶，没有字标；指上去的名字是「全部卡片」。
   ![看板左上角](04-board-logo.png)
   [标志的尺寸和颜色](04-board-logo.log)

## Feedback

- **一套形象了**：标签页、标签标题和看板左上角都是飞鹤和 WildCrane，不再一边新鹤一边旧方块。
- **小尺寸也认得出**：剪影简单，16px 下仍是一只鹤，丹顶那一点颜色让它在一排标签里跳出来。
- **左上角只有鹤**：没有字标，第一次打开的人从页面里看不到产品名，只能看标签页标题。
- **深浅跟系统走**：浏览器主题和系统配色不一致时，鹤的颜色可能和标签栏不搭（卡片已接受这一点）。
- **没有跑到的**：真实浏览器标签栏（headed Chrome、Safari、Firefox）；深色模式下左上角的鹤；Cloud 看板的标签页图标（归 cloud 模块）。
