# 一键下载分镜的全部图片

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「小红书轮播图：五分钟上手看板」（需要 ffmpeg 画图；脚本打印卡号，本次在新项目里跑，是 #2）。正文有三个分镜：
  - `<Storyboard src=".assets/2/carousel.json" label="小红书 3:4" />`：四页轮播图，第 1、2、4 页的预览图是 600×800 的色块，上面的黑方块数等于页码；第 3 页指向的 `previews/3-chat.png` 不存在。
  - `<Storyboard src=".assets/2/draft.json" label="草稿" />`：两页，一张图都没有。
  - `<Storyboard src=".assets/2/deck.json" label="演示文稿" />`：三页，第 1、3 页是 HTML 页面，第 2 页是轮播图第 2 页那张图。
- **浏览器**：无头 Chrome，下载用 `Browser.setDownloadBehavior` 存到一个空的临时目录。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，把指针移到「小红书 3:4」头栏最右侧的下载图标上。
   分镜自成一块白底，头栏左边是标签「小红书 3:4」，右侧是「4 页」和一个只有下载图标的按钮；悬停后下方出现深色提示「全部下载」，读屏标签相同。
   ![头栏的下载按钮](01-download-button.png)
   [按钮属性](01-button.log)

2. 点下载图标，解压下载到的文件。
   得到 `2-小红书 3-4.zip`（标签里的 `:` 换成了 `-`）；里面是 `01.png`、`02.png`、`04.png`，缺图的第 3 页留空号；三张和对应页的原图逐字节相同。
   [zip 内容与比对](02-zip.log)
   ![解压出的三页，依次 01、02、04](02b-unzipped-pages.png)

3. 往下看「草稿」分镜。
   头栏只有「草稿」「2 页」，没有下载按钮；下面当前页是「暂无预览」的虚线框。
   ![没有图就没有按钮](03-no-pictures-no-button.png)
   [两个分镜的按钮](03-no-pictures.log)

4. 往下看「演示文稿」，点它的下载图标并解压。
   当前页是 HTML 的「1 · 第一页」，头栏「演示文稿」「3 页」右侧照样有下载按钮；得到 `2-演示文稿.zip`，里面只有 `02.png`，与第 2 页的图逐字节相同，两页 HTML 不进 zip。
   ![图片和 HTML 混排的分镜](04-mixed-deck.png)
   [zip 内容与比对](04-mixed-deck.log)

5. 把界面语言换成英文（改机器设置），再打开 `/2`。
   头栏变成「4 slides」，按钮的提示变成「Download all」。
   [英文提示](05-english.log)

## Feedback

- **一次到手**：点一下就得到整套图，编号就是页码，缺页留空号一眼能看出少了哪页，比逐张右键省事得多。
- **混排时容易误会**：演示文稿里 HTML 页和图片页在缩略图里排在一起，「全部下载」却只给图片页，三页的分镜下下来只有一个 `02.png`，界面上没有任何说明；以为拿到的是整份稿子的人会吃惊。
- **按钮太安静**：只有一个小图标，不悬停不知道是「全部下载」；没有任何地方提示第 3 页没进 zip。
- **文件名里有空格**：`2-小红书 3-4.zip` 保留了标签里的空格，在终端里要加引号。
- **没有跑到的**：「正在打包…」转圈（本地打包太快，来不及截到）；所有图都取失败时的警示图标和重试；视频分镜（打包草图）；超过 99 页的三位编号；桌面版的另存为对话框。
