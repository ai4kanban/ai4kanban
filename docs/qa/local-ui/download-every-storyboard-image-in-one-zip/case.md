# 一键下载分镜的全部图片

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「小红书轮播图：五分钟上手看板」（需要 ffmpeg 画图；脚本打印卡号，本次和另外两个场景共用一个项目，这张是 #3）。正文有两个分镜：
  - `<Storyboard src=".assets/3/carousel.json" label="小红书 3:4" />`：四页轮播图，第 1、2、4 页的预览图是 600×800 的色块，上面的黑方块数等于页码；第 3 页指向的 `previews/3-chat.png` 不存在。
  - `<Storyboard src=".assets/3/draft.json" label="草稿" />`：两页，一张图都没有。
- **浏览器**：无头 Chrome，下载用 `Browser.setDownloadBehavior` 存到一个空的临时目录。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/3`，把指针移到「小红书 3:4」标题行最右侧的下载图标上。
   标题行是「小红书 3:4 · 4 页」，右侧一个只有下载图标的浅色按钮；悬停提示和读屏标签都是「全部下载」（无头 Chrome 不画原生提示框，以按钮的 `title` 为证）。
   ![标题行的下载按钮](01-download-button.png)
   [按钮属性](01-button.log)

2. 点下载图标，解压下载到的文件。
   得到 `3-小红书 3-4.zip`（标签里的 `:` 换成了 `-`）；里面是 `01.png`、`02.png`、`04.png`，缺图的第 3 页留空号；三张和对应页的原图逐字节相同。
   [zip 内容与比对](02-zip.log)
   ![解压出的三页，依次 01、02、04](02b-unzipped-pages.png)

3. 往下看「草稿」分镜。
   标题行只有「草稿 · 2 页」，没有下载按钮。
   ![没有图就没有按钮](03-no-pictures-no-button.png)
   [两个分镜的按钮](03-no-pictures.log)

4. 把界面语言换成英文（改机器设置并重启 UI），再打开 `/3`。
   按钮的提示变成「Download all」。
   [英文提示](04-english.log)

## Feedback

- **一次到手**：点一下就得到整套图，编号就是页码，缺页留空号一眼能看出少了哪页，比逐张右键省事得多。
- **按钮太安静**：只有一个灰色小图标，不悬停不知道是「全部下载」；没有任何地方提示第 3 页没进 zip。
- **文件名里有空格**：`3-小红书 3-4.zip` 保留了标签里的空格，在终端里要加引号。
- **没有跑到的**：「正在打包…」转圈（本地打包太快，来不及截到）；所有图都取失败时的警示图标和重试；视频分镜（打包草图）；超过 99 页的三位编号；桌面版的另存为对话框。
