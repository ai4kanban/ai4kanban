# 一键下载分镜的全部图片

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「小红书轮播图：五分钟上手看板」（需要 ffmpeg 画图；脚本打印卡号，本次在新项目里第一个跑，是 #2）。正文有三个分镜：
  - `<Storyboard src=".assets/2/carousel.json" label="小红书 3:4" />`：四页轮播图，第 1、2、4 页的预览图是 600×800 的色块，上面的黑方块数等于页码；第 3 页指向的 `previews/3-chat.png` 不存在。
  - `<Storyboard src=".assets/2/draft.json" label="草稿" />`：两页，一张图都没有。
  - `<Storyboard src=".assets/2/deck.json" label="演示文稿" />`：三页，第 1、3 页是 HTML 页面，第 2 页是轮播图第 2 页那张图。
- **浏览器**：无头 Chrome，下载用 `Browser.setDownloadBehavior` 存到一个空的临时目录。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，点「小红书 3:4」标题行最右侧的 ⋯（提示「更多」）。
   分镜自成一块白底，标题行是「小红书 3:4」「4 页」、翻页器「‹ 1 / 4 ›」和 ⋯；四页按 3:4 原比例横向并排，第 1 页描边，标题在页下，最右一页只露出一部分并渐隐。⋯ 弹出的菜单只有一项「全部下载」。
   ![⋯ 菜单里的全部下载](01-download-menu.png)

2. 点「全部下载」，解压下载到的文件。
   得到 `2-小红书 3-4.zip`（标签里的 `:` 换成了 `-`）；里面是 `01.png`、`02.png`、`04.png`，缺图的第 3 页留空号；三张和对应页的原图逐字节相同。
   [zip 内容与比对](02-zip.log)

3. 往下看「草稿」分镜。
   标题行只有「草稿」「2 页」和翻页器，没有 ⋯，也就没有下载入口；两格缩略图都是空白，当前页是「暂无预览」加「重新加载」的虚线框。
   ![没有图就没有菜单](03-no-pictures-no-download.png)

4. 往下看「演示文稿」，点它的 ⋯ →「全部下载」并解压。
   当前页是 HTML 的「1 第一页」，标题行「演示文稿」「3 页」右侧照样有 ⋯ 和「全部下载」；得到 `2-演示文稿.zip`，里面只有 `02.png`，与第 2 页的图逐字节相同，两页 HTML 不进 zip。
   [zip 内容与比对](04-mixed-deck.log)

5. 把界面语言换成英文（改机器设置），再打开 `/2`，点「小红书 3:4」的 ⋯。
   标题行变成「4 slides」，按钮读屏标签「More」，菜单项「Download all」。
   [英文文字](05-english.log)

## Feedback

- **一次到手**：点两下就得到整套图，编号就是页码，缺页留空号一眼能看出少了哪页，比逐张右键省事得多。
- **入口更深了**：「全部下载」现在收在 ⋯ 里，标题行上看不到任何下载的样子，第一次要打开菜单才知道有这个功能。
- **草稿没有 ⋯ 时不一致**：同一张卡上有的分镜有 ⋯、有的没有，用户会以为页面没加载完。
- **混排时容易误会**：演示文稿三页只下下来一个 `02.png`，界面上没有说明 HTML 页不进 zip；以为拿到的是整份稿子的人会吃惊。
- **没提示缺了哪页**：第 3 页没进 zip，只能靠空号自己发现。
- **文件名里有空格**：`2-小红书 3-4.zip` 保留了标签里的空格，在终端里要加引号。
- **没有跑到的**：「正在打包…」转圈（本地打包太快，来不及截到）；所有图都取失败时的警示和重试；视频分镜（打包草图）；超过 99 页的三位编号；桌面版的另存为对话框；手机宽度下的竖版页面带。
