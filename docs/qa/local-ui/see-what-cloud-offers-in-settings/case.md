# 在「配置 → 云端」看 Cloud 提供哪些托管 AI 能力，在「账单」看它们各花多少积分

## Setup

- **看板**：任意一个装好看板的一次性项目（本次用 `get-notified-without-signing-in` 的 `seed.sh` 建的项目）。
- **账号**：Cloud 由本目录的 [stand-in.mjs](stand-in.mjs) 顶替，账号是编的；`/_set?plan=free|pro` 切换套餐，免费版是从没用过 Pro 的账号。第 1 步 `AI4KANBAN_HOME` 里没有 `session.json`（未登录），之后放回手写的 `session.json`（已登录）；每次切换套餐前删掉 `pro.json` 缓存。发票一栏答空。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截「配置」窗口。

## Steps

1. 未登录，点右上角「配置」，再点左栏「云端」。
   「账号」下是「Cloud 目前是邀请制内测。」和一段说明，下面一句「登录即表示你同意 隐私政策与服务条款。」，两个词各链到 `ai4kanban.dev/privacy`、`/terms`；没有 alpha 说明和「Cloud 只中转……」的数据边界段。再下面是「托管 AI 能力」：图像生成「按描述和参考图生成图片。」、语音合成「把文字读成自然的人声。」、音乐生成「按描述生成指定时长的原创音乐。」，末尾一句「Agent 在任务中按需使用，消耗 Pro 套餐的 AI 积分。」没有开关或按钮，也没有厂商和模型名。
   ![未登录的云端页](01-signed-out.png)
   [页面文字与链接](01-signed-out.log)

2. 登录（Pro）后再看「云端」。
   「账号」换成头像、「QA User」「@qa-user」和「退出登录」，下面是「云端存储」；「托管 AI 能力」三项照旧在最下面。
   ![登录后的云端页](02-signed-in.png)
   [页面文字](02-signed-in.log)

3. 点左栏「账单」。
   「AI 积分」卡片里 5,000 / 5,000 剩余，下面一行「配音每秒 1 积分 · 生成图像每张 320 积分 · 生成音乐每首 160 积分」，不再写「生成封面」。
   ![账单页的费率](03-billing.png)
   [页面文字](03-billing.log)

4. 把套餐切成免费版，重新打开「账单」，点「升级」，再点 Pro 下「每月 5,000 AI 积分」旁的「消耗标准」。
   出现免费版和 Pro 的对照：免费版列「全部 6 种工作流」；Pro 依次是「全部 Pro 模板」「新想法自动筛选」「AI 配音、图像和音乐生成」「每月 5,000 AI 积分」「优先支持」，主按钮是「免费试用 7 天」。展开后是「配音、图像和音乐共用每月 5,000 AI 积分。」和三行费率：配音「1 积分 / 秒」、图像「320 积分 / 张」、音乐「160 积分 / 首」。
   ![升级对照](04-upgrade.png)
   [对照表文字，展开前后](04-upgrade.log)

## Feedback

- **一眼知道 Cloud 能干什么**：三项能力各一句话，登录前就能看到，比原来只有账号和存储清楚。
- **说明短了很多**：条款一句话带两个链接，隐私细节交给隐私政策页，页面不再一屏说明文字。
- **Pro 讲清了买的是什么**：对照里工作流归到免费版，Pro 只剩模板、自动筛选和托管生成，不再让人以为不买就用不了工作流。
- **费率藏得刚好**：权益只写「每月 5,000 AI 积分」，想算账再点「消耗标准」，展开写明三种生成共用一个额度；账单页的费率行与它一致。
- **两处说法略有出入**：账单页写「生成图像每张 320 积分」，对照表写「图像 320 积分 / 张」，同一件事两种句式。
- **列表看起来能点**：云端页三项排成带图标的卡片行，像设置项，点上去却什么都不发生；也看不出这些能力是 Pro 才有，要读到最后一句小字。
- **「指定时长的原创音乐」与按首计费对不上**：云端页说能指定时长，费率又是每首 160 积分、与时长无关，用户会猜长曲子是不是更贵。
- **没有跑到的**：真的调用 `akb cloud image` / `tts` / `music` 扣积分、积分用完时的提示、官网定价页、英文界面、桌面应用里的登录；试用本身见 [先免费试用 Pro 7 天](../start-a-pro-trial-in-the-desktop-billing-panel/case.md)。
