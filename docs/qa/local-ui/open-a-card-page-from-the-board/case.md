# 从看板打开一张卡片页

## Setup

- **看板**：一次性 git 项目，`akb install` 新建，有 #1、#3–#7 几张卡。#7「Print layout for the export」正文里有一条很长的文件路径和一个长文件名的 HTML 附件（放在 `.akb/boards/docs/kanban/assets/7/`）。看板的 Agent 换成 [turn-an-idea-into-a-card-on-the-board/stand-in.mjs](../turn-an-idea-into-a-card-on-the-board/stand-in.mjs)，它自动规划时给卡加了一个「Which page size is the default?」问题。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900，界面语言中文，已跳过欢迎导览；开发服务器先打开过一次卡片页，路由已编译。
- **录制**：用 CDP 录屏帧按真实间隔拼成 GIF；同时每约 40ms 记一次页面状态。

## Steps

1. 在看板上点 #7。
   页面停在看板上，没有整页加载画面；约 300ms 后被点的卡开始变暗闪动；卡片页读完后整页一次换成 #7。
   ![从看板打开](01-open-from-board.gif)

2. 看同一次打开的逐帧记录。
   前 1.2 秒地址一直是 `/`、看板一直在，被点的卡在 300ms 前不透明度为 1，之后慢慢降到约 0.5；约 1.3 秒时地址变成 `/7`，看板消失，「打开中」标记随之清掉。卡片页里随后只有局部的骨架行（页面画出后才读的部分），不是整页的加载画面。
   [打开时间线](02-open-timeline.log)

3. 看打开后的卡片页。
   标题「#7 Print layout for the export」、操作按钮、属性行、「待你决定」、正文和附件都在；长路径在正文里折行。
   ![卡片页](03-card-page.png)

4. 把窗口缩到 700px 宽，滚到附件那一段。
   页面换成手机布局，长路径折行，附件标题行和预览收在宽度内，没有横向滚动条。
   ![窄窗口](04-narrow.png)

5. 量窄窗口下卡片页滚动区的宽度。
   滚动区 `overflow-x: hidden`，内容宽 702px、可见宽 700px，页面本身的宽度等于窗口宽度；多出的 2px 被裁掉，不会出现横向滚动条。
   [宽度](05-narrow-widths.log)

## Feedback

- **不再闪一下加载页**：点卡后先留在看板，慢的时候被点的卡自己变暗，读完再整页切换，比以前先跳到加载画面再出内容稳很多。
- **反馈够早又不吵**：300ms 内读完就什么都不显示，读得慢时才变暗，快的时候完全感觉不到等待。
- **窄窗口不再左右晃**：长路径、长附件名都收在宽度里，横向滑不动了。
- **等待时只有一张卡在变**：开发服务器第一次编译时要等好几秒，这时只有那张卡在慢慢闪，别处毫无变化，不留意会以为没点中。
- **没有跑到的**：卡片读取失败的独立页面（错误、重试、回到看板）——把卡文件改成不可读时整个看板一起报「无法读取看板」，停掉服务器时浏览器只显示连接失败，在 CDP 里让卡片页的请求返回 500 时又改为整页加载并正常打开，没能单独让卡片页读取失败；从通知铃的行打开时的标记；减少动态效果下的静止变暗；归档卡的打开。
