# 手动归档今天的第一张卡，看到欢呼

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：新装看板，三张卡——#2「加一个深色模式」，#3「导出 CSV」和 #4「修正登录页错别字」的待办都已勾完。今天还没有归档过任何卡。
- **Agent**：看板的 Agent 换成本目录的 `stand-in.mjs`（不连模型）：收到「归档」就执行 `akb raw archive <id>`，别的什么都不做。整个过程没有交付，也没有提交。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，点「移除」，在对话框里点「丢弃」。
   回到看板，#2 不见了；右下角没有欢呼。
   ![移除后没有欢呼](01-removed-no-cheer.png)

2. 打开 `/3`。
   操作栏里是「修订」「归档」「移除」，没有「执行」。
   ![卡片页的归档按钮](02-archive-button.png)

3. 点「归档」，在确认框（「所有待办项均已完成。卡片完成后移出看板。」）里再点「归档」。
   约 3 秒后回到看板，右下角弹出一块像素画：几个小人在办公室里撒彩带，下面一行「今天第一个任务完成 #3 导出 CSV」；约十秒后自己消失。
   ![今天第一个任务完成](03-first-task-cheer.png)
   ![欢呼的特写](03b-cheer-corner.png)

4. 用同样的方法归档 #4。
   卡片离开看板，这次没有欢呼。
   ![第二张不再欢呼](04-second-task-no-cheer.png)

## Feedback

- **不靠交付也有欢呼**：没有执行、没有提交，点「归档」就为「今天第一个任务完成」欢呼了一次，和卡片说的「归档就算完成」一致。
- **分寸对**：移除不欢呼，当天第二张也不欢呼，不会变成每次都放烟花的噪音。
- **一闪而过**：欢呼只在右下角停十秒左右，不点也不挡操作；但切到别的页面或刚好没看屏幕就错过了，之后没有任何地方能再看到。
- **没有跑到的**：整组完成、版本全部完成两种欢呼；手动提交模式下交付提交后的欢呼；英文界面；手机宽度。
