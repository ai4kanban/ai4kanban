# 在 macOS 深色和染色图标样式下认出 Dock 里的应用

## Setup

- **系统**：macOS 26 及以上，「系统设置 → 外观 → 图标与小组件样式」可选默认、深色、染色。
- **应用**：用这次提交打包的 WildCrane 桌面应用，放在 Dock 里。
- **取证**：本机没有这次提交打包出的应用，也不为取证切换整台电脑的外观，所以每种样式都用 Icon Composer 自带的 `ictool` 把 `desktop/build/icon.icon` 按 macOS 外观渲染成 256px（染色取蓝色），贴在近似 Dock 的底色上。
  [渲染命令](00-render.log)

## Steps

1. 图标样式选「默认」，看 Dock。
   白色圆角底板上一只墨色飞鹤，丹顶是橙红；底板带一层玻璃高光。
   ![默认样式](01-default.png)

2. 换成「深色」。
   底板变成深灰渐变，飞鹤变成米白，丹顶仍是橙红；Dock 里不再有一块白色亮板。
   ![深色样式](02-dark.png)

3. 换成「染色」并选一种颜色。
   整个图标按所选颜色染色，飞鹤在深色底板上清楚可见，丹顶比飞鹤亮一档。
   ![染色样式](03-tinted.png)

## Feedback

- **深色下终于不刺眼**：深色底板和米白飞鹤跟其他深色图标站在一起，不再是一块白板。
- **染色还认得出**：飞鹤轮廓完整，丹顶靠亮度区分，没有被系统一并抹平；只是丹顶不再是红色，那一点辨识度弱了。
- **默认样式多了玻璃感**：白底飞鹤比旧版平面 PNG 多一层高光，和其他 macOS 26 应用一致。
- **没有跑到的**：真实 Dock 和访达里的图标（三张图都是 `ictool` 渲染，不是系统截图）；染色样式的其他颜色和「浅色染色」；旧版 macOS 的 `.icns`；Windows 与 Linux 的图标。
