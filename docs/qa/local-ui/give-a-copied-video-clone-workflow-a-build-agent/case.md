# 给复制的「视频克隆」工作流设置执行 Agent，让卡片可以执行

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：新装看板，#2「把审阅过的片头模板发到共享模板库」已规划好、状态是待执行，有一条未勾的待办；它的工作流写的是 `wf-2`，也就是看板上第一次复制出来的工作流的 id。
- **账号**：本机已登录 Cloud，是 Pro。Cloud 由本目录的 [stand-in.mjs](stand-in.mjs) 顶替，登录是手写的 `session.json`。
- **Agent**：PATH 最前放一个替身 `claude`：被问登录状态时答已登录，被叫去运行时三秒后答「Done (stand-in).」并结束，不连模型。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。截图只截「配置」窗口或卡片相关区域。

## Steps

1. 点右上角的「配置」，再点左栏「工作流」，在中间一栏顶上的下拉里选「视频克隆」。
   中间只有「规划」框（领头的「视频克隆」和「规划助手」）和「定期运行」框，没有「执行」框：内置的视频克隆不能加执行 Agent。
   ![内置的视频克隆](01-built-in.png)
   [页面上的文字](what-the-page-says.log)

2. 点下拉右边的「…」，选「复制工作流」。
   顶上换成名称输入框，里面是选中的「视频克隆2」；「规划」框下面多了一个「执行」框，框里只有一个「+ 设置 Agent」按钮，没有「不可用」之类的警示。
   ![复制出的工作流](02-copy.png)
   [页面上的文字](what-the-page-says.log)

3. 按回车保留名称，再点「设置 Agent」。
   「执行」框里出现一行新 Agent 并被选中，右侧是它的 `AGENT.md`（`docs/kanban/agents/wf-2-executor/AGENT.md`，`lead: execute`，英文标题写的是「视频克隆2 executor」）。应当显示「视频克隆2 executor」，但列表和右侧标题都显示「Wf 2 executor」——由 id 拼出的名字，没用上写进去的标题。
   ![设置了执行 Agent](03-executor.png)
   [页面上的文字](what-the-page-says.log)

4. 按 Esc 关掉「配置」，打开 #2。
   标题旁是「可以开始执行」，工具栏有橙色的「执行」；「工作流」一栏写着「视频克隆2」。
   ![卡片可以执行](04-card-can-build.png)
   [页面上的文字](what-the-page-says.log)

5. 点「执行」。
   弹出「执行 #2」：「Agent 生成文件，完成后归档任务。成品可在任务中查看。」、补充说明输入框、「取消」和「执行」。
   ![执行确认框](05-confirm.png)

6. 点框里的「执行」。
   运行由执行 Agent 跑：运行记录里这次是 `implement #2`，Agent 是 `wf-2-executor`。替身什么都没交，几秒后标题旁是「待你处理」，红框写「任务中没有记录成品文件，补上后请再次执行。」，下面是「再次执行」和「日志 ✓ 完成 · stand-in」。
   ![执行之后](06-building.png)
   [运行记录](06-run.log)

## Feedback

- **流程很短**：复制、点一下「设置 Agent」，卡片就有了「执行」，不用自己去写 `AGENT.md` 的 frontmatter，也不用理解什么叫「规划即交付」。
- **名字显示错了**：新 Agent 在中文界面叫「Wf 2 executor」，既不是工作流名，也不像人起的名字；文件里明明写了「视频克隆2 executor」，只写在 `en` 下。
- **新 Agent 是空壳**：简介和正文都是英文的「Unwritten…」占位，这样就能直接执行，卡片上没有任何提示说这个执行 Agent 还什么都不会做。
- **交付物要执行 Agent 自己写回**：执行 Agent 不在卡片上记下成品，交付就停在「待你处理」；这条要求只在执行完才冒出来，设置 Agent 时没人提。
- **确认框的说法不对味**：「Agent 生成文件，完成后归档任务」对一个「上传模板」的执行 Agent 不太贴切，用户看不出执行的是哪个 Agent。
- **复制后的名字**：「视频克隆2」没有空格，像打错字；输入框自动选中，按回车或点别处都会保留。
- **卡片怎么换到副本上**：卡片页的「工作流」只能看不能改，本用例靠种子直接写 `wf-2`；用户已有的卡片要换到副本，界面上找不到地方。
- **没有跑到的**：英文界面、给执行 Agent 改名、把执行 Agent 删掉后卡片回到「规划完即归档」、真实 Claude Code 执行和交付收尾。
