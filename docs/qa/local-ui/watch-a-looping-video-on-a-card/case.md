# 在卡片上看一段循环播放的视频

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「首页动图改用视频」（需要 ffmpeg；脚本打印卡号，本次和另外两个场景共用一个项目，这张是 #4）。脚本用 ffmpeg 生成一段 4 秒、960×540 的 H.264 MP4（测试图案，左上角带走动的时间码），放进 `.akb/boards/docs/kanban/assets/4/`，复制成 `loop.mp4` 和 `walkthrough.mp4`。正文先是 `<Asset src=".assets/4/loop.mp4" label="首页动图" loop />`，中间十二行文字，最后是不带 `loop` 的 `<Asset src=".assets/4/walkthrough.mp4" label="操作录屏" />`。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。动态用前后两帧截图加 `video` 元素的状态日志代替录屏。

## Steps

1. 打开 `/4`，让「首页动图」完整出现在视野里。
   视频自己开始播：静音、循环、没有控制条；隔 1.5 秒的两帧时间码不同，`currentTime` 走到 3.85 秒后回到 0.24 秒接着播。
   ![第一帧](01a-loop-frame.png)
   ![1.5 秒后](01b-loop-frame-later.png)
   [播放状态与采样](01-loop-playing.log)

2. 往下滚，直到「首页动图」完全离开视野，再滚回来。
   离开视野后暂停，`currentTime` 停在原处不动；滚回来后接着播。
   [滚出、滚回时的状态](02-scroll-out-pauses.log)

3. 滚到「操作录屏」。
   是普通播放器：有控制条（播放键、`0:00 / 0:04`、音量、全屏），不静音、不循环，不会自己播。
   ![普通播放器](03-plain-player.png)
   [状态](03-plain-video.log)

4. 开启「减少动态效果」（`Emulation.setEmulatedMedia` 设 `prefers-reduced-motion: reduce`），重新打开 `/4`。
   「首页动图」停在首帧不播，正中间一个圆形播放按钮（读屏标签「播放」）。
   ![停在首帧](04-reduced-motion-held.png)
   [状态与按钮位置](04-reduced-motion.log)

5. 点这个播放按钮。
   按钮消失，视频开始静音循环播放，仍然没有控制条。
   ![点了之后在播](05-reduced-motion-playing.png)
   [状态](04-reduced-motion.log)

## Feedback

- **像动图一样自然**：打开卡片就动，没有控制条和声音，和 GIF 的观感一样；离开视野就停，不白占资源。
- **尊重减少动态效果**：停在首帧加一个醒目的播放按钮，想看的人点一下就行。
- **点开之后没有暂停键**：减少动态效果模式下点了播放就一直循环，画面上没有暂停按钮（滚走才停），对正是因为不想看动画才开这个设置的人不太友好。
- **两种视频长得不一样但没说明**：卡片上看不出哪个是「动图」哪个是「视频」，只能靠有没有控制条判断。
- **没有跑到的**：浏览器拒绝 `play()`（如省电模式）时退回播放按钮；Safari 和 iOS；桌面版；带 `loop` 的音频或图片（应被忽略）；官网的 `LoopVideo`（不在本场景范围）。
