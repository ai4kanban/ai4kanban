# 在卡片页上看软件规划师画的示意图

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2 的「软件规划师」段是一段 `flowchart TB` 的 mermaid 代码块；#3 内容相同，只是图头错写成 `flowchar TB`。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 #2。
   正文和 Worth noting 下方有一个收起的「软件规划师」段，看不到图。
   ![收起的软件规划师段](01-collapsed-section.png)

2. 点「软件规划师」展开。
   段里画出一张自上而下的流程图：5 个节点（含一个菱形判断），箭头上标着「有」「没有」，配色与看板一致；没有原代码。
   ![画出的示意图](02-diagram.png)
   [页面上画出的内容](02-03-what-the-page-drew.log)

3. 打开 #3，展开「软件规划师」。
   图头写错，页面不画图，原样显示 mermaid 代码块。
   ![图头写错时显示代码](03-broken-header-shows-code.png)
   [页面上画出的内容](02-03-what-the-page-drew.log)

## Feedback

- **图一眼看懂**：五个框把「结束讨论 → 停 Agent → 清理进程」的分支讲清楚，比读 Scope 快，而且风格和卡片页融为一体。
- **图默认收起**：审卡时最该先看的图藏在一个收起的段里，标题只写「软件规划师」，不展开就不知道里面有图。
- **图偏大**：5 个节点占了大半屏，菱形尤其大，看下面的 Scope 要往下滚很远。
- **写错只退回代码**：图头写错时用户只看到一段代码，没有一句说明为什么没画出来；卡片说明里提到某一行写错时会被悄悄略过，这次没有验证。
- **没有跑到的**：深色模式、手机宽度、Cloud 看板上的同一张卡、在 GitHub 上看同一张卡。
