# 在运行办公室里看每个 Agent 穿着自己的职业装

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：新装看板，#2「给导出加一个 CSV 选项」，一个项目自建 Agent `release-notes`；对 #2 起了七次专项运行：文案与文档、竞品调研已结束，界面设计师、产品配图、技术选型顾问、Release notes、邮件策划还在跑。
- **Agent**：运行由本目录的替身 `claude` 顶替（不连模型）；`seed.sh` 自己把它放到 PATH 最前。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截办公室窗口。

## Steps

1. 点右上角的「运行历史」（波形图标）。
   办公室里五张桌前各坐一个背对你的机器人，穿着各自的职业装：邮件策划天蓝外套斜挎邮包，技术选型顾问棕色外套，产品配图戴宽檐草帽、背后一块画板，界面设计师橙色贝雷帽、淡紫罩衫；Release notes 是没穿职业装的黑色机器人，左臂一枚「R」徽标。屏幕按工作分：界面设计师的是设计画布，邮件策划、技术选型顾问的是文稿，Release notes 的是代码。已结束的竞品调研（猎鹿帽、卡其风衣）和文案与文档并排坐在右下角沙发上，脸朝你。左下角「5 个运行中」。
   ![办公室](01-office.png)
   [办公室文字与运行列表](01-office.log)

2. 办公室开着，在命令行对 #2 再起一次 `akb spec prompt-writer 2`。
   几秒内一个深蓝制服的机器人从左下角走进来，名牌「提示词撰写」，侧身迈步走到空桌前，转成背影打字；左下角变成「6 个运行中」。
   ![走进来](02-walk-in.gif) · ![走路中的一帧](02-walking.png)

3. 等它坐定。
   提示词撰写坐在第二排第二张桌前，背后深蓝制服上的星星图案看得清，屏幕亮起。
   ![坐到桌前](03-prompt-writer-at-desk.png)
   [办公室文字](03-prompt-writer-at-desk.log)

## Feedback

- **办公室终于像个团队**：以前一屋子同一个机器人，现在背影就分得出谁在干什么，帽子和背后的包、画板在实际大小下也清楚。
- **屏幕内容是好细节**：设计师对着画布、写文档的对着文稿，一眼知道它在做哪类活。
- **自建 Agent 太素**：Release notes 是一只全黑机器人，背对时臂上的「R」很小，和别人的彩色衣服放在一起像没做完；几个自建 Agent 同时跑时只能靠名牌分。
- **名牌被截断**：「Release n…」「技术选型…」名字一长就截，要点开才知道是谁。
- **没有跑到的**：真实 Agent 的运行（这里是替身）、走出办公室、点机器人打开日志、深色模式、桌面应用、减少动态效果。
