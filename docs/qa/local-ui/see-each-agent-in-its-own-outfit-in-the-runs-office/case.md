# 在运行办公室里看每个 Agent 穿着自己的职业装

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：新装看板，#2「给导出加一个 CSV 选项」，一个项目自建 Agent `release-notes`；对 #2 起了七次专项运行：文案与文档、竞品调研已结束，界面设计师、产品配图、技术选型顾问、Release notes、邮件策划还在跑。
- **Agent**：运行由本目录的替身 `claude` 顶替（不连模型），默认干 3 秒就收工；`seed.sh` 自己把它放到 PATH 最前，下面的 `akb` 命令也要带上它。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截办公室窗口。

## Steps

1. 点右上角的「运行历史」（波形图标）。
   办公室里五张桌前各坐一个背对你的机器人，穿着各自的职业装：邮件策划天蓝外套斜挎邮包，技术选型顾问棕色外套，产品配图戴宽檐草帽、背后一块画板，界面设计师橙色贝雷帽、淡紫罩衫；Release notes 是没穿职业装的黑色机器人，左臂一枚「R」徽标。屏幕按工作分：界面设计师的是设计画布，邮件策划、技术选型顾问的是文稿，Release notes 的是代码。已结束的竞品调研（猎鹿帽、卡其风衣）和文案与文档并排坐在右下角沙发上，脸朝你。左下角「5 个运行中」。
   ![办公室](01-office.png)
   [办公室文字与运行列表](01-office.log)

2. 办公室开着，在命令行对 #2 再起一次 `akb spec prompt-writer 2`。
   一秒内一个深蓝制服的机器人从左下角走进来，名牌「提示词撰写」，沿过道一路朝右迈步，每一帧都朝右，再上行到空桌前；左下角变成「6 个运行中」。
   ![走进来](02-walk-in.gif) · ![走路中的一帧](02-walking.png) · ![连续 21 帧都朝右](02-facing-right.png)

3. 看它坐定。
   提示词撰写坐在第二排第二张桌前，转成背影打字，深蓝制服上的星星图案看得清，屏幕亮起。
   ![坐到桌前](03-prompt-writer-at-desk.png)

4. 等替身收工（约 3 秒）。
   提示词撰写起身朝右走到沙发；沙发上先结束的那位（这次是文案与文档）让出座位，下到过道后一路朝左走出左下角的门，整段每一帧都朝左，不来回翻转。左下角回到「5 个运行中」，沙发上是提示词撰写和竞品调研。
   ![走出去](04-walk-out.gif) · ![离场连续 44 帧都朝左](04-facing-left.png) · ![走后的办公室](04-after.png)
   [走后的办公室文字与运行列表](04-after.log)

## Feedback

- **办公室终于像个团队**：背影就分得出谁在干什么，帽子和背后的包、画板在实际大小下也清楚；屏幕内容（画布、文稿、代码）也一眼说明它在做哪类活。
- **走路朝向稳了**：进场朝右、离场朝左，按 15 帧/秒连拍没有一帧朝反，看着就是在走而不是在原地抽搐。
- **收工有点仓促**：桌前坐不到几秒就起身去沙发，同时沙发上的人被挤出门，两个机器人交错走，第一次看会以为出了什么事。
- **自建 Agent 太素**：Release notes 是一只全黑机器人，臂上的「R」很小，和别人的彩色衣服放在一起像没做完。
- **名牌被截断**：「Release n…」「技术选型…」名字一长就截，要点开才知道是谁。
- **没有跑到的**：自建 Agent（带「R」徽标）走路时徽标跟着镜像——这次走动的都不是它；真实 Agent 的运行（这里是替身）、点机器人打开日志、深色模式、桌面应用、减少动态效果。
