# 在卡片上把原片和复刻放在一起对比

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「对比发布会片头的原片和复刻」（需要 ffmpeg；脚本打印卡号，本次用一个新项目，这张是 #2）。脚本生成一段 6 秒、960×540、带 440 Hz 提示音的原片和色相偏移、带 660 Hz 提示音的复刻，两张横版截图、两张 540×960 的竖版图，以及三镜的 `shots.json`（S1 标志淡入 0–2 秒、S2 标题滑入 2–4.5 秒、S3 收尾定格 4.5–6 秒）。正文依次是：带 `shots` 和 `a-label`/`b-label` 的视频 `<Compare>`「原片与复刻」，带两边标签的图片 `<Compare>`「第 1 秒」，不带两边标签的竖版图片 `<Compare>`「竖版封面」。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截对比块（放大后截整个窗口）；播放和声音用视频元素的状态日志代替录屏。

## Steps

1. 打开 `/2`，滚到「原片与复刻」。
   白色外框，标题行左边是可折叠的「原片与复刻」，右边只有「查看原尺寸」和「更多」（⋯）两个图标。「原片」在上、「复刻」在下，各 752×340，没有圆角和边框；左上角的名字标签旁各有一个喇叭：原片是亮的音量图标，复刻是半透明的静音图标。下面一条播放条分成三段（宽 239、298、179，按时长），再下面是「‹ ▶ ›」「S1 / 3 · 标志淡入」「0:00 / 0:06」「1×」。原片有声、复刻静音，都没有自带控制条。
   ![对比块](01-video-compare.png)
   [布局与状态](01-video-layout.log)

2. 点播放键，3 秒后再点一次。
   两段一起播，复刻与原片相差不到 0.2 秒；过 2 秒时文字换成「S2 / 3 · 标题滑入」，播放条第一段填满、第二段接着走。再点一次两段同时停在 3.3 秒左右。
   ![播放中](02-playing-shot-2.png)
   [每 0.5 秒的采样](02-play-together.log)

3. 鼠标停在播放条的第三段上。
   这一段变灰，上方出现深色气泡「S3 · 收尾定格 · 0:05」。
   ![悬停第三段](03-hover-s3.png)
   [气泡文字](03-hover-a-shot.log)

4. 点第三段，然后点三次「上一镜」，再点一次「下一镜」。
   点第三段两边都跳到 4.5 秒（「S3 / 3 · 收尾定格」）；「上一镜」依次跳到 2 秒、0 秒，在第一镜上再点不动；「下一镜」跳回 2 秒。
   [每次点击后的状态](04-jump-by-shot.log)

5. 点「1×」，播放 1 秒后暂停，再连点三次。
   变成「1.5×」，两段视频的播放速率都是 1.5；再点依次是 2、0.5、1。
   [倍速](05-speed.log)

6. 鼠标停在复刻的喇叭上，点它，播放一会儿；再点一次复刻的喇叭，然后再点一次。
   悬停提示「取消静音」。点后复刻出声、原片自动静音，两个图标对调；播放时也只有复刻有声。再点复刻的喇叭两边都静音（两个都是半透明的静音图标）；又点一次复刻重新出声。
   ![悬停复刻的喇叭](06-unmute-tip.png)
   ![复刻出声](06-clone-heard.png)
   [每次点击后两边的静音状态](06-speakers.log)

7. 复刻出声时点「查看原尺寸」，在预览里点原片的喇叭，然后按 Esc。
   当前页面上盖一层深色遮罩，中间是同一个对比块（上下两边各 1312×355，画面居中、两侧黑边），右上角一个 ✕；卡片里的两段视频随即暂停。预览沿用卡片里的选择：复刻出声、原片静音。预览里点原片的喇叭后改成原片出声；按 Esc 关闭预览，焦点回到「查看原尺寸」，卡片里也已是原片出声、复刻静音。预览从 0:00、S1 开始，不接着卡片里的进度。
   ![放大后的预览](07-full-size.png)
   [预览里的状态与关闭后](07-full-size.log)

8. 点「更多」（⋯）。
   菜单里两项「下载「原片」」「下载「复刻」」（对比块的 `a-label`/`b-label`）；各自下载到的 `source.mp4`、`clone.mp4` 与卡片里的原文件逐字节相同。
   ![下载菜单](08-download-menu.png)
   [菜单和下载到的文件](08-download.log)

9. 滚到「第 1 秒」。
   两张截图上下排，各 752×340，左上角是「原片」「复刻」；没有播放条，也没有喇叭。
   ![横版图片](09-landscape-images.png)
   [两组图片的布局](09-images.log)

10. 滚到「竖版封面」。
    两张竖图左右并排，各 375×667；没写两边标签，标签显示文件名 `phone-source.png`、`phone-clone.png`。
    ![竖版图片](10-portrait-images.png)
    [两组图片的布局](09-images.log)

## Feedback

- **终于能听复刻了**：每边一个喇叭，点哪边就听哪边，另一边自动静音，不会两边同时响；放大前后选择不变，切来切去不用重设。
- **标题行清爽多了**：只剩「查看原尺寸」和「⋯」，下载收进菜单并写明「下载「原片」」，比原来两个无字图标好认；代价是下载多点一下。
- **审复刻依旧顺手**：两边同步，进度条按镜头切开，上一镜/下一镜比拖进度条准。
- **喇叭小、点错风险低但不显眼**：图标 13px、贴在名字标签里，第一次用不一定注意到复刻那边能点；静音的一边半透明，在亮色画面上更难看清。
- **放大后从头播**：预览是另一组播放器，在卡片里看到第 3 镜点放大，预览又回到 0:00；两侧大片黑边，画面并没有大多少。
- **气泡时间四舍五入**：S3 从 4.5 秒开始，气泡写「0:05」，与 `shots` 里的 4.5 对不上。
- **没有跑到的**：真的用耳朵听（只读了视频元素的静音状态）、图片对比块的放大、侧滑返回关闭、`shots` 写错时的提示、拖动进度条、两段时长不一、桌面版、手机宽度、英文界面。
