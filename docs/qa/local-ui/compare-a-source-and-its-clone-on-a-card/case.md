# 在卡片上把原片和复刻放在一起对比

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「对比发布会片头的原片和复刻」（需要 ffmpeg；脚本打印卡号，本次与「找到「视频克隆」工作流」共用一个项目，这张是 #6）。脚本生成一段 6 秒、960×540 的原片和色相偏移后的复刻、两张横版截图、两张 540×960 的竖版图，以及三镜的 `shots.json`（S1 标志淡入 0–2 秒、S2 标题滑入 2–4.5 秒、S3 收尾定格 4.5–6 秒）。正文依次是：带 `shots` 和 `a-label`/`b-label` 的视频 `<Compare>`「原片与复刻」，带两边标签的图片 `<Compare>`「第 1 秒」，不带两边标签的竖版图片 `<Compare>`「竖版封面」。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。截图只截对比块；播放用视频元素的状态日志代替录屏。

## Steps

1. 打开 `/6`，滚到「原片与复刻」。
   左上角是标签「原片与复刻」，右上角一个放大按钮；「原片」在上、「复刻」在下，各 752×340，左上角各有名字标签，没有圆角和边框。下面一条播放条分成三段（宽 239、298、179，按时长），下方是「‹ ▶ ›」「S1 / 3 · 标志淡入」「0:00 / 0:06」「1×」。原片有声，复刻静音，都没有自带控制条。
   ![对比块](01-video-compare.png)
   [布局与状态](01-video-layout.log)

2. 点播放键，3 秒后再点一次。
   两段一起播，复刻与原片的时间差保持在 0.03 秒内；过 2 秒时文字换成「S2 / 3 · 标题滑入」，进度条第一段填满、第二段接着走。再点一次两段同时停在 3.13 秒。
   ![播放中](02-playing-shot-2.png)
   [每 0.5 秒的采样](02-play-together.log)

3. 鼠标停在播放条的第三段上。
   这一段变灰，上方出现深色气泡「S3 · 收尾定格 · 0:05」。
   ![悬停第三段](03-hover-s3.png)
   [气泡文字](03-hover-a-shot.log)

4. 点第三段，然后点三次「上一镜」，再点一次「下一镜」。
   点第三段两边都跳到 4.5 秒（「S3 / 3 · 收尾定格」）；「上一镜」依次跳到 2 秒、0 秒，在第一镜上再点不动；「下一镜」跳回 2 秒。
   [每次点击后的状态](04-jump-by-shot.log)

5. 点「1×」，播放 1 秒后暂停，再连点三次。
   变成「1.5×」，两边一起按 1.5 倍播（1 秒走了 1.5 秒）；再点依次是 2、0.5、1。
   [倍速](05-speed.log)

6. 点右上角的放大按钮，再按 Esc。
   整个对比块全屏，上下两边各 1440×390，播放条在底部。无头 Chrome 里按 Esc 没有退出全屏（无头浏览器不处理这个键），改用 `document.exitFullscreen()` 退出；真实浏览器里的 Esc 没有验证。
   ![全屏](06-full-size.png)
   [全屏尺寸](06-full-size.log)

7. 滚到「第 1 秒」。
   两张截图上下排，各 752×340，左上角是「原片」「复刻」；没有播放条。
   ![横版图片](07-landscape-images.png)
   [两组图片的布局](07-images.log)

8. 滚到「竖版封面」。
   两张竖图左右并排，各 375×667；没写两边标签，标签显示文件名 `phone-source.png`、`phone-clone.png`。
   ![竖版图片](08-portrait-images.png)
   [两组图片的布局](07-images.log)

## Feedback

- **审复刻终于顺手**：两边始终同步，进度条按镜头切开、当前镜头的编号和名字一直显示，可以直接说「S2 不对」；上一镜/下一镜比拖进度条准得多。
- **排法自动且合理**：横版上下、竖版左右，一屏内两边都看得全，不用自己切换。
- **气泡时间四舍五入**：S3 从 4.5 秒开始，气泡和计时都写「0:05」，与 `shots` 文件里的 4.5 对不上，短镜头多时会让人以为跳错了位置。
- **只有原片出声**：复刻固定静音，要听复刻的配乐或音效对不对，卡片上做不到。
- **放大按钮没有文字**：右上角只有图标，悬停才知道是「查看原尺寸」，而它其实是全屏。
- **没有跑到的**：`shots` 文件写错时退回普通进度条、图片与视频混用时的提示、拖动进度条、两段时长不一时复刻停在最后一帧、真实浏览器的 Esc、桌面版、手机宽度、英文界面。
