# 在卡片上把原片和复刻放在一起对比

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「对比发布会片头的原片和复刻」（需要 ffmpeg；脚本打印卡号，本次用一个新项目，这张是 #2）。脚本生成一段 6 秒、960×540 的原片和色相偏移后的复刻、两张横版截图、两张 540×960 的竖版图，以及三镜的 `shots.json`（S1 标志淡入 0–2 秒、S2 标题滑入 2–4.5 秒、S3 收尾定格 4.5–6 秒）。正文依次是：带 `shots` 和 `a-label`/`b-label` 的视频 `<Compare>`「原片与复刻」，带两边标签的图片 `<Compare>`「第 1 秒」，不带两边标签的竖版图片 `<Compare>`「竖版封面」。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。截图只截对比块（放大后截整个窗口）；播放用视频元素的状态日志代替录屏。

## Steps

1. 打开 `/2`，滚到「原片与复刻」。
   左上角是可折叠的标签「原片与复刻」，右上角是放大和下载两个按钮；「原片」在上、「复刻」在下，各 752×340，左上角各有名字标签，没有圆角和边框。下面一条播放条分成三段（宽 239、298、179，按时长），下方是「‹ ▶ ›」「S1 / 3 · 标志淡入」「0:00 / 0:06」「1×」。原片有声，复刻静音，都没有自带控制条。
   ![对比块](01-video-compare.png)
   [布局与状态](01-video-layout.log)

2. 点播放键，3 秒后再点一次。
   两段一起播，复刻比原片慢约 0.06 秒、一直不变；过 2 秒时文字换成「S2 / 3 · 标题滑入」，进度条第一段填满、第二段接着走。再点一次两段同时停在 3.2 秒左右。
   ![播放中](02-playing-shot-2.png)
   [每 0.5 秒的采样](02-play-together.log)

3. 鼠标停在播放条的第三段上。
   这一段变灰，上方出现深色气泡「S3 · 收尾定格 · 0:05」。
   ![悬停第三段](03-hover-s3.png)
   [气泡文字](03-hover-a-shot.log)

4. 点第三段，然后点三次「上一镜」，再点一次「下一镜」。
   点第三段两边都跳到 4.5 秒（「S3 / 3 · 收尾定格」）；「上一镜」依次跳到 2 秒、0 秒，在第一镜上再点不动；「下一镜」跳回 2 秒。
   [每次点击后的状态](04-jump-by-shot.log)

5. 点「1×」，播放 1 秒后暂停，再连点三次。
   变成「1.5×」，两边一起按 1.5 倍播（1 秒走了 1.5 秒）；再点依次是 2、0.5、1。
   [倍速](05-speed.log)

6. 再点播放，1 秒后点右上角的放大按钮；然后按 Esc。
   不进系统全屏：当前页面上盖一层深色遮罩，中间是同一个对比块（1312×808），右上角一个 ✕；卡片里的两段视频随即暂停。预览的标题行只有标签和下载按钮；上下两边各 1312×355（画面按比例居中，两侧是黑边），播放条在底部，从 0:00、S1 开始，不接着卡片里的进度。焦点在 ✕ 上，Tab 在 ✕、下载、上一镜、播放、下一镜、倍速之间循环，不跑到预览外。按 Esc 预览关闭，焦点回到放大按钮，卡片里的进度还在 4.57 秒。点 ✕、点遮罩也一样关闭并把焦点还给放大按钮。
   ![放大后的预览](06-full-size.png)
   [预览尺寸、焦点和三种关闭](06-full-size.log)

7. 点放大按钮右边的下载按钮，分别选「原片」「复刻」。
   下载按钮变成橙色，下面弹出两项「原片」「复刻」（对比块的 `a-label`/`b-label`）。选中后浏览器各下载一个文件：`source.mp4`、`clone.mp4`，与卡片里的原文件逐字节相同。
   ![下载菜单](07-download-menu.png)
   [菜单和下载到的文件](07-download.log)

8. 滚到「第 1 秒」。
   两张截图上下排，各 752×340，左上角是「原片」「复刻」；没有播放条。
   ![横版图片](08-landscape-images.png)
   [两组图片的布局](08-images.log)

9. 滚到「竖版封面」。
   两张竖图左右并排，各 375×667；没写两边标签，标签显示文件名 `phone-source.png`、`phone-clone.png`。
   ![竖版图片](09-portrait-images.png)
   [两组图片的布局](08-images.log)

## Feedback

- **审复刻终于顺手**：两边始终同步，进度条按镜头切开、当前镜头的编号和名字一直显示，可以直接说「S2 不对」；上一镜/下一镜比拖进度条准得多。
- **放大不再吓人**：放大只是在当前页面盖一层，Esc、✕、点遮罩都能回来，焦点也回到原处；卡片里的视频自动暂停，不会两边同时出声。
- **放大后从头播**：预览是另一组播放器，在卡片里看到第 3 镜点放大，预览又回到 0:00，得重新跳到 S3；回到卡片后原来的位置倒是还在。
- **放大后的画面不够大**：上下排时每边只有半屏高，横版视频在 1440 宽的窗口里只占中间约一半宽，两侧大片黑边。
- **下载一步到位**：两项直接用「原片」「复刻」命名，下到的就是原文件、文件名不变；但标题行两个图标都没有文字，要悬停才知道哪个是下载。
- **气泡时间四舍五入**：S3 从 4.5 秒开始，气泡和计时都写「0:05」，与 `shots` 文件里的 4.5 对不上。
- **只有原片出声**：复刻固定静音，要听复刻的配乐或音效对不对，卡片上做不到。
- **没有跑到的**：图片对比块的放大和下载、侧滑返回关闭、`shots` 文件写错时退回普通进度条、图片与视频混用时的提示、拖动进度条、两段时长不一时复刻停在最后一帧、桌面版、手机宽度、英文界面。
