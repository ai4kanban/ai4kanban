# 在「搁置」列里找出放了好几天没动的卡

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：设置已完成，模块 `web`、`api`；#2「导出 CSV」（待执行，刚写）、#3「深色模式」（未就绪，12 天前写）、#4「批量导入」（待执行，7 天前写），以及分组 #5「账号设置」——根卡和子卡 #6「修改头像」20 天前写、子卡 #7「修改密码」8 天前写。看板按卡片文件的修改时间判断，`seed.sh` 把文件时间往前拨。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900，界面语言中文；第 5 步换成 390×844 的手机宽度，第 6 步把机器设置的 `language` 改成 `en` 并重启看板 UI。

## Steps

1. 打开看板，把列横向滚到最右。
   第三列「搁置」出现在「待执行」「未就绪」右边，列头底色比另两列深一档、圆点深灰（「待执行」绿点，「未就绪」灰点），计数 3。列里是一张一行的卡，按搁置天数从久到短：#3「12 天」、#5「8 天」、#4「7 天」；卡脚写着模块（· WEB / · API）和带钟表图标的天数。#4 虽是待执行也在这里；分组 #5 按组内最近一次改动（子卡 #7，8 天前）计天数，不按根卡的 20 天。
   ![三列和搁置列](01-stale-column.png)

2. 把鼠标停在 #3 的「12 天」上。
   提示气泡「12 天没有变动」。
   ![天数的提示](02-days-tip.png)

3. 在编辑器里给 #3 的正文加一行并保存，不刷新页面。
   约 7 秒内 #3 离开「搁置」，回到「未就绪」的 WEB 分带，卡脚不再有天数；「搁置」计数变成 2。
   ![改过的卡回到原列](03-edited-card-left-stale.png)

4. 只给分组里的子卡 #7 正文加一行并保存，不动根卡。
   约 8 秒内根卡 #5 也离开「搁置」，回到「未就绪」；「搁置」只剩 #4「7 天」。
   ![子卡一动，整组回到原列](04-group-left-stale.png)

5. 换成手机宽度，点列头右侧第三个圆点。
   页头变成深一档的灰底「● 搁置 1」，下面是 #4，卡脚「· API」「7 天」。
   ![手机上的搁置页](05-phone-stale-page.png)

6. 换成英文界面，横向滚到最右，鼠标停在 #4 的天数上。
   列名「STALE」，天数写「7d」，提示气泡「Untouched for 7 days」。
   ![英文界面](06-english.png)

## Feedback

- **一眼分得出急活和陈卡**：放了一周以上的卡单独成列、最久的在最上，卡脚直接写天数；不用再一张张点开看最后改动时间。
- **分组按整组算是对的**：子卡还在推进时根卡留在原列，天数也按最近一次改动算，不会把正在做的分组误判成搁置。
- **一改就回去，不用手动挪**：改正文就够，几秒后自己归位；但这一列没有「我看过了、先留着」的办法，想留着不做又不想看到它，只能随便改一笔。
- **1440 宽的窗口看不全**：三列加起来比窗口宽，「搁置」默认只露出一条边，要横向滚才看得到；不知道有第三列的人可能一直不会去滚。
- **英文提示被窗口切掉**：最右一列的天数提示贴着窗口右缘弹出，「Untouched for 7 days」只露出「Untouched for 7 d」（中文「12 天没有变动」短，刚好放得下）。
- **刚打开的那一下会漏**：页面刚打开一两秒内改了卡片文件，这次改动不会刷新列，要等下一次改动或手动刷新；本场景第 3 步之前先等了 10 秒。
- **没有跑到的**：Cloud 看板（读 `updatedAt`）、执行中或有交付在跑的卡不进「搁置」、搁置列为空时的「没有搁置的卡片」都没有在这里验证；重新克隆或切换分支后所有卡都算刚改过，这一点也只在卡片上读到。
