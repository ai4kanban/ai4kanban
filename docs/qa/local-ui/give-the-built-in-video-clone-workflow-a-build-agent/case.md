# 不复制，直接给内置的「视频克隆」工作流设置或移除执行 Agent

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：新装看板，#2「把审阅过的片头模板发到共享模板库」已规划好、状态是待执行，工作流是内置的「视频克隆」，有一条未勾的待办。
- **账号**：本机已登录 Cloud，是 Pro。Cloud 由 [stand-in.mjs](../give-a-copied-video-clone-workflow-a-build-agent/stand-in.mjs) 顶替，登录是手写的 `session.json`。
- **Agent**：PATH 最前放一个替身 `claude`（被问登录状态时答已登录，被叫去运行时答「Done (stand-in).」），打开界面不会起真实的 setup 运行。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截「配置」窗口或卡片页。

## Steps

1. 点右上角的「配置」，再点左栏「工作流」，在中间一栏顶上的下拉里选「视频克隆」。
   中间三个框：「规划」（视频克隆、规划助手）、「执行」（只有一个「+ 设置 Agent」按钮，没有「不可用」之类的警示）、「定期运行」。「视频克隆」是胸前叠着两条胶片的专属角色，不是首字母卡片。
   ![内置的视频克隆](01-built-in.png)
   [三个框的文字与角色图](01-stages.log)

2. 点「设置 Agent」。
   「执行」框里出现「视频克隆 executor」并被选中，行尾只有一个 ×（「移除 Agent」），没有换人的箭头；右侧是它的 `AGENT.md`（`docs/kanban/agents/video-clone-executor/AGENT.md`），标题旁写「你添加的」和「删除」。规划那一侧不变。
   ![设好执行 Agent](02-executor.png)
   [设好之后](02-executor.log)

3. 按 Esc 关掉「配置」，打开 #2。
   标题旁是「可以开始执行」，工具栏有「执行」「修订」「移除」，「工作流」写「视频克隆」。
   ![卡片可以执行](03-card-can-build.png)
   [卡片页文字](03-card.log)

4. 回到「配置 → 工作流 → 视频克隆」，点执行框里的「视频克隆 executor」，在右侧点「删除」，再在确认框里点「删除」。
   确认框只有「取消」「删除」。删掉后「执行」框回到「+ 设置 Agent」，`docs/kanban/agents/` 空了。
   ![确认删除](04-confirm-delete.png)
   ![删掉之后](04-deleted.png)
   [删除前后](04-deleted.log)

5. 再点「设置 Agent」，然后点新 Agent 行尾的 ×；关掉「配置」打开 #2。
   × 不弹确认框，直接把这个 Agent 删掉：「执行」框回到「+ 设置 Agent」，`docs/kanban/agents/` 空了。#2 的工具栏变回「细化」「修订」「移除」，没有「执行」；标题旁仍是「可以开始执行」。
   ![行尾的 ×](05-set.png)
   ![移除之后](05-removed.png)
   ![卡片没有执行了](05-card-after-remove.png)
   [每一步的文字](05-removed.log)

6. 回到「配置 → 工作流 → 视频克隆」，再点「设置 Agent」。
   1 秒内「执行」框里出现一个全新的「视频克隆 executor」，`docs/kanban/agents/` 里又有了 `video-clone-executor`。
   ![再设一次](06-set-after-remove.png)
   [每秒的执行框](06-set-after-remove.log)

7. 旧版本留下的文件夹：点 × 移除后，在命令行把 `docs/kanban/agents/video-clone-executor/AGENT.md` 放回去（描述改成「旧看板上留下的执行 Agent，上传片头模板。」），重新打开「配置 → 工作流 → 视频克隆」，点「设置 Agent」。
   1 秒内「执行」框里是「视频克隆 executor」，右侧是放回去的那份 `AGENT.md`，描述原样保留；看板顶部没有报错。
   ![接回留下的文件夹](07-leftover-folder.png)
   [每秒的执行框与看板顶部](07-leftover-folder.log)

## Feedback

- **不用复制了**：内置的视频克隆直接点「设置 Agent」就能接着执行，卡片立刻出现「执行」；规划那一侧仍锁着，不会被误改。
- **一格一件事**：执行格不再能换成「开发」等别的 Agent，只剩「设置」和行尾 ×，不会再走进换人后设不回来的死路。
- **旧看板自愈**：以前留下的 `video-clone-executor` 文件夹会被直接接回，写过的提示词也还在。
- **× 即删除，没有确认**：行尾 × 会连提示词一起删掉、无法撤销，却不像右侧的「删除」那样先问一句；写过提示词的人一不小心就没了。
- **卡片状态没跟上**：移除执行 Agent 后 #2 仍标「可以开始执行」，工具栏却没有「执行」，读起来自相矛盾。
- **没有跑到的**：真的执行一次（另一个场景跑过副本的）、旧看板里执行格已被换成「开发」时的样子、其他四个内置工作流、英文界面。
