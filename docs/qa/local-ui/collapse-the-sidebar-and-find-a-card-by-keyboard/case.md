# 收起侧边栏，再只用键盘从搜索打开一张卡

## Setup

- **看板**：一次性 git 项目，`akb install` 新建，删掉 `setup-checklist.md`；再用 `akb raw create` 建 #3「Export a card as PDF」、#4「Export the board as CSV」、#5「Export archived cards」（只有标题，正文是模板占位）。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900，界面语言中文，已跳过欢迎导览；先清空页面的 `localStorage`，侧边栏是展开的。

## Steps

1. 鼠标移到顶栏标志右侧的侧边栏图标上。
   出现提示「收起侧边栏」。
   ![悬停提示](01-hover.png)

2. 点这个图标，再点一次。
   侧边栏的宽度平滑收到 0，看板跟着变宽，提示变成「展开侧边栏」；再点一次侧边栏平滑展开回原来的宽度。
   ![收起再展开](02-collapse-expand.gif)

3. 收起侧边栏后刷新页面。
   刷新后侧边栏仍是收起的。
   ![刷新后](03-after-reload.png)

4. 展开侧边栏，点一下看板空白处，按 `/`，输入 `export`。
   搜索框获得焦点（`/` 本身没有输进去），左栏换成「匹配结果 3」：#3、#4、#5；看板本身不筛选。
   ![按 / 搜索](04-search.png)

5. 按两次 ↓。
   高亮从 #3 移到第二行 #4「Export the board as CSV」，光标还在搜索框里。
   ![方向键移动高亮](05-arrow-down.png)

6. 按回车。
   打开 #4 的卡片页，搜索框清空，左栏回到「全部卡片」。
   ![打开高亮的卡](06-opened.png)

## Feedback

- **全程不碰鼠标就能找卡**：`/`、↓、回车三步打开一张卡，熟悉命令面板的人会觉得顺手。
- **收起按钮位置自然**：紧挨标志，提示文案随状态切换；刷新后记得上次的选择，不用每次再收。
- **看不出能用键盘**：搜索框占位只写「查找卡片」，没有 `/` 的提示，也看不出能用方向键选，这些快捷键要靠自己发现。
- **搜索只筛左栏**：输入关键词后看板上的卡片一张不少，眼睛容易先去看板上找。
- **没有跑到的**：窄屏（按钮不显示）；减少动态效果；讨论行的出现和收起；⋯ 菜单和记忆文件夹的展开。
