# 在归档页按交付时间或创建时间排序

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：归档里六张卡，交付日期与编号顺序不同——#6「卡片搜索」和 #3「深色模式」同在 2026-10-12，#2 在 10-10，#5 在 10-08，#7 在 10-01，#4「批量移动卡片」没有归档日期。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1280×800，界面语言中文。

## Steps

1. 打开 `/archive`。
   标题行右侧是两个选项「交付时间 ↓」「创建时间 ↓」，「交付时间」选中。卡片按交付日期从新到旧：#6、#3（同一天，编号大的在前）、#2、#5、#7；下面一条分隔线「在看板开始记录归档日期之前完成」，其下是没有日期的 #4。
   ![按交付时间](01-by-delivery.png)
   [选项与行顺序](01-by-delivery.log)

2. 点「创建时间」。
   页面不刷新，直接按编号从大到小重排：#7、#6、#5、#4、#3、#2；分隔线消失，日期列仍是各卡的交付日期，#4 那一行留空。
   ![按创建时间](02-by-creation.png)
   [选项与行顺序](02-by-creation.log)

3. 刷新页面。
   回到「交付时间」排序，顺序与第 1 步相同，上次选的「创建时间」没有被记住。
   ![刷新后](03-reopened.png)
   [选项与行顺序](03-reopened.log)

## Feedback

- **终于能看最近交付了什么**：默认就是交付时间，打开即见最新落地的卡，不用在编号里翻。
- **按创建时间时日期列有点误导**：列里还是交付日期，排序却按编号，日期上下乱跳（10-01 排在 10-12 前），第一次看会以为排错了；列头没有说明这是哪种日期。
- **↓ 像是能点的**：两个选项都带向下箭头，看起来能点一下反转顺序，其实只是"最近在前"的固定标记。
- **不记住选择**：习惯按创建时间看的人每次进来都要再点一次。
- **没有跑到的**：英文界面、Cloud 看板、手机宽度、几百张卡的大归档。
