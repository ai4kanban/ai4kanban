# 在桌面应用的账单面板里先免费试用 Pro 7 天，试用结束后再购买

## Setup

- **账号**：本机已登录 Cloud，从没用过 Pro（没试用、没订阅、没拿过赠送）。
- **本次证据的来源**：本分支的看板界面（`kanban-ui`）在浏览器里对着 `get-notified-without-signing-in` 的 `seed.sh` 建的临时看板实跑，视口 1440×900，界面语言中文；账单面板与桌面应用里的是同一个组件。[stand-in.mjs](stand-in.mjs) 顶替 Cloud：开始试用等 1.5 秒才答，`/_set?state=ended` 让试用到期；结账答一个编的链接。登录是手写的 `session.json`，没有走真实登录和 Creem。

## Steps

1. 打开「配置 → 账单」。
   「当前套餐」是「免费版 $0」和「升级」；没有「AI 积分」卡片，发票一栏「暂无发票」。
   ![从没用过 Pro](01-never-tried.png)
   [页面文字](01-never-tried.log)

2. 点「升级」。
   免费版和 Pro 并排；免费版的按钮是灰的「当前套餐」，Pro 的主按钮是「免费试用 7 天」，没有「购买 Pro」。
   ![套餐页，未试用](02-plans.png)
   [页面文字与按钮](02-plans.log)

3. 点「免费试用 7 天」。
   按钮变淡、不可再按，文字换成「正在开始试用…」。
   ![正在开始试用](03-starting.png)
   [按钮](03-starting.log)

4. 等 Cloud 答完。
   自动回到账单页：「Pro」旁一个绿色「试用中」，下面「还剩 7 天 · 2026年10月28日结束」；「AI 积分」1,000 / 1,000 剩余，右边「不按月重置」。页面上没有「升级」或任何购买按钮。
   ![试用中](04-trialing.png)
   [页面文字与按钮](04-trialing.log)

5. 让试用到期，重新打开「账单」，点「升级」。
   账单页回到「免费版」和「升级」；套餐页 Pro 的主按钮变成「购买 Pro」，不再出现「免费试用 7 天」。
   ![试用结束后的套餐页](05-trial-over.png)
   [页面文字与按钮](05-trial-over.log)

6. 点「购买 Pro」。
   浏览器打开 Cloud 给的结账链接。
   [打开的链接](06-buy.log)

## Feedback

- **入口一眼明白**：套餐页上只有一个主按钮，没试用过就是「免费试用 7 天」，不用读说明就知道先试再买。
- **试用状态清楚**：「试用中」加「还剩 7 天」和结束日期，积分写明「不按月重置」，不会误以为每月有 1,000。
- **试用中买不了，也没说怎么买**：试用期账单页没有「升级」，想提前订阅的用户找不到入口，也看不到一句「试用结束后可购买」，只能自己猜。
- **开始试用没有确认**：一点就开始，回到账单页时没有任何「已开始试用」的提示，只是套餐换了；不留意会以为什么都没发生。
- **没有跑到的**：开始试用失败（「无法开始试用，请重试。」）、试用积分用完的提示、只剩 1 天、试用中同时有订阅或赠送、真实 Cloud 和 Creem、打包好的桌面应用本身、英文界面。
