# 右键卡片里的图片，复制或下载它

## Setup

- **看板**：用本目录的 `seed.sh` 往一次性项目里加一张卡「首页配图」（需要 ffmpeg 画图；脚本打印卡号，本次和另外三个场景共用一个项目，这张是 #4）。正文依次是：一个 `<Asset src=".assets/4/board-overview.png" label="看板总览" alt="看板首页：三列卡片，右侧是聊天面板" />`（黄底黑条，1200×675）；一张看板自己的 Markdown 图片 `![流程示意图](/asset-image/4/flow-diagram.png)`（青底黑条）；一张外链图片（Google 标志）。图片文件在 `.akb/boards/docs/kanban/assets/4/`。
- **浏览器**：无头 Chrome，下载用 `Browser.setDownloadBehavior` 存到一个空的临时目录；用 `Browser.grantPermissions` 给页面剪贴板读写权限。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/4`，在「看板总览」图上点右键。
   图片贴满白框，四周没有留白和阴影；指针处弹出看板样式的菜单，两项：「复制图片」「下载图片」。
   ![Asset 图片的右键菜单](01-asset-menu.png)

2. 点「下载图片」。
   临时目录里出现 `board-overview.png`，和看板里的原文件逐字节相同（图片地址带的 `?v=` 没进文件名）。
   [下载结果](02-download.log)

3. 再右键同一张图，点「复制图片」。
   图片右上角出现「✓ 已复制」，3 秒内消失；剪贴板里是一张 1200×675 的 `image/png`。
   ![已复制](03-copied-badge.png)

4. 右键下面的「流程示意图」（Markdown 图片），点「下载图片」。
   同样的两项菜单；下载得到 `flow-diagram.png`，与原文件逐字节相同。
   [菜单与下载结果](04-markdown-image.log)

5. 左键点「流程示意图」打开灯箱，在大图上点右键，再按两次 Esc。
   大图上弹出同样的菜单；第一次 Esc 只关掉菜单，灯箱还在，第二次才关灯箱。
   ![灯箱里的菜单](05-lightbox-menu.png)

6. 右键外链的 Google 标志。
   不出现看板菜单，页面也不拦截右键（`contextmenu` 没被 `preventDefault`），交给浏览器自己的菜单（无头 Chrome 不画原生菜单）。
   [右键结果](06-external.log)

7. 查看图片的替代文字。
   「看板总览」的 `alt` 是卡片里写的 `alt` 文字「看板首页：三列卡片，右侧是聊天面板」，不是 `label`「看板总览」；Markdown 图片和它的灯箱大图都是「流程示意图」。
   [各图片的 alt](07-alt.log)

8. 把界面语言换成英文（改机器设置），刷新后再右键「看板总览」。
   菜单变成「Copy image」「Download image」。
   ![英文菜单](08-english-menu.png)

## Feedback

- **顺手**：右键就在指针处出菜单，两项都一眼看懂；下载直接是原文件名，不再需要去 `.akb` 里翻原图。
- **两个下载入口**：标题行的 ⋯ 里也有「下载」（还有「复制绝对路径」），和右键的「下载图片」做的是同一件事，但右键菜单里没有复制路径，⋯ 里没有复制图片，要记两处。
- **「已复制」很克制**：位置在图片右上角，一两秒就走，不打断；但失败时什么都不显示，用户只能靠粘贴来确认。
- **Esc 分层对**：灯箱里先关菜单再关灯箱，没有一按全没。
- **外链图片没有任何提示**：同一张卡里有的图能右键下载、有的不能，用户看不出区别。
- **`label` 和 `alt` 不同时只看得到 `label`**：`alt` 只在读屏和 DOM 里，页面上看不出来写没写。
- **没有跑到的**：桌面版的另存为对话框；界面原型（TSX/HTML）的预览（只有图片挂菜单）；聊天里粘贴的图片打开后的灯箱；手机长按；把剪贴板里的图真正粘贴进外部应用（只在页面内读回了剪贴板）；非 PNG 图片转 PNG 后复制。
