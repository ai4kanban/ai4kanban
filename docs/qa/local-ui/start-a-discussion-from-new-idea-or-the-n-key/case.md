# 从「新想法」按钮或 N 键开始一段讨论

## Setup

- **看板**：一次性 git 项目，`akb install` 新建，删掉了 `setup-checklist.md`（设置已完成）。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900，界面语言中文。

## Steps

1. 鼠标停在右上角「新想法」按钮上。
   按钮上是灯泡、「新想法」和一个小号的「N」按键标记；下方出现提示「说个想法、问进度或安排卡片」。
   ![悬停新想法](01-hover-new-idea.png)

2. 点一下看板空白处，按 N。
   不点按钮也打开了新的讨论：标题「接下来该做什么？」，光标已在输入框里，输入框是空的（按下的 n 没有被打进去）。
   ![按 N 打开讨论](02-press-n.png)

3. 按 Esc 关上讨论，点左栏「查找卡片」，按 N。
   查找框里出现「n」，讨论没有打开。
   ![在查找框里按 N](03-n-in-search-box.png)

4. 把窗口换成手机宽度（390×844）。
   顶栏的「新想法」仍带文字，只是不再显示「N」标记。
   ![手机宽度的顶栏](04-phone-header.png)

## Feedback

- **一眼知道它能做什么**：提示一句话说清「想法、进度、安排卡片」三件事，比单看「新想法」三个字更不容易被当成「新建卡片」。
- **N 键顺手**：在看板上随手一按就能开口，输入时又不会误触；但除了按钮上的小「N」，没有别处告诉用户有这个快捷键。
- **手机上终于有字了**：不再只剩一个灯泡，能看懂。
- **没有跑到的**：手机宽度上点按查看提示；英文界面；对话框（如「配置」）打开时按 N。
