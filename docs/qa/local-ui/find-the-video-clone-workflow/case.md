# 找到「视频克隆」工作流，看它要什么

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：新装看板，#5「照着发布会片头做一个模板」的工作流是 `video-clone`。
- **账号**：没有登录 Cloud，不是 Pro。
- **Agent**：PATH 最前放 [stand-in-claude](../approve-a-stage-on-a-card/stand-in-claude)，改名为 `claude`，不放 `act.sh`：每次运行 3 秒后报完成，不改卡片。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。截图只截「配置」窗口或卡片正文。

## Steps

1. 点右上角的「配置」，再点左栏「工作流」，点中间一栏顶上的「软件开发」。
   下拉列表顶上是「查找工作流…」搜索框，下面六个内置工作流：「软件开发」带「默认」和勾，下面依次是「产品视频」「演示文稿」「社媒帖」「博客文章」「视频克隆」，都不带「Pro」或锁；最底下是「新建工作流」。
   ![工作流列表](01-workflow-list.png)
   [页面上的文字](what-the-page-says.log)

2. 鼠标停在「视频克隆」上。
   右侧出现深色气泡：「先确认原片拆解和复刻脚本，再拿到参考视频的复刻成片和可复用的视频模板，满意即可归档。」
   ![视频克隆的说明](02-description.png)
   [页面上的文字](what-the-page-says.log)

3. 点「视频克隆」。
   顶上换成「视频克隆」和「内置」，没有「Pro」；中间是「规划」框（领头的「视频克隆」，下面是「规划助手」和「+」）、只有一个「+ 设置 Agent」按钮的「执行」框，和「定期运行」框（「还没有定期运行的 Agent。」）。右侧是领头 Agent「视频克隆」：「复刻用代码制作的视频，做成保留拍法、可换内容的 beat 表模板，用你的内容渲染一支并与原片逐镜对比。」，「你的要求」的占位提示是「会附加到视频克隆卡片每次新建、细化和修订运行的末尾，例如「模板统一用 1080×1920 竖屏」。」
   ![视频克隆的领头 Agent](03-video-cloner.png)
   [页面上的文字](what-the-page-says.log)

4. 关掉「配置」，打开 #5。
   卡片的「工作流」一栏写着「视频克隆」；工具栏是「细化」「修订」「移除」，没有锁或「登录以使用 Pro」。
   ![没有 Pro 的视频克隆卡片](04-card.png)
   [页面上的文字](what-the-page-says.log)

5. 点「细化」，在弹出的「细化 #5」里再点「细化」。
   标题旁写「正在细化…」，运行日志展开，第一行「video-cloner starts each planning step in a new session」；3 秒后运行「已完成」，下面一句「#5 细化后仍在待办……」（替身没写计划）。
   ![没有 Pro 也能细化](05-refining.png)
   [对话框和运行前后的页面](05-refine.log)

## Feedback

- **列表名字跟上了**：下拉里原来的「图文轮播」已叫「社媒帖」，六个内置工作流的名字都是任务本身。
- **先知道要审两轮**：悬停说明一开头就写「先确认原片拆解和复刻脚本」，和演示文稿、博客文章的说明同一个句式；选工作流时就知道中途要停下来审稿，不会以为一次跑完。
- **说明和 Agent 简介说法不一**：工作流说明讲「原片拆解」「复刻脚本」，Agent 简介讲「beat 表模板」「逐镜对比」，两段话描述同一件事却用了两套词，「beat 表」对一般用户也太行话。
- **工作流和 Agent 同名**：工作流叫「视频克隆」，领头 Agent 也叫「视频克隆」，第 3 步里两个同名标题上下摆着，一时分不清在看哪个。
- **说明里没说要交什么**：卡片要靠描述里写一个本地 mp4 路径，这一点在列表、说明和 Agent 简介里都看不到；第一次用的人不知道参考视频从哪放进来。
- **空的「执行」框没解释**：执行框只有「+ 设置 Agent」，没说不设也行、规划里就会做完；第一次看会以为缺了一步。
- **免费用户不再被拦**：列表里没有一个「Pro」，卡片上直接是「细化」，点下就开跑；原来那颗带锁的「登录以使用 Pro」不见了。
- **托管素材的取舍看不到**：没有 Pro 时配乐会留空，但列表、说明和卡片上都没提，要等成品出来才知道。
- **没有跑到的**：真实 Agent 运行一张视频克隆卡，看它先交出两份分镜待审、批准后再出 `<Compare>` 对比（要一次真实运行；两份分镜在卡片上的样子见 [审视频复刻的两份分镜](../review-two-storyboards-one-shot-at-a-time/case.md)）；新想法面板里的工作流选择器；英文界面。
