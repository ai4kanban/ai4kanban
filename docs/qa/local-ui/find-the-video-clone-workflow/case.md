# 找到「视频克隆」工作流，看它要什么

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：新装看板，#5「照着发布会片头做一个模板」的工作流是 `video-clone`。
- **账号**：没有登录 Cloud，不是 Pro。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。截图只截「配置」窗口或卡片正文。

## Steps

1. 点右上角的「配置」，再点左栏「工作流」，点中间一栏顶上的「软件开发」。
   下拉列表有六个内置工作流：「软件开发」带「默认」和勾，下面依次是「产品视频」「演示文稿」「图文轮播」「博客文章」「视频克隆」，后五个都带「Pro」；最底下是「新建工作流」。
   ![工作流列表](01-workflow-list.png)
   [页面上的文字](what-the-page-says.log)

2. 鼠标停在「视频克隆」上。
   约半秒后右侧出现深色气泡：「拿到参考视频的复刻成片和可复用的视频模板，满意即可归档。」
   ![视频克隆的说明](02-description.png)
   [页面上的文字](what-the-page-says.log)

3. 点「视频克隆」。
   顶上换成「视频克隆 Pro」；中间只有「规划」框（领头的「视频克隆」，下面是「规划助手」和「+」）和「定期运行」框（「还没有定期运行的 Agent。」），没有「执行」框。右侧是领头 Agent「视频克隆」：「把参考视频复刻成可复用的视频模板，渲染出复刻版并与原片逐镜头对比。」，「你的要求」的占位提示是「…例如「模板统一用 1080×1920 竖屏」」。
   ![视频克隆的领头 Agent](03-video-cloner.png)
   [页面上的文字](what-the-page-says.log)

4. 关掉「配置」，打开 #5。
   卡片的「工作流」一栏写着「视频克隆」；标题下面原来放「规划」的位置是带锁的「登录以使用 Pro」，旁边只有「移除」。
   ![没有 Pro 的视频克隆卡片](04-card-needs-pro.png)
   [页面上的文字](what-the-page-says.log)

## Feedback

- **说明终于讲清交付物**：悬停说明和 Agent 简介都直说「复刻成片」加「视频模板」，不再让人以为要先审一份逐镜头配方；用户知道自己最后看到的是视频。
- **工作流和 Agent 同名**：工作流叫「视频克隆」，领头 Agent 也叫「视频克隆」，第 3 步里两个同名标题上下摆着，一时分不清在看哪个。
- **说明里没说要交什么**：卡片要靠描述里写一个本地 mp4 路径，这一点在列表、说明和 Agent 简介里都看不到；第一次用的人不知道参考视频从哪放进来。
- **没有「执行」框是对的但没解释**：其他工作流都有两个阶段，这里只剩「规划」，界面上没说这是「规划里就做完」。
- **没有跑到的**：Pro 用户真正运行一张视频克隆卡、看它交出的复刻成片和 `<Compare>` 对比（要 Pro 和一次真实运行）；新想法面板里的工作流选择器；英文界面。
