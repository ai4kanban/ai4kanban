# 在「社媒帖」工作流里找到社媒帖配图，停用后它不再回来

## Setup

- **看板**：一个刚用 `akb install` 建好的一次性 git 项目。
- **账号**：本机已登录 Cloud，是 Pro（社媒帖是 Pro 工作流）。Cloud 由 [stand-in.mjs](../give-a-copied-video-clone-workflow-a-build-agent/stand-in.mjs) 顶替。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截「配置」窗口。

## Steps

1. 点右上角的「配置」，再点左栏「工作流」，点中间一栏顶上的「软件开发」，鼠标停在「社媒帖」上。
   下拉里依次是「软件开发」「产品视频」「演示文稿」「社媒帖」「博客文章」「视频克隆」，没有「图文轮播」。悬停「社媒帖」弹出深色气泡：「先确认文案，再拿到各平台配文（图文轮播另有逐页图片），满意即可归档。」
   ![工作流列表与社媒帖的说明](01-workflow-list.png)
   [列表与气泡文字](01-workflow-list.log)

2. 点「社媒帖」。
   「规划」框里领头的是「社媒帖策划」，「规划助手」下面是「社媒帖配图」；「执行」框只有「+ 设置 Agent」。两人都有自己的角色图。
   ![社媒帖工作流](02-social-flow.png)
   [各个框的文字与角色图](02-social-flow.log)

3. 点「社媒帖配图」。
   右侧说明「按确认的文案为社媒帖新做配图：图文轮播按各页大纲的图位出图，纯文字帖为最需要配图的一段出一张图。」，右上「停用」，「额外要求」的范围是「社媒帖 · 规划」。角色戴天蓝帽檐、穿酒红短夹克。
   ![社媒帖配图](03-illustrator.png)
   [右侧文字](03-illustrator.log)

4. 点「社媒帖策划」。
   说明「负责社媒帖卡片从规划到交付：先确定文案（图文轮播还要定逐页大纲和模板），再渲染逐页图片并写好各平台配文。」
   ![社媒帖策划](04-planner.png)
   [右侧文字](04-planner.log)

5. 点「社媒帖配图」，点「停用」；刷新页面，重新打开「配置 → 工作流 → 社媒帖」。
   停用后配图移到规划框底部的「已停用（1）」下；刷新后它仍在「已停用（1）」下，没有被自动加回。
   ![刷新后仍是停用](05-off-after-reload.png)
   [停用后与刷新后](05-off-after-reload.log)

6. 关掉页面，在项目里跑本目录的 `old-board.py`，把看板改回升级前的样子（社媒帖的规划助手写成空列表，也没有加过配图的记录），再打开「配置 → 工作流 → 社媒帖」。
   「社媒帖配图」自动出现在「规划助手」下，已启用。
   ![旧看板打开后](06-old-board.png)
   [规划框文字](06-old-board.log)

## Feedback

- **改名一看就懂**：「社媒帖」比「图文轮播」宽，悬停说明也写清了纯文字帖只交配文、轮播才有逐页图片。
- **配图帮手的说明清楚**：一句话讲清轮播和纯文字帖各出几张图，和博客配图的位置、用法一致。
- **策划的说明没跟上**：策划说明仍写「再渲染逐页图片」，没提配图交给了社媒帖配图，也没说纯文字帖不渲染；读完以为策划自己出图。
- **停用的后果不知道**：停用后纯文字帖还配不配图、轮播的图位谁来补，界面上没说。
- **没有跑到的**：真实的社媒帖规划运行（配图帮手真的出图、改文案只重做受影响的图）、卡片写「不要图」时跳过、英文界面、桌面应用。第 6 步的旧看板是手工改出来的，不是真的从旧版升级。
