# 不登录 Cloud，也在铃铛里看到等你处理的卡片

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：新装看板，去掉安装时自带的 #1，只留一张规划好、待执行的软件开发卡 #2「修好设置页的拼写」。
- **账号**：本机没有登录 Cloud（`AI4KANBAN_HOME` 里没有 `session.json`）。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截右侧的通知栏。卡片上的问题用 `akb raw update-questions` 在命令行加和清，代替 Agent 写问题。

## Steps

1. 打开看板首页，点右上角的铃铛。
   铃铛读作「通知 · 1 条未读」；通知栏顶上是「待处理」「已完成」两个标签，「1 条新消息」「全部标为已读」，下面一行「#2 修好设置页的拼写 · 待审核 · 刚刚」，前面一个橙点。没有「登录才有通知」之类的提示。这一行来自看板状态目录里的本机记录 `notifications.json`。
   ![未登录的通知栏](01-signed-out.png)
   [铃铛、本机记录和通知栏文字](01-signed-out.log)

2. 通知栏开着，在命令行给 #2 加一道 `[user]` 问题「改成「設定」还是「设置」？」。
   1 秒内同一行变成「#2 修好设置页的拼写 · 待你决定 · 刚刚」，仍是 1 条未读；本机记录里这一条变成 `kind: question`。
   ![问题来了](02-question.png)
   [本机记录与通知栏](02-question.log)

3. 刷新页面。
   铃铛仍是「1 条未读」，通知栏还是「待你决定」那一行，没有丢。
   ![刷新之后](03-after-reload.png)
   [刷新后的铃铛与通知栏](03-after-reload.log)

4. 在命令行清掉 #2 的问题，等 5 秒。
   本机记录里这一条变成 `state: stale`；铃铛变回「通知」，通知栏写「没有待处理事项」和一句说明「需要你处理的卡片会显示在这里：待审核、待你决定，或交付失败。」
   ![问题清掉之后](04-retired.png)
   [本机记录与通知栏](04-retired.log)

## Feedback

- **不登录也有用了**：以前未登录的铃铛只有「登录才有通知」，现在卡片一需要人就出现，跟登录时一样快，刷新也不丢。
- **空状态会说话**：「没有待处理事项」下面一句列出会出现什么，第一次用的人知道铃铛是干什么的。
- **问题清掉后卡片也不再提醒审核**：#2 一开始是「待审核」，问过一次问题再清掉后整行消失，卡片明明还在待执行、没人审过；回到第 1 步的状态需要用户自己记得。
- **「已完成」标签没有用上**：本机只记已落地的交付，这次没有交付，没法看到它。
- **没有跑到的**：系统通知弹窗（浏览器里没有桌面应用的通知通道）、交付失败与中断、已落地进「已完成」、重启桌面应用和崩溃后补回、登录后与 Cloud 去重、静音开关、多个窗口。
