# 在配置里凭角色图认出每个内置 Agent

## Setup

- **看板**：一个刚用 `akb install` 建好的看板，界面语言中文，没有自建 Agent。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1280×1000。截图只截 Agent 列表或右侧详情的头部。

## Steps

1. 点右上角的「配置」，再点左栏的「工作流」。
   「规划」「执行」「定期运行」三组里每个 Agent 前都有自己的像素机器人，同一只机器人靠手里的道具区分；竞品调研拿双筒望远镜，产品配图拿相机，质检员拿夹着清单的夹板。没有一行是「无道具机器人 + 首字母卡片」。
   ![工作流的 Agent 列表](01-workflow-list.png)
   [每行的角色图](01-workflow-list.log)

2. 点「竞品调研」。
   右侧详情头部是放大的同一张图：胸前一副灰色双筒望远镜，两枚天蓝镜片，脸完整露出。
   ![竞品调研](02-competitor-research.png)
   [详情的角色图](02-competitor-research.log)

3. 点「产品配图」。
   详情头部是拿着天蓝镜头相机的机器人。
   ![产品配图](03-illustrator.png)
   [详情的角色图](03-illustrator.log)

4. 点「质检员」。
   详情头部是拿着桃色夹板、夹板上有一列对勾清单的机器人。
   ![质检员](04-qa-manager.png)
   [详情的角色图](04-qa-manager.log)

5. 点左栏的「看板」。
   看板自带的 Agent 都有自己的角色图，「描述项目」拿着展开的书本和铅笔，同样没有首字母卡片。
   ![看板自带的 Agent](05-board-agents.png)
   [每行的角色图](05-board-agents.log)

6. 点「描述项目」。
   详情头部放大显示书本和铅笔，书页中缝清楚。
   ![描述项目](06-project-writer.png)
   [详情的角色图](06-project-writer.log)

## Feedback

- **列表终于整齐**：四个补上的角色和其余 Agent 站在同一基线、同一风格，扫一眼不再有几个「缺图」的空位。
- **26px 下道具要细看**：列表里的头像只有 26px，产品配图的相机像一枚放大镜，质检员的夹板和描述项目的书本也差不多大小；靠名字认人没问题，单靠图区分还得点开看大图。
- **竞品调研的画风略不同**：它是用图像生成工具重画的，机身更粗、轮廓更重，和相邻手绘的角色放在一起能看出来，但不突兀。
- **没有跑到的**：桌面应用（Electron）、深色模式、自建 Agent 的首字母卡片（这次没建）。设置向导在后台自动跑了一次「读取仓库」，会真的调用一次 Agent。
