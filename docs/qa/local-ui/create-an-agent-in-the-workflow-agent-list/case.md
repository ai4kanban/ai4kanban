# 在工作流的 Agent 列表里新建一个 Agent

## Setup

- **看板**：一个刚用 `akb install` 建好的看板，界面语言为中文；工作流是内置的「软件开发」，还没有自建 Agent。
- **界面**：在浏览器里打开看板 UI（`kanban-ui`），窗口宽 1280px。

## Steps

1. 点右上角的「配置」，再点左栏的「工作流」。
   中间一栏是「规划」「执行」两个分组框，下面隔开一段是「定期运行」框，里面是自带的「质检员」。「规划」框里软件规划师下面是一行小字「规划助手」，带着宣传文案、邮件策划等五个 Agent；「执行」框里只有「开发」，没有小字也没有「+」。当前选中的「软件规划师」没有底色，只在分组框左边线上亮起一小段橙色。「规划助手」和「定期运行」那两行小字的右端各有一个灰底的「+」小按钮。
   ![工作流的 Agent 列表](01-agent-list.png)

2. 点「界面设计师」，再把鼠标移到「提示词撰写」上。
   橙色短线移到「界面设计师」这一行，右侧换成它的详情；鼠标下的「提示词撰写」只铺一层浅灰底，选中的行仍然没有底色。
   ![选中行与悬停行](02-selected-and-hover.png)

3. 点「规划助手」右端的「+」（悬停名称「新建规划助手」）。
   「规划助手」这一组的末尾多出一行：虚线空头像位、已聚焦的名称输入（占位符 `release-notes`）、右端变淡且不可点的「创建」；行下一行小字「小写字母，用短横线连接」。刚点的「+」变成「×」，「定期运行」的「+」不变。
   ![列表里的新建行](03-new-agent-row.png)

4. 输入 `qa-manager`，按回车。
   没有创建：行下的小字换成棕红色的拒绝原因「`qa-manager` is an agent the command ships. Pick another name.」，输入的名称还在，光标仍在输入里。
   ![名称被拒绝](04-name-refused.png)

5. 全选输入里的名称，改成 `release-notes`。
   一改字，拒绝原因就换回灰色的名称提示；「创建」是白底深色字，可以点。
   ![输入了可用的名称](05-name-typed.png)

6. 按回车。
   新建行消失，「规划助手」这一组末尾多出「Release notes」并被选中（橙色短线在它左边）；右侧是它的 `AGENT.md` 路径和内容（`hook: plan`），「×」变回「+」。
   ![创建成功](06-created.png)

7. 再点「规划助手」的「+」，在名称输入里按 Esc。
   只有新建行收起，「配置」窗口还开着，「×」变回「+」。
   ![Esc 之后](07-after-esc.png)

8. 再点「规划助手」的「+」，然后点它变成的「×」。
   新建行收起，按钮变回「+」，窗口还开着。
   [08-cancel-with-cross.log](08-cancel-with-cross.log)

## Feedback

- **「规划助手」这个名字说对了它们是干什么的**：比原来的「规划后」读得出是规划时叫来帮忙的，不再让人以为它们排在规划之后跑。
- **但「规划助手」撞名了**：「配置 → 看板」里早就有一个叫「规划助手」的 Agent（陪你把想法聊成方案的那个），这页右侧运行时下面那句红字「在「规划助手」里更改」说的就是它，不是左边这一组。同一个窗口里同一个词指两样东西，点那句红字前很容易以为会跳到左边的分组。
- **列表短了，终于放得下**：「执行后」一组去掉以后，1280×900 的窗口里新建行打开、再多一个 Agent，「定期运行」框和质检员仍在视野里，不用滚动。
- **「执行」框成了孤零零的一行**：只剩「开发」，没有任何一句话说明这里不能再加 Agent；以前在这里加过检查的人得自己去文档里找到「改用定期运行」的说法。
- **拒绝原因是英文**：中文界面里冒出一句「is an agent the command ships」，而且「the command」对用户没有意义；名称保留、光标不丢这一点很好，改一个字提示就恢复。
- **「创建」不起眼**：白底小字在灰色行里不像主操作，第一次用更可能直接按回车；名称为空时它只是变淡，没有别的说明。
- **创建之后是半成品**：新 Agent 的显示名是自动生成的「Release notes」，简介和正文是英文的「Unwritten — …」占位，中文看板上显得突兀；选中后右侧的 `AGENT.md` 编辑框立刻带着一圈粗橙色聚焦框。
- **「+」在标题行、新建行在组尾**：组里有五六个 Agent 时两者隔得很远，眼睛要往下找。
- **没有跑到的**：英文界面、键盘 Tab 聚焦「+」的轮廓、很长的拒绝原因换行；「定期运行」框里的「+」在 `set-a-workflow-agent-to-run-on-a-schedule` 那个用例里跑。
