# 翻看欢迎导览

## Setup

- **看板**：任意一个新装看板。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900，界面语言中文；`AI4KANBAN_HOME/settings.json` 里没有 `welcomeTourShown`，所以一打开就弹出「功能导览」。每次要从头看导览时都先删掉这一项再刷新。
- **录制**：用 CDP 录屏帧按真实间隔拼成 GIF，只截导览弹窗一带。

## Steps

1. 等导览弹出，点「下一步」，等它停稳后点「上一步」。
   弹窗是一叠卡片。前进时最前面那张整张（标题栏、内容、底部按钮一起）向左滑出并转一个小角度，下面那张浮上来成为第 2 页「专注主线，支线交给 Agent」；后退时第 1 页「执行之前，先看草稿」从左侧抽回、落到最前面。每次约半秒，插图从头播放。
   ![前进再后退](01-next-then-back.gif)

2. 让系统开启「减少动态效果」（CDP 模拟 `prefers-reduced-motion: reduce`），重新打开页面做同样的操作。
   页面直接切换，没有滑动；插图一出现就是画完的样子。
   ![减少动态效果](02-reduced-motion.gif)

3. 关掉减少动态效果，重新打开页面，点导览右上角 ✕。
   导览不是瞬间消失：整叠卡片和遮罩一起淡出并轻微下沉，约 150ms 后露出看板；`settings.json` 随后记下 `welcomeTourShown: true`。
   ![点 ✕ 关闭](03-close-with-x.gif)

4. 再让导览弹出一次，点左下角「跳过」。
   和 ✕ 一样淡出、下沉后消失。
   ![点跳过关闭](04-close-with-skip.gif)

5. 打开右上角「配置」→「通用」，滚到「功能导览」。
   这一行写着「看看 AI4Kanban 能为你做些什么。」，右边是「重新查看」。
   ![设置里的功能导览](05-settings-row.png)

6. 点「重新查看」。
   配置关上，导览从第 1 页「执行之前，先看草稿」重新弹出。
   ![再次打开导览](06-tour-again.png)

7. 一路点「下一步」到第 5 页「让 Agent 替你当用户」，点「开始使用」。
   同样淡出、下沉后消失，回到看板。
   ![点开始使用关闭](07-close-with-get-started.gif)

## Feedback

- **像在翻一叠卡**：翻页方向一眼能看出来，后退也有对应的反向动作。
- **关得一致了**：✕、「跳过」「开始使用」都和 Esc 一样有退场，关掉时知道它去哪了，不再像页面闪了一下。
- **按钮会跟着跑**：整张卡一起滑走，「下一步」在那半秒里也跟着卡片移开鼠标下方。
- **减少动态效果时干净利落**：直接换页，插图也不再逐笔画出。
- **重看入口藏得深**：它在「通用」页最底下，要滚过安装、交付、运行、隐私、语言才看得到。
- **没有跑到的**：手机宽度；减少动态效果时的关闭；退场中连点关闭；底部圆点跳页；键盘左右键。
