# 翻看欢迎导览

## Setup

- **看板**：任意一个新装看板。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900，界面语言中文；`AI4KANBAN_HOME/settings.json` 里没有 `welcomeTourShown`，所以一打开就弹出「功能导览」。
- **录制**：用 CDP 连续截图（约每 56 毫秒一帧），按真实间隔拼成 GIF，只截导览弹窗一带。

## Steps

1. 等导览弹出，点「下一步」，等它停稳后点「上一步」。
   弹窗是一叠卡片。前进时最前面那张整张（标题栏、内容、底部按钮一起）向左滑出并转一个小角度，下面那张浮上来成为第 2 页「专注主线，支线交给 Agent」；后退时第 1 页从左侧抽回、落到最前面。每次约半秒，插图从头播放。
   ![前进再后退](01-next-then-back.gif)

2. 让系统开启「减少动态效果」（CDP 模拟 `prefers-reduced-motion: reduce`），重新打开页面做同样的操作。
   页面直接切换，没有滑动；插图一出现就是画完的样子。
   ![减少动态效果](02-reduced-motion.gif)

## Feedback

- **像在翻一叠卡**：卡堆不再只是装饰，翻页方向一眼能看出来，后退也有对应的反向动作。
- **按钮会跟着跑**：整张卡一起滑走，「下一步」在那半秒里也跟着卡片移开鼠标下方。
- **减少动态效果时干净利落**：直接换页，插图也不再逐笔画出。
- **没有跑到的**：手机宽度的滑出加浮起；底部圆点跳页；键盘左右键；动画中途连点。
