# 点附件标签把它收起，再点展开

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目（需要 ffmpeg）：#2「首页改版」依次带一份有中文、English 两个版本的桌面样稿「首页（桌面）」、一篇 Markdown 文稿「对比 TASKMASTER」、一张不带标签的图片 `traffic.png`、一个图片 `<Compare>`「改版前后」。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，看「首页（桌面）」，鼠标移到样稿画面上。
   标题行左边是向下的箭头、加粗的「首页（桌面）」和浅灰底的版本「中文 ⌄」（不再带版本数）；右边是「查看代码」`<>`、「查看原尺寸」↗ 和 ⋯ 三个图标。样稿贴满白框；指针在画面上时，右下角浮出缩放条「− 59% + ⇤⇥」。
   ![展开的样稿](01-expanded.png)

2. 点「首页（桌面）」。
   样稿收起成只剩标题行的一条（高 514 → 44），箭头转向右，读屏标签从「收起 首页（桌面）」变成「展开 首页（桌面）」；「查看代码」「查看原尺寸」跟着隐藏，只留版本和 ⋯；下面的文稿跟着上移 470px。
   ![收起后只剩标题行](02-collapsed.png)

3. 收起状态下点「中文」，选 English，再点标签。
   版本菜单列出中文、English；选完仍是收起的一条，版本显示「English」；点标签后展开，画的是英文版「Welcome back」，缩放条回来。
   ![展开后是英文版](03-expanded-english.png)

4. 点「查看代码」，再点两次标签。
   只切到代码视图，样稿不收起，`<>` 图标变成按下状态、提示变成「查看画面」；收起再展开后仍是代码视图。
   ![收起再展开后仍是代码](04-code-kept.png)

5. 往下看「对比 TASKMASTER」，点标签。
   文稿正文收起，只剩 44px 高的标题行；右侧的「查看原文」和「查看原尺寸」隐藏，只留 ⋯。
   ![文稿收起](05-article-collapsed.png)

6. 看下面不带标签的图片 `traffic.png`，点标题行左边的箭头。
   标题行只有一个箭头、没有名字，右侧是「查看原尺寸」和 ⋯；点箭头同样收起成一条，只剩箭头和 ⋯。箭头的读屏标签是「收起 」，后面没有名字。
   ![没有标签的图片收起](06-no-label.png)

7. 往下看「改版前后」，点标签，再点 ⋯。
   两张图都收起，只剩「改版前后」和 ⋯；⋯ 里是「下载「改版前」」「下载「改版后」」。
   ![对比收起](07-compare-collapsed.png)

8. 刷新页面。
   四个附件都回到展开，版本回到「中文」：收起状态不记忆。
   [刷新后的标题行](08-reload.log)

## Feedback

- **整齐多了**：四种附件的标题行都是同一个样子——箭头、名字、右边一两个图标和 ⋯，收起后只剩箭头、名字和 ⋯，一眼能认出是一家人。
- **长卡片能跳过附件**：一下收成 44px 高的一条，下面的内容立刻顶上来。
- **收起不丢状态**：收起时切版本、收起前选的代码视图，展开后都还在。
- **箭头比以前好认**：箭头单独成一个按钮、悬停有底色，比原来塞在小标签里的 11px 箭头更像能点；但悬停没有文字提示，第一次不知道点名字也能收。
- **不带标签的图片只有一个孤零零的箭头**：标题行左边空着，读屏只念「收起」，不知道收的是什么。
- **刷新就全展开**：想一直收着某个大附件，每次打开卡片都得再点一次；也没有「全部收起」。
- **没有跑到的**：视频、手机样稿、分镜和视频 `<Compare>` 的收起；桌面应用（Electron）；深色模式；键盘操作（Tab 到箭头按回车）；手机宽度。
