# 点附件标签把它收起，再点展开

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目（需要 ffmpeg）：#2「首页改版」依次带一份有中文、English 两个版本的桌面样稿「首页（桌面）」、一篇 Markdown 文稿「对比 TASKMASTER」、一张不带标签的图片 `traffic.png`、一个图片 `<Compare>`「改版前后」。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 `/2`，看「首页（桌面）」，鼠标停在左上角标签上。
   标签左侧有向下的箭头，标签下方出现提示「收起」；标签右边是版本「中文 2」，标题行右侧是「缩小 · 59% · 放大 · 适应宽度」「代码」和两个图标。
   ![展开的样稿](01-expanded.png)
   ![标签的悬停提示](01-tip.png)
   [三个附件的标题行](01-label.log)

2. 点标签。
   样稿收起成只剩标题行的一条（高 511 → 41），箭头转向右，提示变成「展开」；缩放按钮不见，「中文 2」「代码」和两个图标还在；下面的文稿跟着上移 470px。
   ![收起后只剩标题行](02-collapsed.png)
   [标题行和位移](02-collapsed.log)

3. 收起状态下点「中文 2」，选 English，再点标签。
   选版本后仍是收起的一条，版本显示「English 2」；点标签后展开，画的是英文版「Welcome back」，缩放按钮回来。
   ![收起时切到 English](03-collapsed-english.png)
   ![展开后是英文版](03-expanded-english.png)
   [切版本前后](03-version.log)

4. 点「代码」，再点两次标签。
   点「代码」只切到代码视图，样稿不收起；收起再展开后仍是代码视图，按钮仍是「画面」。
   ![收起再展开后仍是代码](04-code-kept.png)
   [按钮和状态](04-code.log)

5. 往下看「对比 TASKMASTER」，点标签。
   文稿正文收起，只剩标题行；「原文」、复制路径、查看原尺寸、下载四个按钮照常显示。
   ![文稿收起](05-article-collapsed.png)
   [标题行](05-article.log)

6. 看下面不带标签的图片 `traffic.png`。
   标题行左侧没有标签，也没有能收起的入口，只有右侧的缩放和两个图标。
   ![没有标签的图片](06-no-label.png)
   [标题行](06-no-label.log)

7. 往下看「改版前后」，点标签。
   两张图都收起，只剩标签和右侧的全屏按钮。
   ![对比收起](07-compare-collapsed.png)
   [标题行和图片数](07-compare.log)

8. 刷新页面。
   三个附件都回到展开，版本回到「中文」：收起状态不记忆。
   [刷新后的标题行](08-reload.log)

## Feedback

- **长卡片终于能跳过附件**：一下收成 41px 高的一条，下面的内容立刻顶上来，比一路滚过去省事得多。
- **收起不丢状态**：收起时切版本、收起前选的代码视图，展开后都还在，没有"重新来一遍"的感觉。
- **展开时的「收起」提示看不见**：提示落在样稿画面下面，只露出一角，读不出字（已报 triage）；收起后的「展开」提示正常。
- **入口不算显眼**：只有标签里一个 11px 的小箭头暗示能点，第一次看卡片的人多半不会想到点标签。
- **没有标签的附件收不起来**：同一张卡上有的能收、有的不能，用户分不清为什么。
- **刷新就全展开**：想一直收着某个大附件，每次打开卡片都得再点一次；也没有「全部收起」。
- **没有跑到的**：视频、手机样稿和视频 `<Compare>` 的收起；桌面应用（Electron）；深色模式；键盘操作（Tab 到标签按回车）。
