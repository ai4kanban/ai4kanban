# 扫过顶栏的按钮，打开再关上「运行历史」

## Setup

- **看板**：任意已建好的看板（这次是一次性 git 项目，`akb install` 新建，几张卡）。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900，界面语言中文，已跳过欢迎导览，鼠标先停在看板空白处。
- **录制**：用 CDP 录屏帧按真实间隔拼成 GIF。

## Steps

1. 鼠标移到右上角「统计」图标上停一秒，再横移到「运行历史」、再到「配置」，最后移开。
   第一个提示「统计」稍等一下才出现；之后移到相邻按钮，「运行历史」「配置」的提示立即跟着换过去。
   ![扫过顶栏](01-tip-delay-and-sweep.gif)

2. 分别量一次三种情况下提示出现的时间。
   冷启动时约 400ms 后才开始显现；提示已显示时移到相邻按钮，50ms 内就出现；移开一秒后再悬停，又回到约 400ms 的等待。
   [提示时间](02-tip-timing.log)

3. 点「运行历史」。
   遮罩淡入，办公室面板从略小、略低的位置放大到原位并淡入；面板打开期间，顶栏的「运行历史」按钮保持按下的浅灰底色（`aria-pressed="true"`）。
   ![运行历史已打开](03-runs-open.png)

4. 按 Esc。
   面板反向缩小、淡出后才消失，按钮回到未按下的样子（`aria-pressed="false"`）。
   ![打开再关上](04-open-close-runs.gif)

## Feedback

- **扫按钮不再闪一串提示**：鼠标路过不会挨个弹提示，真想看时停一下就出现，连着看几个又不用每个都等，节奏对。
- **对话框有了进退场**：开关都有一个短暂的缩放淡入淡出，知道它从哪来、回到哪去；按钮保持按下，也能看出当前打开的是哪个。
- **第一次打开有点空**：进场动画播完时办公室插画还没加载出来，前几帧是一块空白面板。
- **没有跑到的**：待筛选、通知计数亮起时的变宽和数字淡入（这次用 `akb triage add` 加的条目一分钟内就被自动筛选建成了卡，计数没来得及亮）；减少动态效果；键盘聚焦时提示立即显示；点遮罩、点 ✕ 关闭；通知侧栏的滑入滑出；手机宽度。
