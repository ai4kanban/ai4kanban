# 在看板上把一个想法变成卡片

## Setup

- **看板**：一次性 git 项目，刚用 `akb install` 建好（自带 #1），删掉了 `setup-checklist.md`。
- **Agent**：用本目录的 [stand-in.mjs](stand-in.mjs) 顶替真实 agent——在 `<项目>/.akb/boards/docs/kanban/ui.config.json` 写 `"harness":"claude-code"` 和 `harnessSettings["claude-code"].command = "node stand-in.mjs <cli/bin/ai4kanban.mjs>"`。它从标准输入读看板发来的提示：在讨论里用 `akb raw plan new` 存一份方案；被要求按方案加任务时建一张卡；被要求规划时写一行摘要、问一个 `[user]` 问题。不花钱，也不需要账号。
- **界面**：浏览器打开看板 UI（`kanban-ui`）首页，窗口 1440×900，界面语言中文；先在欢迎导览上点「跳过」。

## Steps

1. 点右上角「新想法」。
   看板换成一张大白纸：标题是一句轮换的提问（这次是「接下来该做什么？」），下面一个输入框，右下角是 Agent 选择和发送按钮。
   ![新想法](01-new-idea.png)

2. 在输入框里写「想把一张卡片导出成 PDF，发给不用看板的同事」。
   发送按钮由浅变实。
   ![写下想法](02-typed.png)

3. 点发送。
   Agent 回了一句话，下面是「规划任务」「立即开始」两个按钮和工作流「软件开发」；右侧展开「方案」，标题「Export a card as PDF」，底部是方案文件的路径。左栏多出「讨论」一组和这段讨论。
   ![Agent 写出方案](03-plan.png)

4. 点方案右上角的放大按钮，再点一次还原。
   方案从右侧栏平滑移到中间、变宽，底边停在「规划任务」和输入框上方，背后的对话淡出；还原时移回右侧，对话淡回。
   ![放大再还原方案](04-enlarge-plan.gif)

5. 点「规划任务」。
   两个按钮换成带脉冲点的「正在写成卡片…」。
   ![正在写成卡片](05-writing-cards.png)

6. 等十来秒。
   讨论自己关上，页面留在看板，不跳到新卡片。约 6 秒后「未就绪」列出现 #3「Export a card as PDF」：描边和硬阴影是强调色，卡上带问号标记和待办 0/1；「全部卡片」计数从 1 变成 2，左栏的「讨论」一组消失。
   ![看板上的新卡](06-board.png)

7. 点 #3。
   打开卡片页「#3 Export a card as PDF」：「来源」是「计划」，「待你决定」里是 Agent 规划时问的问题（A4 推荐 / US Letter / 自己填）。
   ![新卡片页](07-card-page.png)

8. 点左栏「全部卡片」回到看板。
   #3 的强调色描边没了，和 #1 一样是普通黑边。
   ![打开过的新卡](08-board-after-open.png)

## Feedback

- **不再被拽走**：写完卡停在原地，新卡用强调色标出来，想看再点，比自动跳到卡片页更可控；看过一次标记就消失，也符合「未读」的直觉。
- **中间有几秒空窗**：讨论关上后，看板要等约 6 秒才出现新卡，这几秒里没有任何提示，第一次用的人会以为卡没建成。
- **放大方案很顺**：方案放大占满对话区、按钮和输入框仍在下方能用，读长方案方便。
- **卡号跳了一个**：方案先占了 #2，新卡是 #3；看板上 #1 后面直接是 #3，第一次用的人会以为丢了一张。
- **「规划任务」和「立即开始」没有说明**：按钮旁没有一句提示两者的差别。
- **英文混在中文界面里**：Agent 选择写着「Global default」。
- **替身带来的偏差**：方案和规划内容由替身写成，验证的是流程，不是 Agent 的质量。
