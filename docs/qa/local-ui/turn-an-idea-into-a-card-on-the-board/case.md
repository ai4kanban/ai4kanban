# 在看板上把一个想法变成卡片

## Setup

- **看板**：一次性 git 项目，刚用 `akb install` 建好（自带 #1），删掉了 `setup-checklist.md`。
- **Agent**：用本目录的 [stand-in.mjs](stand-in.mjs) 顶替真实 agent——在 `<项目>/.akb/boards/docs/kanban/ui.config.json` 写 `"harness":"claude-code"` 和 `harnessSettings["claude-code"].command = "node stand-in.mjs <cli/bin/ai4kanban.mjs>"`。在讨论里它用 `akb raw plan new` 存一份方案；被要求按方案加任务时建一张卡；被要求规划时写一行摘要、问一个 `[user]` 问题。不花钱，也不需要账号。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440 宽，界面语言中文；先在欢迎导览上点「跳过」。

## Steps

1. 点右上角「新想法」。
   看板换成一张大白纸：标题是一句轮换的提问（这次是「接下来该做什么？」），下面一个输入框，右下角是 Agent 选择和发送按钮。
   ![新想法](01-new-idea.png)

2. 在输入框里写「想把一张卡片导出成 PDF，发给不用看板的同事」。
   发送按钮由浅变实。
   ![写下想法](02-typed.png)

3. 点发送。
   左栏多出「讨论」一组和这段讨论；Agent 回了一句话，下面是「规划任务」「立即开始」两个按钮和工作流「软件开发」；右侧展开「方案」，标题「Export a card as PDF」，底部是方案文件的路径。
   ![Agent 写出方案](03-plan.png)

4. 点「规划任务」。
   两个按钮换成「正在写成卡片…」。
   ![正在写成卡片](04-writing-cards.png)

5. 等十来秒。
   自动跳到新卡片页「#3 Export a card as PDF」：「来源」是「计划」，「待你决定」里是 Agent 规划时问的问题（A4 推荐 / US Letter / 自己填），右侧对话栏顶上是「来自讨论 · 3 条」。
   ![新卡片页](05-card-page.png)

6. 点左栏「全部卡片」。
   「未就绪」列有了 #3，卡上带问号标记和待办 0/1；「全部卡片」计数从 1 变成 2。
   ![看板上的新卡](06-board.png)

## Feedback

- **一句话到一张规划好的卡**：写想法、点两下，看板自己建卡、规划、跳到卡片页，中间不用碰命令行，顺。
- **卡号跳了一个**：方案先占了 #2，新卡是 #3；看板上 #1 后面直接是 #3，第一次用的人会以为丢了一张。
- **「规划任务」和「立即开始」没有说明**：按钮旁没有一句提示两者的差别，要悬停或读文档才知道「立即开始」会跳过细化。
- **英文混在中文界面里**：Agent 选择写着「Global default」，导览之外的这处没翻译。
- **替身带来的偏差**：卡片页对话栏下方的「这台电脑上没有安装 Claude Code」提示，是因为替身冒充了 Claude Code 而本机取证环境里没有它，真实安装不会出现；方案和规划内容也由替身写成，验证的是流程，不是 Agent 的质量。
