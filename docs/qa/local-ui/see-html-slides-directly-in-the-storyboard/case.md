# 做演示文稿：先看清交付的是图片版 PPT，再在卡片上直接翻 HTML 幻灯片

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2「季度复盘演示文稿」正文有两份分镜：
  - `<Storyboard src=".assets/2/deck.json" label="季度复盘 4:3" />`：`size` 为 1440×1080；第 1 页是子目录里的 `pages/cover.html`（贴边的深蓝边框、一个正圆和一个「查看原始数据」链接），第 2 页是 `pages/growth.tsx`（柱状图），第 3 页指向的 `pages/end.html` 不存在。
  - `<Storyboard src=".assets/2/wide.json" label="宽屏版" />`：两页 HTML，不写 `size`。
- **账号**：没有登录 Cloud，不是 Pro。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 点右上角的「配置」，再点左栏「工作流」，点中间一栏顶上的「软件开发」，鼠标停在「演示文稿」上。
   右侧出现气泡：「先确认每页内容，再拿到图片版 PPT（每页一张图，不能直接改字），满意即可归档。」
   ![演示文稿的说明](01-slide-deck-description.png)

2. 关掉「配置」，打开 `/2`，看「季度复盘 4:3」。
   分镜自成一块白底。标题行是折叠箭头、「季度复盘 4:3」「3 页」和翻页器「‹ 1 / 3 ›」，「‹」变灰；没有 ⋯（整份没有图片，就没有下载）。下面三格缩略图（238×179），1、2 直接画出页面，3 是空白；再下面只显示第 1 页：「1 封面」。页面按正文宽度画成 720×540（1440×1080 的画布缩放 0.5），正圆没被拉扁，四边的边框都完整，没有被裁。
   ![只显示当前一页](02-deck.png)

3. 点标题行的「›」。
   换成「2 增长」「2 / 3」，第 1 页不再显示，第 2 格缩略图描边；TSX 页面同样按 4:3 画出：标题「周活跃增长 +87%」和四根柱子。
   ![TSX 页](03-tsx-page.png)

4. 再点「›」。
   换成「3 结尾」「3 / 3」，「›」变灰；一个 720×540 的虚线框，中间是「暂无预览」和「重新加载」。
   ![缺文件的页](04-missing-page.png)

5. 点第 1 格缩略图回到封面，点页面；在放大的页面上点「查看原始数据」；再按 Esc。
   悬停时右上角出现「放大查看」；点开后页面按窗口放大到 1093×820，仍是 4:3。点链接没有任何反应，放大视图还开着、没有打开新页面；按 Esc 关闭。
   ![放大的 HTML 页](05-enlarged.png)

6. 往下看「宽屏版」。
   没写 `size` 的分镜按 1920×1080 排版，缩略图（359×202）和当前页（720×405）都是 16:9；标题行「宽屏版」「2 页」「1 / 2」，同样没有 ⋯。
   ![不写尺寸时按 16:9](06-no-size.png)

## Feedback

- **不用先导出图片**：HTML/TSX 页直接出现在分镜里，缩略图和当前页一致，比例和留边都对，看稿的体验与图片页没有区别。
- **一次一页，翻页器在标题行**：「‹ 1 / 3 ›」挪到了右上角，和缩略图一起用很顺手，整份稿只占一页高；但想快速通读全部页的文字，得一页页翻。
- **标题行更干净**：只剩名字、页数和翻页器，两份稿各有白底和标题行，边界清楚。
- **配置里说清了代价**：「图片版 PPT（每页一张图，不能直接改字）」一句话就让人知道交付物不能在 PowerPoint 里改字；但这句只在悬停气泡里，不悬停看不到。
- **全 HTML 的分镜没有任何菜单**：标题行连 ⋯ 都没有，想把当前稿子拿出去给别人看只能等交付的 `.pptx`。
- **缺页的提示太泛**：「暂无预览」不说是文件不存在，「重新加载」点了也不会变好；缺页的缩略图只是一块空白，看不出是缺页。
- **放大后的链接是死的**：符合「只看不点」的设计，但页面里有链接时看起来像能点，点了没任何反馈。
- **没有跑到的**：真实演示文稿卡片的规划和交付（要 Pro 和一次真实运行），以及交付后 `.pptx` 每页一张图；带演讲备注的页；英文界面的说明文字；手机宽度。
