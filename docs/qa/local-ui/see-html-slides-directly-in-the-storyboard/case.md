# 做演示文稿：先看清交付的是图片版 PPT，再在卡片上直接翻 HTML 幻灯片

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2「季度复盘演示文稿」正文有两份分镜：
  - `<Storyboard src=".assets/2/deck.json" label="季度复盘 4:3" />`：`size` 为 1440×1080；第 1 页是子目录里的 `pages/cover.html`（贴边的深蓝边框、一个正圆和一个「查看原始数据」链接），第 2 页是 `pages/growth.tsx`（柱状图），第 3 页指向的 `pages/end.html` 不存在。
  - `<Storyboard src=".assets/2/wide.json" label="宽屏版" />`：两页 HTML，不写 `size`。
- **账号**：没有登录 Cloud，不是 Pro。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 点右上角的「配置」，再点左栏「工作流」，点中间一栏顶上的「软件开发」，鼠标停在「演示文稿」上。
   列表里六个工作流都不带「Pro」。右侧出现气泡：「先确认每页内容，再拿到图片版 PPT（每页一张图，不能直接改字），满意即可归档。」
   ![演示文稿的说明](01-slide-deck-description.png)
   [气泡与列表文字](01-slide-deck-description.log)

2. 关掉「配置」，打开 `/2`，看「季度复盘 4:3」。
   分镜自成一块白底。标题行是折叠箭头、「季度复盘 4:3」「3 页」和翻页器「‹ 1 / 3 ›」，「‹」变灰；没有 ⋯（整份没有图片，就没有下载）。下面三格缩略图（238×179），1、2 直接画出页面，3 是空白；再下面只显示第 1 页：「1 封面」。页面按正文宽度画成 720×540（1440×1080 的画布缩放 0.5），正圆没被拉扁，四边的边框都完整，没有被裁。
   ![只显示当前一页](02-deck.png)

3. 点标题行的「›」。
   换成「2 增长」「2 / 3」，第 1 页不再显示，第 2 格缩略图描边；TSX 页面同样按 4:3 画出：标题「周活跃增长 +87%」和四根柱子。
   ![TSX 页](03-tsx-page.png)

4. 再点「›」。
   换成「3 结尾」「3 / 3」，「›」变灰；一个 720×540 的虚线框，中间是「暂无预览」和「重新加载」。
   ![缺文件的页](04-missing-page.png)

5. 点第 1 格缩略图回到封面，点页面；在放大的页面上点「查看原始数据」。
   悬停时右上角出现「放大查看」。点开后页面按窗口放大到 1019×764，仍是 4:3，两侧各留出一个按钮的位置；页面下方是深色胶囊「1 / 3 封面」，右侧中间一个深色圆形「›」，第一页没有「‹」；右上角的关闭按钮也是同款深色圆形（40×40，白色 ✕）。点链接没有任何反应，放大视图还开着、没有打开新页面。
   ![放大后的第一页](05-enlarged.png)
   [按钮、页码和点链接前后](05-enlarged.log)

6. 点右侧的「›」。
   放大视图里换成第 2 页的柱状图，胶囊变成「2 / 3 增长」，左右两侧都有按钮。
   ![在放大视图里翻页](06-next-in-enlarged.png)

7. 按 →，再按一次 →。
   第一次换到「3 / 3 结尾」：缺文件的页在放大视图里是同尺寸的灰底「暂无预览」，右侧的「›」消失；再按 → 不动，仍是第 3 页。
   ![最后一页没有下一页按钮](07-arrow-to-end.png)
   [每次按键后](07-arrow-to-end.log)

8. 按 ←，再按 Esc。
   ← 回到「2 / 3 增长」；Esc 关闭放大视图，卡片上的分镜停在第 2 页：标题行「2 / 3」，第 2 格缩略图描边，下方是「2 增长」。
   ![关闭后停在最后看的一页](08-close-stays.png)
   [按键与关闭后的分镜](08-close-stays.log)

9. 往下看「宽屏版」。
   没写 `size` 的分镜按 1920×1080 排版，缩略图（359×202）和当前页（720×405）都是 16:9；标题行「宽屏版」「2 页」「1 / 2」，同样没有 ⋯。
   ![不写尺寸时按 16:9](09-no-size.png)

10. 把窗口缩到 600×900，点「季度复盘 4:3」的当前页（第 2 页）。
    放大的页面占满宽度（568×426）；「‹」「›」不在两侧，而是夹在页码胶囊「2 / 3 增长」左右。
    ![窄窗口的放大视图](10-narrow.png)
    [按钮位置](10-narrow.log)

## Feedback

- **不用先导出图片**：HTML/TSX 页直接出现在分镜里，缩略图和当前页一致，比例和留边都对，看稿的体验与图片页没有区别。
- **放大后能一路翻完**：放大视图里点「›」或按 ←/→ 就能整份翻完，关掉后分镜停在刚看的那页，审稿终于不用开开关关。
- **页码和标题一眼可见**：深色胶囊「2 / 3 增长」压在页面下方，翻到哪页很清楚；首尾直接去掉按钮，不会误以为还能翻。
- **深色圆形按钮更像看图软件**：关闭和翻页按钮同一套样式，在浅色页面上也看得清；但关闭按钮压在顶栏「新想法」按钮上，顶栏透过遮罩隐约可见，略显杂乱。
- **放大页变小了一点**：为给两侧按钮留位置，4:3 页面从约 1093 宽缩到 1019 宽，小字的可读性略降，不过差别不大。
- **缺页在放大视图里更含糊**：只剩一块灰底「暂无预览」，连卡片上的「重新加载」都没有，看不出是文件不存在。
- **放大后的链接是死的**：符合「只看不点」的设计，但页面里有链接时看起来像能点，点了没任何反馈。
- **全 HTML 的分镜没有任何菜单**：标题行连 ⋯ 都没有，想把当前稿子拿出去给别人看只能等交付的 `.pptx`。
- **免费用户也能选演示文稿**：没登录 Cloud，列表里的演示文稿不再带「Pro」，和软件开发一样直接可选。
- **配置里说清了代价**：「图片版 PPT（每页一张图，不能直接改字）」一句话就让人知道交付物不能在 PowerPoint 里改字；但这句只在悬停气泡里，不悬停看不到。
- **没有跑到的**：图片页和竖版页（图文轮播）分镜的放大翻页；只有一页时不显示按钮；手机上不能横滑翻页（设计如此）；真实演示文稿卡片的规划和交付（要一次真实运行）；英文界面；桌面应用。
