# 在卡片对话里提问，看回复一段段写出来

## Setup

- **看板**：一次性 git 项目，`akb install` 新建；#6「Export misses archived cards」是待筛选建成的卡，还没聊过。
- **Agent**：用 [turn-an-idea-into-a-card-on-the-board/stand-in.mjs](../turn-an-idea-into-a-card-on-the-board/stand-in.mjs) 顶替真实 agent（配置方法见那个场景）。在卡片对话里它分五段回答，每段间隔约 1 秒，模拟真实 agent 边想边输出。
- **界面**：浏览器打开看板 UI（`kanban-ui`）的 `/6`，窗口 1440×900，界面语言中文，已跳过欢迎导览，讨论栏是关着的。
- **录制**：用 CDP 录屏帧按真实间隔拼成 GIF；发送后每约 100ms 记一次对话状态。

## Steps

1. 点右上角「讨论」。
   讨论栏从右侧滑出，正文区同步变窄；栏里是「关于这张卡片，想聊什么？」和输入框。
   ![打开讨论栏](01-open-chat.gif)

2. 在输入框里写「导出的 CSV 用什么分隔符？」。
   发送按钮变实。
   ![写好问题](02-typed.png)

3. 点发送，看回复写出来。
   我的那行立即以气泡出现在对话里，输入框同时清空；先短暂出现「思考中…」，随后回复文字逐字显示，末尾有一个闪烁的竖线光标，没有「正在回复」那一行；每段到达后文字继续平滑往后长，而不是整块跳出。
   ![发送并看回复](03-send-and-stream.gif)

4. 回复写到一半时看一眼。
   已到的三段在对话里（光标在闪，这一帧正好熄灭）；「执行」变灰，输入框下方写着「发送需等回复结束 · Esc 中止回复」，发送按钮变成停止键，卡片标题旁出现「讨论中」。
   ![写到一半](04-streaming.png)

5. 看同一次发送的逐帧记录。
   点发送后 28ms 我的那行就在、输入框已空；约 0.1 秒出现「思考中…」，约 0.25 秒换成光标，0.35 秒起回复字数从 6 一路涨到 161；回复结束后约 0.4 秒光标消失。
   [发送时间线](05-stream-timeline.log)

6. 等回复结束。
   五段回复完整显示，光标不见了，发送按钮回到浅色，「讨论中」消失；左栏「讨论」一组里多了 #6 这段对话。
   ![回复完成](06-finished.png)

## Feedback

- **发出去就看得到**：气泡在点下的那一刻出现，不用等服务器读回，打字的人不会怀疑「发出去没有」。
- **回复像在打字**：文字按到达的速度平滑往后长，配上光标，比以前隔一阵整块跳出一段自然得多，也一眼能看出还没写完。
- **等的时候知道能做什么**：输入框下的「Esc 中止回复」和停止键说得清楚。
- **多段回复各占一段**：每次输出都另起一段，替身的五句话排成五行，像被拆碎的一句话；真实 agent 一次输出一大段时不会这样。
- **替身带来的偏差**：回复内容和节奏由替身决定，验证的是显示方式，不是 Agent 的质量。
- **没有跑到的**：发送失败时文字和图片回到输入框；「N 条新消息」按钮和平滑滚到底；工作步骤和「来自讨论」的展开收起；输入框随内容长高；复制、清空按钮的按压反馈；窄窗口覆盖层；减少动态效果。
