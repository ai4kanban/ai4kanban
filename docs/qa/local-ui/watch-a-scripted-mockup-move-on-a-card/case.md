# 在卡片上看一份会动的样稿

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2 带三份样稿——WebGL 画的旋转三角形（`.html`）、canvas 画的跳动柱状图（`.tsx`，内联 `<script dangerouslySetInnerHTML>`）、一份逐项试着联网、读看板页面、写 `localStorage` 和外链 three.js 的 `.html`；#3 带一份 0.5 秒后进入 `while (true)` 的 `.html`。每份动画样稿都在画面上写出自己画到第几帧。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 打开 #2，看「WebGL 背景」。
   橙色三角形在深色底上转个不停，左下角的「WebGL：第 N 帧」一直往上数。
   ![WebGL 样稿在动](01-webgl-moves.gif)
   [画框里的文字](01-04-what-the-frames-say.log)

2. 往下滚到「访问量动画」（`.tsx`）。
   柱状图像波浪一样起伏，「canvas：第 N 帧」一直在涨。
   ![.tsx 样稿的 canvas 在动](02-tsx-canvas.png)
   [画框里的文字](01-04-what-the-frames-say.log)

3. 再往下看「越界检查」。
   第一行「脚本：在跑」，其余五项——外链 three.js、读看板页面、localStorage、cookie、联网 fetch——全是「被拦」；看板自己的 `localStorage` 里没有多出东西。
   ![越界的事全被拦下](03-escape-blocked.png)
   [画框里的文字](01-04-what-the-frames-say.log)

4. 点「WebGL 背景」上方的文件名 `.assets/2/orbit.html`。
   打开样稿自己的页面，顶部是「返回 #2 首页加一段会动的背景」，三角形放大到整栏宽，帧数照样在涨。
   ![样稿页上照样在动](04-own-page.png)
   [画框里的文字](01-04-what-the-frames-say.log)

5. 打开 #3，等样稿卡住，再在左上角「查找卡片」里输入「首页」。
   样稿停在「卡死前的最后一行字」，不再应答；看板照常：1 秒画了 62 帧，搜索框立刻列出「匹配结果 2」。
   ![样稿卡死，看板照常](05-board-still-answers.png)
   [卡死的样稿和看板](05-frozen-mockup.log)

## Feedback

- **动效终于能直接审**：WebGL 和 canvas 在卡片里就动起来，不用另开文件或录视频；`.tsx` 也能跑脚本后，同一种格式既能画静态界面又能演示动效。
- **画面里的字太小**：样稿按整页宽度排版再缩进卡片栏，卡片页上的说明文字只有几个像素高，要点文件名去样稿页才看得清。
- **被拦时毫无提示**：外链的 three.js 静静地加载失败，样稿只会显示得不对；作者要自己猜到「库必须内联」，卡片页上没有任何一句说明。
- **画框高度不随内容**：越界检查只有六行字，下面却留了一大片空白画框。
- **卡死不拖累看板**：死循环的样稿只冻住它自己，搜索、滚动都不受影响；但样稿上没有任何「已停止响应」的标记，看起来只是一张静态图。
- **没有跑到的**：桌面应用（Electron）里的同一张卡；同一页上两份 `.html` 样稿一个卡死时另一个是否跟着停（卡片说明里说会）；手机框；深色模式。
