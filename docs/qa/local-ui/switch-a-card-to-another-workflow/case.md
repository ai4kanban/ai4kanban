# 在卡片页把一张卡换到另一个工作流

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性 git 项目：#2「给设置页加一个导出按钮」本该是开发卡，却建在「博客文章」工作流上，停在阶段「大纲」，大纲已放在卡片上，状态待执行。
- **账号**：本机已登录 Cloud，是 Pro。Cloud 由 [stand-in.mjs](../give-a-copied-video-clone-workflow-a-build-agent/stand-in.mjs) 顶替。
- **Agent**：PATH 最前放 [stand-in-claude](../approve-a-stage-on-a-card/stand-in-claude)，改名为 `claude`，并把本目录的 [act.sh](act.sh) 放在它读的位置：每次运行 10 秒、什么都不改。
- **界面**：浏览器打开看板 UI（`kanban-ui`），视口 1440×900，界面语言中文。截图只截卡片页上半部。

## Steps

1. 打开 `/2`。
   元数据栏「工作流」写「博客文章 ⌄」，下面是阶段区块「大纲 › 文章」「大纲待你批准」和「批准，开始文章」。
   ![博客卡片](01-blog-card.png)
   [页面文字](01-blog-card.log)

2. 点「博客文章 ⌄」。
   弹出列表：顶上一行灰字「更换后将重新规划。」，下面六个工作流，「博客文章」高亮带勾，最底下「管理工作流」。
   ![工作流列表](02-list.png)
   [列表文字](02-list.log)

3. 选「软件开发」。
   列表收起，「工作流」变成「软件开发」，阶段区块和「批准」按钮消失，工具栏出现「执行」；标题旁和「已计划」都写「细化 · 排队中」，旁边有「取消」。卡片文件里 `workflow`、`phases`、`phase` 都去掉了，`status` 回到 `todo`，多了 `schedule: action: refine`；卡片上的大纲留着。
   ![换到软件开发](03-switched.png)
   [每 0.5 秒的页面文字与卡片文件](03-switched.log)

4. 等细化开始（看板每分钟查一次排队的工作），再点「软件开发」。
   标题旁变成「正在细化…」，运行日志展开，这次运行是软件规划师的 `clarify`。「工作流」一项变灰带锁，悬停提示「正在运行，停下后才能更换工作流」，点了不弹列表。
   ![运行中锁住](04-locked.png)
   [页面文字、运行记录和工作流一项](04-locked.log)

5. 等运行结束，再点「软件开发 ⌄」。
   锁去掉，列表又能弹出。替身没写计划，卡片仍在待办，运行日志下面写「#2 细化后仍在待办，看板不会再自动细化它。请重新细化，或手动标记为待执行。」
   ![运行结束后](05-after.png)
   [页面文字与卡片文件](05-after.log)

## Feedback

- **分错工作流终于能改**：在卡片页点一下就换，不用删卡重建，大纲等已产出的内容都留着。
- **提示够短**：「更换后将重新规划。」一句话说清代价，锁住时的悬停提示也直接说要先停下。
- **换完要等一会儿**：细化只是「排队中」，最长一分钟后才开始；这段时间工具栏照样亮着「执行」，容易让人直接点执行，跳过新工作流的规划。
- **锁只在悬停时说原因**：触屏上看不到「正在运行，停下后才能更换工作流」，只有一个小锁。
- **没有跑到的**：真实规划师重新规划的结果、交付进行中时的锁、命令行 `akb raw update --workflow`、换到已删除的工作流、英文界面和手机宽度。
