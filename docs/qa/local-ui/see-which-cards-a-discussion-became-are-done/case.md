# 在讨论里看它写成的卡片哪些已经完成

## Setup

- **看板**：用本目录的 `seed.sh` 建一个一次性项目：新装看板，卡 #2「导出 CSV」、#3「导出时带上表头」、#4「导出为 Excel」；#3 已归档，#4 已丢弃。
- **讨论**：左栏有一段讨论「列表导出」，它的四份计划分别写成了 #2、#3、#4 和 #9（#9 的卡片文件已不存在）。从讨论写卡要真实 Agent，所以这段讨论的记录由 `seed-chat.mjs` 手写，内容和真实写卡后留下的一致。
- **界面**：浏览器打开看板 UI（`kanban-ui`），窗口 1440×900，界面语言中文。

## Steps

1. 在左栏「讨论」下点「列表导出」。
   回答下面列出四张卡：`→ 已写成 #2 导出 CSV` 是醒目的橙色；`✓ 已完成 #3 导出时带上表头` 和 `已放弃 #4 导出为 Excel` 变灰；`→ 已写成 #9` 只有编号。
   ![讨论里的卡片](01-discussion.png)

2. 检查哪几行能点。
   #2、#3、#4 是指向卡片页的链接，#9 不是。
   [链接](02-links.log)

3. 点「已完成 #3」。
   打开 #3 的归档页。
   ![归档的卡片](03-archived-card.png)

4. 在终端归档 #2。
   [`akb raw archive 2` 的输出](04-archive.log)

5. 回到看板，再点「列表导出」。
   #2 变成 `✓ 已完成 #2 导出 CSV`，和 #3 一样变灰。
   ![归档后](05-after-archive.png)

## Feedback

- **一眼看出做到哪了**：讨论里写成的卡片不再一律是「已写成」，完成的打勾变灰，放弃的也变灰，剩下的橙色就是还在做的。
- **归档后标题还在，也还能点**：点进去是归档页，能直接看到当时做了什么。
- **找不到的卡像在进行中**：#9 的文件已经没了，却显示和进行中一样的「→ 已写成」，只是没有标题、不能点；看的人会以为它还在看板上。
- **「已放弃」没有图标**：「已完成」有对勾，「已放弃」只有文字，两者同样变灰，扫一眼不容易分开。
- **没有跑到的**：真实 Agent 从讨论写卡的全过程；卡片自己聊天栏里的分隔线；英文界面。
