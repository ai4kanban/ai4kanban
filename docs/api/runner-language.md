# Runner 作业语言

`cloud.runner_job_json(p_job cloud.runner_jobs)` 返回原始 `prompt` 和 `language: 'zh' | 'en' | null`，不再返回 `languageLine`。测试作业的 `language` 为 `null`。

CLI 与 Runner 按代码选择共享系统提示词，仅注入一次：回复及给任务创建者看的内容使用系统语言，不随用户消息语言改变；工作流的最终产物沿用项目语言。

首次运行、支持更新的续跑及子运行使用同一规则；切换系统语言不翻译成果。子运行替换继承环境末尾已知的新旧平台语言注入，保留用户其他内容、正文引用及未知文本。空值也清除旧注入，不回退到本机设置，也不额外指定回复语言。

新版客户端兼容旧 Cloud 的已知中英文语言行，仅移除普通作业自动追加的末尾段。无法更新系统提示词时保留已有会话和用户规则，显示限制提示，由用户自行另开会话。

Claude Code 默认系统提示词快照会保留旧规则，续跑时显示上述限制；命令显式设置 `--system-prompt-snapshot off` 才支持更新。平台不改写用户的快照选择。
